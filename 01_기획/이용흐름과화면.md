# 이용 흐름과 화면

기준일: 2026-11-09 · 대상: 기획자·디자이너·프론트엔드 개발자

이 문서는 사장님이 각 화면에서 무엇을 보고 어떤 행동을 하는지 설명합니다. 서비스의 목적과 범위는 [서비스 기획서](서비스기획서.md), AI 판단과 보완 질문은 [AI 수집과 최소 질문](AI수집과최소질문.md)에서 확인합니다. API·데이터와 구현 방법은 [개발 문서](개발/README.md)를 봅니다.

S01은 소개, S02~S06은 가입·로그인, S07~S11은 가게 등록·진단, S12·S13·S15는 정비, S14는 계정 설정, S16은 전후 보고서, A01은 관리자 화면입니다. 아래 화면 목록에서 필요한 ID를 먼저 찾은 뒤 해당 제목을 검색하면 됩니다.

## 1. 화면 목록

|---|---|---|---|

| [S02](#s02-회원가입) | 회원가입 | 비회원 | 이메일·구글·카카오 가입 |

## 2. 전체 흐름

```text
S01 랜딩 → S02 회원가입 → (이메일 가입: S03 / 카카오 이메일 없음: S04) → S07 홈
S07 홈 → S08 가게 등록 → (후보가 여럿이면 S09) → S10 진행 → S11 무료 진단 결과
S11 → S12 자동 정비 신청 → (A01 승인) → S15 연결 → S13 정비안 승인 → 자동 정비
자동 정비 끝 → (2주 뒤) S10 재측정 → S16 전후 비교 보고서
```

- 로그인한 사장님이 랜딩이나 로그인 화면에 오면 S07로 보낸다.
- 로그인하지 않은 사람이 S07~S16에 오면 S05로 보내고, 로그인 후 원래 화면으로 돌려보낸다.

## 3. 화면별 동작

#### S01 랜딩

- 첫 화면: "AI가 맛집을 추천할 때, 우리 가게도 보이도록." 설명은 "AI가 읽는 가게 정보, seelo가 직접 바꿉니다."와 [우리 가게 무료 진단]
- 스크롤 소개: 가상 시내에서 가게 앞으로 접근하며 짧은 문구가 순차 전환된다. ① "우리 가게는, 왜 빠져 있을까요?"(진단) → ② "AI가 찾을 수 있게. 가게 정보를 직접 바꿉니다."(실제 정보 정비) → ③ "얼마나 달라졌는지, 숫자로 확인하세요."(2주 뒤 전후 비교)
- 성과 표현: 서비스 이용 가게의 실제 전후 실측이 확보되기 전에는 "평균 N% 상승"을 서비스 실적으로 주장하지 않는다. 시안의 20% → 40%, +20%p는 두 AI 평균을 가정한 시연 수치로, 수치 바로 옆에 "가상 비교 예시 · 실제 성과 아님"을 명시한다. 실제 성과를 게시할 때는 가게 수·측정 기간·모델별 성공 답변 수·평균 산식·증감의 단위(%p)를 함께 공개한다.
- 문제: AI는 지역의 일부 가게만 추천한다는 근거 수치 1개(2장)
- 이용 방법 4단계: 링크 넣기(무료 진단) → Google·카카오에 seelo 초대 → 바꿀 내용 승인 → seelo가 고치고 2주 뒤 전후 비교
- 무료 진단과 자동 정비 비교표
  - 무료: 노출 정도, 주변 가게 비교, 고쳐야 할 점 개수
  - 자동 정비: 고쳐야 할 점 확인·승인, Google·카카오 정보 수정, 2주 뒤 재측정, 전후 비교 보고서
- 결과 화면 예시(무료 진단, 전후 비교 보고서). 예시 수치에는 "예시"를 붙여 실제 성과처럼 보이지 않게 한다.
- 측정 횟수(60번)는 보여 주지 않고 "여러 번"이라고만 쓴다(2026-10-16 결정).
- 하단: 이용약관, 개인정보처리방침
- [무료로 확인하기]: 로그인 상태면 S07, 아니면 S02로 간다.

#### S02 회원가입

- 버튼: [구글로 시작하기], [카카오로 시작하기]
- 이메일 가입 입력: 이메일, 비밀번호, 비밀번호 확인
- 약관 동의: 이용약관(필수), 개인정보 수집·이용(필수), 전체 동의
- [가입하기], "이미 계정이 있나요? 로그인"
- 입력 규칙과 오류 문구

| 경우 | 문구·동작 |
|---|---|
| 이메일 형식이 아님 | "이메일 형식이 아니에요" |
| 비밀번호가 8자 미만이거나 영문·숫자가 섞이지 않음 | "8자 이상, 영문과 숫자를 함께 써 주세요" |
| 비밀번호 확인이 다름 | "비밀번호가 서로 달라요" |
| 필수 약관에 동의하지 않음 | [가입하기] 비활성 |
| 같은 이메일로 인증을 마친 계정이 있음 | "이 이메일은 [구글/카카오/이메일]로 가입되어 있어요"와 [그 방식으로 로그인]. 가입은 막는다. 소셜 가입도 같다 |

- 소셜 가입은 구글·카카오 동의 화면을 거쳐 돌아온다. 처음 가입이면 약관 동의를 받고 S07로 간다.

#### S03 이메일 인증 안내

- "OO@OO.com으로 인증 메일을 보냈어요. 메일의 링크를 누르면 가입이 끝나요."
- [인증 메일 다시 보내기]: 누른 뒤 60초 동안 누를 수 없다.
- [이메일 주소 바꾸기]: S02로 돌아가 다시 넣는다.
- 인증 링크는 24시간 동안 한 번만 쓸 수 있다. 만료된 링크는 "링크가 만료됐어요"와 [다시 보내기]를 보여 준다.
- 24시간 동안 인증하지 않은 계정은 지운다.
- 인증 전에 로그인하면 이 화면으로 보낸다.

#### S04 카카오 이메일 입력

- 카카오 로그인에서 이메일을 받지 못했을 때만 보인다.
- 이메일 입력 → 인증 메일 발송(S03과 같은 규칙) → 인증하면 가입 완료
- 같은 이메일 가입 차단 규칙은 S02와 같다.

#### S05 로그인

- [구글로 로그인], [카카오로 로그인], 이메일·비밀번호 입력, [로그인]
- [비밀번호를 잊으셨나요?] → S06, [회원가입] → S02
- 틀리면 "이메일 또는 비밀번호가 맞지 않아요". 어느 쪽이 틀렸는지는 알려 주지 않는다.
- 5번 연속 틀리면 10분 동안 로그인을 막는다.
- 소셜로 가입한 이메일로 비밀번호 로그인을 하면 "이 이메일은 [구글/카카오]로 가입되어 있어요"
- 로그인은 14일 동안 유지한다.

#### S06 비밀번호 재설정

- 1단계: 이메일을 넣으면 가입 여부와 관계없이 "가입된 이메일이면 재설정 메일을 보냈어요"를 보여 준다. 가입 여부를 드러내지 않기 위해서다.
- 2단계(메일 링크): 새 비밀번호와 확인을 넣으면 S05로 간다.
- 링크는 1시간 동안 한 번만 쓸 수 있다.
- 소셜 가입 계정이 요청하면 메일로 "[구글/카카오]로 로그인하세요"라고 알린다.

#### S07 홈(내 가게)

- 상단: 로고, 계정 메뉴(계정 설정, 로그아웃)
- 가게 정보 줄: 가게 이름, 주소, 찾은 출처(Google·카카오·네이버·공식 웹사이트·인스타그램 ✓/✕), [가게 변경]
- 상태 카드: 지금 상태에 맞는 카드 하나만 보여 준다.

| 상태 | 카드 내용 | 버튼 |
|---|---|---|
| 가게 없음 | "가게를 등록하고 AI 노출을 확인해 보세요" | 가게 등록 |
| 수집·측정 중 | 단계와 진행률 | 진행 상황 보기(S10) |
| 측정 실패 | "측정을 끝내지 못했어요. 무료 횟수는 차감되지 않았어요" | 다시 시도(하루 3번까지. 넘으면 "내일 다시 시도해 주세요") |
| 진단 완료 | ChatGPT·Gemini 등장률 요약, 고쳐야 할 점 N개 | 결과 보기(S11), 자동 정비 신청(S12) |
| 무료 사용 후 가게 변경 | "무료 진단은 계정당 1회예요" | 자동 정비 신청(측정 포함) |
| 정비 신청됨 | "신청이 접수됐어요. 승인되면 이메일로 알려 드려요" | 없음 |
| 신청 거절됨 | 거절 사유 | 다시 신청 |
| 연결 필요 | "Google·카카오에 seelo를 초대해 주세요"와 지도별 연결 상태 | 연결하기(S15) |
| 정비안 준비 중 | "연결된 지도의 정보를 읽고 바꿀 내용을 만들고 있어요" | 없음 |
| 정비안 확인 필요 | "바꿀 내용 N개를 확인해 주세요" | 정비안 확인(S13) |
| 정비 중 | 진행 표시. 수동 처리 칸이 있으면 "일부 칸은 seelo 팀이 직접 고치고 있어요" | 없음 |
| 재측정 대기 | "정비를 마쳤어요. M월 D일에 다시 측정해요"와 바꾼 항목 수 | 바꾼 내용 보기(S13, 읽기 전용) |
| 재측정 중 | 단계와 진행률 | 진행 상황 보기(S10) |
| 재측정 실패 | "다시 측정하지 못했어요" | 다시 시도(하루 3번까지) |
| 보고서 완료 | ChatGPT·Gemini 등장률 전후 요약 | 전후 비교 보고서(S16) |

- 정비 신청이 있으면 신청 상태 카드를 가게 상태보다 먼저 보여 준다.
- 정비 신청부터 보고서 완료 전까지는 [가게 변경]을 막고 "정비가 끝나기 전에는 가게를 바꿀 수 없어요"를 보여 준다.
- 사장님이 지도에서 seelo 권한을 지우면 "Google(또는 카카오) 연결이 끊겼어요"와 [다시 연결하기]를 보여 준다.
- 지난 기록: 가게를 바꾼 적이 있으면 이전 가게의 진단 결과와 전후 비교 보고서를 볼 수 있다(수정 불가).

#### S08 가게 등록·변경

- 입력: 가게 이름(필수, 1~50자), 지도 링크(필수)
- 링크 칸 안내: "Google 지도·카카오맵·네이버 지도에서 가게를 찾아 [공유 → 링크 복사]한 주소를 넣어 주세요." 지도별 복사 방법은 펼쳐서 본다.
- 공유 문구를 통째로 붙여 넣어도 링크만 골라낸다.
- [등록하기]를 누르면 가게를 찾는다(F-03).
  - 하나로 정해지면 S10으로 간다.
  - 후보가 여럿이면 S09로 간다.
  - 찾지 못하면 "가게를 찾지 못했어요. 다른 지도 링크를 넣어 주세요"
- 오류
  - 지원하지 않는 링크: "Google 지도·카카오맵·네이버 지도 링크만 넣을 수 있어요"
  - 음식점·카페·바가 아님: "지금은 음식점·카페·바만 진단할 수 있어요"(등록하지 않는다)
- 가게를 바꿀 때
  - "가게를 바꾸면 지금 가게의 결과는 지난 기록으로 옮겨져요"를 확인받는다.
  - 무료 진단을 이미 썼으면 "무료 진단은 다시 할 수 없어요"도 보여 준다.
  - 진행 중인 측정은 멈춘다.
  - 정비 신청이 진행 중이면 바꿀 수 없다.

#### S09 가게 후보 선택

- "어느 가게인가요?"와 후보 최대 5개(가게 이름, 주소, 업종, 찾은 지도)
- 후보를 고르면 S10으로 간다.
- [여기에 없어요]를 누르면 S08로 돌아가 "다른 지도 링크를 넣어 주세요"를 보여 준다.

#### S10 수집·측정 진행

- 단계: ① 가게 정보 모으기(지도·공식 웹사이트·인스타그램·AI 웹 검색) ② 질문 만들기 ③ ChatGPT·Gemini에 물어보기(n/60) ④ 결과 정리

- [내 가게가 아니에요]: S08 변경 모드로 간다. 측정을 멈추고 무료 횟수는 차감하지 않는다. 정비 승인 뒤의 측정과 재측정에서는 이 버튼을 숨긴다.
- 무료 진단을 이미 쓴 계정이 가게를 바꾸면 ①까지만 하고 S07로 간다.

  - ②는 건너뛰고 정비 전과 같은 질문을 쓴다.
- 진행률은 자동으로 새로고침한다. 끝나면 첫 측정은 S11, 재측정은 S16으로 간다.

#### S11 무료 진단 결과

- 요약
  - "ChatGPT 답변 m개 중 n개에서 추천됐어요(x%)". Gemini도 같은 형식. m은 성공한 답변 수(보통 30)다.
  - "추천될 때 평균 k번째"
  - 한 번도 추천되지 않았으면 "아직 한 번도 추천되지 않았어요". 오류가 아니라 정상 결과로 보여 준다.
- 주변 가게 비교: 우리 가게와 주변 가게 5곳의 ChatGPT 등장률, Gemini 등장률, 평균 등장 순서. 우리 가게는 강조한다.

  - 많이 인용된 사이트 5개와 인용 횟수

  - 0개면 "눈에 띄는 문제를 찾지 못했어요"를 보여 주고 신청 버튼은 그대로 둔다.
- 측정 조건(작은 글씨): 측정일, 질문 3개 × 10번 × ChatGPT·Gemini
- 무료 결과는 언제든 다시 볼 수 있다.

#### S12 자동 정비 신청·진행

- 신청 전에 보여 줄 것
  - seelo가 하는 일: Google 지도·카카오맵 정보 수정, 2주 뒤 재측정, 전후 비교 보고서
  - 사장님이 할 일: Google·카카오에 seelo 계정을 한 번씩 초대, 필요한 누락 질문이 있을 때만 최소 보완(전체 최대 3문항), 준비된 바꿀 내용을 보고 승인. 질문에 답하지 않아 보류된 새 변경은 빼고 진행할 수 있다. 아이디·비밀번호는 받지 않는다.
  - 고치지 않는 곳: 네이버 지도·공식 웹사이트·인스타그램·외부 사이트(진단에만 사용)
  - "베타 기간에는 신청 후 승인되면 진행돼요"와 [신청하기]
- 진단 결과가 없는 가게(무료 진단을 쓴 뒤 가게를 바꾼 경우)에는 "신청이 승인되면 측정부터 다시 진행해요"라고 알린다.
- 신청 후 진행 단계: 신청 접수 → 승인 → 지도 연결 → 바꿀 내용 확인 → 정비 중 → 재측정 대기(날짜 표시) → 전후 비교 보고서
  - 사장님이 할 단계(연결, 확인)에는 해당 화면으로 가는 버튼을 둔다.
- 같은 가게로는 정비를 한 번만 받을 수 있다. 거절된 경우에만 다시 신청할 수 있다.

#### S13 정비안 확인·승인

- 들어오는 곳: S07 "정비안 확인 필요" 카드, 정비안 준비 이메일
- 상단 요약
  - 진단 결과 3줄: ChatGPT·Gemini 등장률, 평균 등장 순서, 주변 가게 5곳과 비교한 위치
  - 바꿀 항목 N개(Google a개, 카카오 b개)
  - 지도별 연결 상태
- ① 고쳐야 할 점(영향이 큰 순서, F-08)
  - 제목(예: "Google 지도에 영업시간이 없어요")과 분류
  - 왜 중요한가: 관련 AI 답변, 주변 가게와의 차이
  - 이 문제를 고치는 칸(②)으로 가는 링크
- ② 지도별 바꿀 내용: Google 지도 / 카카오맵 탭(연결된 지도만)
  - 칸마다 이름, 지금 값, 바꿀 값, 이유를 보여 준다. 영문 소개·메뉴처럼 긴 값은 펼쳐서 본다.
  - 누락 정보 질문: AI가 자료와 연결 후 현재 값을 확인해도 필요한 사실을 찾지 못했을 때만 기본 0~2문항, 신청 전체 최대 3문항을 공통 영역에 보여 준다. S09 지점 확인·두 지도·재생성·나중 연결을 합산한다. 한 문항에 여러 독립 입력을 숨기지 않는다. 불일치는 AI가 최대한 해소하고 해결하지 못한 변경은 기본 보류한다.
  - 미확인 필수값이 있는 새 변경은 시스템이 승인 대상에서 제외하고 ‘이번에 보류한 항목’으로 구분한다. 기존 공개 값은 지우지 않는다. 사장님이 칸마다 [빼기]를 누를 필요 없이 [준비된 내용만 확인]으로 넘어갈 수 있다.
  - 알레르기·할랄 등의 새 주장은 기본 제외해 질문을 늘리지 않는다. 공개하려면 기존 근거·사장님 확인 규칙을 지키며 확인 요청도 전체 한도 안에서 처리한다.
  - 사장님은 바꿀 값을 직접 고칠 수 있다. 고친 값도 글자 수·형식 규칙(F-09)을 지켜야 한다.
  - 가게 이름·주소·업종은 seelo가 바꾸지 않는다. 다르면 사장님이 직접 고치는 방법을 알려 준다.
  - Google·카카오에서 가게를 찾지 못했으면 등록·인증 방법을 보여 준다. 등록하고 연결하면 정비안을 다시 만든다.
- ③ 진단 근거(펼치기): 질문별 AI 답변 원문. 우리 가게와 주변 가게 이름을 강조한다.
- 하단 안내와 버튼
  - "승인하면 위 내용으로 Google 지도·카카오맵을 고쳐요. 고치기 전 값은 seelo에 기록해 두고, 각 지도 관리 화면에서 언제든 직접 되돌릴 수 있어요."
  - [정비 시작]: 한 번 누르면 연결된 지도에서 승인한 칸을 모두 고친다.
- 한쪽 지도만 연결된 상태로 승인하면 그 지도만 고친다. 나중에 다른 지도를 연결하면 그 지도의 정비안만 다시 승인받는다.
- 승인 뒤에는 읽기 전용이 된다. 칸마다 결과(완료, 반영 대기, seelo 팀 처리 중)를 보여 준다.

## 4. 지도 연결의 상세 흐름

사장님이 Google·카카오에 seelo 계정을 한 번씩 초대하는 화면이다. 초대가 끝나면 고치는 일은 seelo가 한다(F-10). 네이버는 외부인에게 관리 권한을 줄 수 없어 정비하지 않는다.

#### S15 공통

- 들어오는 곳: S12 승인 단계, S07 "연결 필요" 카드, 승인 이메일
- 카드 2개: Google 지도, 카카오맵
  - 연결 상태: 연결 안 됨, 초대 대기, 연결됨, 권한 확인 필요
  - [초대 방법 보기](그림이 있는 단계 안내), seelo 계정 [복사], 초대한 뒤 누르는 [초대했어요]
- 초대한 지도만 정비한다. 한쪽만 연결해도 그 지도부터 정비안을 만든다.
- 사장님은 각 지도에서 언제든 seelo를 지워 권한을 거둘 수 있다고 알려 준다.
- 사장님 아이디·비밀번호는 받지 않는다.
- [초대했어요]를 누르고 3일 안에 초대가 오지 않으면 "초대가 아직 오지 않았어요"와 단계 안내를 다시 보여 주고, 이메일로도 알린다.
- seelo 계정
  - Google: seelo 공용 Google 계정(seelo 도메인 이메일, 2단계 인증 필수)
  - 카카오: seelo 공용 카카오계정(같은 이메일로 가입, 2단계 인증 필수)

#### Google 지도 카드: 관리자로 초대

| 단계 | 누가 | 할 일 |
|--|---|------------------------------|
| 0 | seelo | 가게가 Google 지도에 있는지(F-03 결과) 보여 준다. 없으면 이 카드 대신 Google 비즈니스 프로필 등록 방법을 보여 준다. |

| 6 | seelo | 초대 메일이나 `business.google.com`에서 초대를 수락한다. API 승인 후에는 API로 수락한다. |

- Google 관리자 권한으로 할 수 있는 것: 영업시간·주소·전화·서비스 수정, 게시물·사진 관리, 리뷰 답글
- 할 수 없는 것: 사용자 추가, 프로필 삭제
- 새로 추가된 사용자는 7일 동안 프로필 삭제·소유권 이전 같은 일부 기능이 막힌다. 정보 수정은 바로 할 수 있다.
- 고치는 방법: API 승인 전에는 `business.google.com` 관리 화면을 브라우저 자동화로, 승인 후에는 Business Profile API로 고친다(F-10).

#### 카카오맵 카드: 운영자로 초대

| 단계 | 누가 | 할 일 |
|--|---|------------------------------|
| 0 | seelo | 가게가 카카오맵에 있는지(F-03 결과) 보여 준다. |
| 1 | 사장님 | 카카오비즈니스 파트너센터(앱 또는 PC)에 사장님 카카오계정으로 로그인한다. |
| 2 | 사장님 | 매장관리에 가게가 없으면 먼저 대표 권한을 받는다: 사업자등록번호로 매장 조회 → 내 가게 선택 → [관리자 권한 등록하기] → 매장 정보 확인 → 비즈니스 심사 동의 → 신청. 심사 결과는 카카오톡으로 온다. 이 경우만 사장님 일이 한 번 더 늘어난다. |
| 3 | 사장님 | 사이드메뉴에서 매장을 고르고, 대시보드 오른쪽 위 [⋮] → [운영자 관리]로 간다. |
| 4 | 사장님 | seelo 화면에서 복사한 seelo 카카오계정(이메일 또는 전화번호)을 넣고 [운영자 초대]를 누른다. |
| 5 | seelo | 카카오톡 채널 메시지나 파트너센터 사이드메뉴 > 받은 요청에서 초대를 수락한다. |
| 6 | seelo | 파트너센터에 그 매장이 보이는지, 매장 > 매장정보 화면이 열리는지 확인한다. |
| 7 | seelo | 카드를 "연결됨"으로 바꾼다. 이후 처리는 Google과 같다. |

- 운영자가 할 수 있는 것: 매장 정보 수정, 후기 관리, 소식 작성
- 대표자만 할 수 있는 것: 대표자 변경, 매장 삭제, 매장주 인증, 운영자 초대·내보내기, 카카오톡 채널 연결
- 대표자는 [운영자 관리]에서 아직 수락하지 않은 초대를 취소하거나, 운영자를 [내보내기]로 뺄 수 있다.
- seelo가 고칠 수 있는 칸: 영업시간(휴게·공휴일·임시 영업·날짜 지정 휴무), 가격 정보(상품·가격·사진·소개, 추천 2개), 매장 사진(최대 100장, 태그), 사이트·SNS 링크(가게가 직접 운영하는 곳만), 제공 서비스, 태그(5개), 한 줄 소개(50자)
- 주소·업종 변경은 사업자등록증이 필요해 사장님에게 맡긴다.
- 고치는 방법: 카카오는 매장 정보 수정 API가 없다. 그래서 seelo 카카오계정으로 파트너센터 매장 > 매장정보 화면을 브라우저 자동화로 고친다(2026-10-16 결정). 규칙은 Google과 같다(F-10).
- 매장관리에서 고친 내용은 30분~1시간 뒤 반영된다(주소·업종 제외).
- 외부 업체를 운영자로 둬도 되는지에 대한 카카오의 제한 문구는 찾지 못했다. 고객센터에 물어본다(13장 사전 확인).

#### 네이버 지도: 정비하지 않음

- 스마트플레이스의 운영자 권한은 네이버 도움말상 **사업자의 내부 직원에게만** 줄 수 있다. 운영자는 예약 고객 연락처 등을 볼 수 있어서, 외부인에게 주면 개인정보보호법상 동의 없는 제3자 제공이 될 수 있다.
- seelo가 네이버 주인 권한을 대신 받지도 않는다. 네이버는 주인 변경 어뷰징을 감시하고, 대표자가 아닌 사람의 신청에는 재직증명서를 요구한다.
- 그래서 네이버는 정비하지 않는다(2026-10-17 결정). 네이버 기본정보는 가게 찾기와 진단 비교에만 쓴다.

## 5. 화면 공통 원칙

한 화면에서는 현재 상태와 다음 행동을 먼저 보여 줍니다. 기술 설명과 긴 근거는 필요한 사람이 펼쳐 보도록 합니다. 오류는 원인과 다시 할 수 있는 행동을 함께 안내하고, 진행 중인 작업은 창을 닫아도 이어집니다.

보완 질문은 같은 가게의 신청 전체에서 최대 3개입니다. 여러 지도나 페이지로 나눠 질문을 늘리지 않으며, 미확인 새 변경은 자동 보류해 준비된 내용만 승인할 수 있게 합니다.
