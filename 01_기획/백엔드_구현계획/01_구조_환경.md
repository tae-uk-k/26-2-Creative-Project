- 새 코드는 `04_MVP/seelo/` 아래에 만든다. 기존 `04_MVP/hanoon-mvp/`(Flask 더미 MVP)는 건드리지 않는다.

## 4. 환경변수(`.env.example`에 전부 적는다)

비밀 값은 저장소에 올리지 않는다. 표의 "비밀" 열이 예인 값은 운영에서 VM의 `.env`(권한 600)에만 둔다.

| 이름 | 예시·기본값 | 비밀 | 설명 |
|---|---|---|---|
| `APP_ENV` | `dev` | | `dev`·`test`·`prod` |
| `APP_BASE_URL` | `http://localhost:8080` | | 메일 링크·OAuth 리디렉션의 기준 주소(화면과 API가 같은 출처) |
| `FAKE_EXTERNALS` | `true`(dev), `false`(prod) | | 외부 연동을 모두 가짜로(17 1장). 운영에서 true면 시작 실패 |
| `FAKE_MAP_BEHAVIOR` | `normal` | | 가짜 관리 화면 동작: `normal`·`block`·`reflect_delay` |
| `DATABASE_URL` | `postgresql+psycopg://seelo:seelo@db:5432/seelo` | 예 | SQLAlchemy용 |
| `QUEUE_DATABASE_DSN` | `postgresql://seelo:seelo@db:5432/seelo` | 예 | Procrastinate용(libpq 형식, 같은 DB) |
| `SECRET_KEY` | 32바이트 이상 난수 | 예 | OAuth `state`용 `SessionMiddleware` 서명, CSRF 서명 |
| `EMAIL_HMAC_KEY` | 32바이트 이상 난수 | 예 | `free_usage_ledger.email_hash` HMAC 키. **절대 바꾸지 않는다**(바꾸면 무료 사용 기록이 무효) |
| `MAIL_TOKEN_FERNET_KEY` | `Fernet.generate_key()` 값 | 예 | 메일 링크 토큰 임시 암호화 |
| `COOKIE_SECURE` | `false`(dev), `true`(prod) | | 세션·CSRF 쿠키 `Secure` |
| `SESSION_TTL_DAYS` | `14` | | 세션 유지 |

`infra/nginx/default.conf` 요지:

```nginx
server {
  listen 80;
  client_max_body_size 1m;

```

운영(D-07)은 서울 리전 VM 1대에 같은 compose를 쓰고 TLS는 nginx(Let's Encrypt)에서 끝낸다. DB 백업은 매일 `pg_dump`를 VM 밖 저장소로 보낸다(10 6장).

## 7. 코드 규칙

### 7.1 이름

- 파이썬: 모듈·함수·변수 `snake_case`, 클래스 `PascalCase`, 상수 `UPPER_SNAKE`.
- DB: 테이블·컬럼 `snake_case`(02).
- API JSON: `camelCase`. 모든 API 스키마는 `CamelModel`을 상속한다.

```python
from pydantic import BaseModel, ConfigDict
from pydantic.alias_generators import to_camel

class CamelModel(BaseModel):
    model_config = ConfigDict(alias_generator=to_camel, populate_by_name=True, from_attributes=True)
```

- 작업(06) 이름은 명세서와 같은 `camelCase` 문자열을 `name=`으로 준다. 함수 이름은 `snake_case`(예: `name="collectStore"`, 함수 `collect_store`).

### 7.2 비동기·DB

- 전부 `async`로 쓴다(FastAPI, SQLAlchemy `AsyncSession`, httpx, OpenAI `AsyncOpenAI`, `google-genai`의 `client.aio`, Playwright async API).
- 엔진: `create_async_engine(DATABASE_URL, pool_pre_ping=True, pool_size=10)`. 세션 팩토리: `async_sessionmaker(engine, expire_on_commit=False)`.
- 관계(relationship)는 모두 `lazy="raise"`로 두고, 필요한 곳에서 `selectinload`로 명시한다. 지연 로딩 오류를 숨기지 않는다.
- **커밋은 항상 명시적으로 한다.** SQLAlchemy 세션은 첫 쿼리 때 트랜잭션을 자동으로 연다(autobegin). 그래서 `async with session.begin():`을 쓰지 않는다(이미 열린 트랜잭션과 부딪힌다).
  - API: 요청 하나 = 세션 하나(`get_db`). 유스케이스 서비스 함수가 마지막에 `await session.commit()`을 직접 부른다. `get_db`는 끝날 때 커밋되지 않은 것을 `rollback()`으로 버리고 닫는다.
  - 작업: `async with session_scope() as session:` 블록마다 필요한 곳에서 `await session.commit()`. 외부 API를 부르는 동안 트랜잭션을 열어 두지 않는다(읽기 → `commit()`으로 닫기 → 외부 호출 → 쓰기 → `commit()`).
  - 저장점이 필요한 곳(작업 등록 중복, 고유 위반을 무시할 곳)만 `async with session.begin_nested():`.
  - 코드 형태는 13 2장.
- 상태 변경은 03의 `transition()`(조건부 UPDATE)만 쓴다. ORM 객체의 `status`를 직접 바꾸지 않는다.

### 7.3 시간

- DB에는 `timestamptz`, 파이썬에서는 항상 시간대가 있는 UTC(`datetime.now(UTC)`)를 쓴다. `datetime.utcnow()`는 쓰지 않는다.
- "하루"(다시 시도 3회, 비용 상한)는 한국 시간 기준이다. `timeutil.kst_day_range(now)`가 그날 KST 00:00~다음날 00:00을 UTC로 바꿔 돌려준다.

### 7.4 외부 HTTP

- `integrations/http.py`의 `make_client(timeout_s, follow_redirects=False)`로만 클라이언트를 만든다. 기본 `User-Agent`는 `WEBSITE_USER_AGENT`.
- 서비스는 외부 어댑터를 직접 만들지 않는다. `seelo.integrations.get_clients()`가 돌려주는 묶음(`places`, `short_links`, `kakao`, `naver`, `website`, `openai`, `gemini`, `instagram`, `mailer`, `oauth`, `map_admin(provider)`)만 쓴다. API에서는 FastAPI 의존성으로, 작업에서는 함수 호출로 받는다. 테스트는 이 함수를 가짜로 바꾼다(11 2장).
- 모든 외부 호출에 제한 시간을 둔다: 지도 API 5초, 웹사이트 10초(robots.txt 5초), AI 60초, 이메일 30초, 관리 화면 작업은 작업 단위(06).
- 응답 원문을 로그에 남기지 않는다(크기·상태 코드·지연 시간만).

### 7.5 로그

- `structlog` JSON 로그. 모든 로그에 `request_id`(API) 또는 `job_id`·`task`(작업)를 붙인다.
- 가림 처리기(`logging.py`의 `redact`): 키 이름이 `password`, `token`, `secret`, `authorization`, `cookie`, `email`, `api_key`, `code`를 포함하면 값을 `"[REDACTED]"`로 바꾼다. 문자열 값 안의 이메일 주소 형태(`[^@\s]+@[^@\s]+`)는 `***@도메인`으로 바꾼다.
- 예외 로그에 요청 본문을 넣지 않는다.

### 7.6 오류

- 업무 오류는 `AppError(code, http_status, message, details=None)`로 던진다. 코드와 문구는 04 2장 표만 쓴다.
- 응답 형식:

```json
{ "error": { "code": "EMAIL_TAKEN", "message": "이 이메일은 구글로 가입되어 있어요", "details": { "provider": "google" } } }
```

- 요청 검증 오류(Pydantic)는 `VALIDATION_ERROR`(422)로 바꾸고, `details.fields`에 `{필드(camelCase): 오류 코드}`를 넣는다.
- 처리하지 못한 예외는 500 `INTERNAL_ERROR`, 문구 "잠시 후 다시 시도해 주세요". Sentry로 보낸다.

### 7.7 금지

- `print` 금지(로그 사용).
- `requests` 라이브러리 금지(httpx만).
- 비밀 값을 기본값으로 코드에 적지 않는다.
- 테스트에서 실제 외부 API를 부르지 않는다(`-m live` 제외).

구현 메모(2026-10-29, 16단계): 운영 파일·TLS·백업/복구·감시 준비는 `infra/OPERATIONS.md`에 모았다. 기존 개발 compose·`.env`는 바꾸지 않았다. `backend/scripts/check_uptime.py`는 외부 모니터용 일회성 명령이다. 실제 배포·외부 스케줄 설치는 D-07 결정 뒤 남았다.
