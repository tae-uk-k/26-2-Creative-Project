# 한눈 미정사항 결정 로그

- 목적: 기획서 본문에서 확정되지 않은 정책·기술·운영 결정을 한곳에서 관리한다.
- 상태값: `미정` / `논의 중` / `확정` / `보류`
- 원칙: 결정 시 선택안, 이유, 결정일, 영향받는 기능을 함께 기록한다.

## 1. 이미 확정한 사항

| ID | 결정 | 확정 내용 |
|---|---|---|
| F-01 | 개발 기준 | 과제용 화면이 아니라 실제 창업·개발을 전제로 작성한다. |
| F-02 | 사용자 | 실제 개별 가게 사장님을 대상으로 한다. |
| F-03 | 로그인 | 회원가입·로그인을 포함한다. |
| F-04 | AI 연동 | OpenAI·Gemini 실제 API를 연결한다. |
| F-05 | 필수 가치 | 지도 링크 정보 수집, AI 노출 측정, AI 노출 최적화 보고서 생성을 핵심으로 한다. |
| F-06 | 과금 경계 | AI 노출 진단은 무료, 구체적인 개선 항목과 개선 자료가 포함된 보고서는 유료다. |
| F-07 | 비교군 | 대상 가게 주변의 가게를 비교군으로 사용한다. |
| F-08 | 월간 재측정 | 구현 예정 기능으로 두고 상세 정책은 보류한다. |
| F-09 | 일정 | 현재 7주차이며 13주차까지 작동 가능한 베타를 완성한다. |
| F-10 | 역할 | 김태욱은 개발·데이터, 강가힐은 기획·UI를 책임진다. |
| F-11 | 구매 단위 | 가게별 개별 구매이며 상인회 단체구매는 하지 않는다. |

## 4. 다음 질문

가장 먼저 결정할 항목은 D-01이다. 지도 제공자마다 공식적으로 수집 가능한 항목과 구현 방식이 다르므로, 1차 버전에서 Google Maps와 Naver Maps를 모두 지원할지 확정해야 한다.
