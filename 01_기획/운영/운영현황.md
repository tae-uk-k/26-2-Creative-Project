# 운영 현황과 미완료 항목

현재 기준일은 2026-11-28이다. 진행 상태는 이 문서에서 갱신한다. 코드 검증과 실제 운영 검증은 각 작업의 완료 조건으로 기록한다.

## 출시 판단과 작업 순서

현재 작업본은 로컬 기능 시험을 통과했다. 11월 27일 운영 HTTPS에서 API·DB는 정상 응답했고 배포 커밋은 `abfa4dd`였다. `/prototype`은 피그마로 이동했으며 `/stores`에는 새 쇼핑몰 React 화면이 없었다. 실제 고객을 받기 전에 배포·몰별 위임·실제 AI·고객 이용 흐름을 검증해야 한다. 공개 모집과 유료 출시는 마지막 두 행의 조건도 충족해야 한다.

### 출시 전에 드러난 추가 작업

- 약관·개인정보 처리방침(`/terms`, `/privacy`)은 검토 전 초안이다(U10). 계정 화면(`/account`)에서 비밀번호 변경·탈퇴를 할 수 있다. 쇼핑몰 계정 삭제 후 브라우저 프로필과 큐 정리까지 검증하고, 그 전에는 파일럿 운영자가 연결 해제·프로필 정리 결과를 확인한다.
- 쇼핑몰 측정 요청은 질문과 반복 수를 제한한다. 현재 쇼핑몰 측정 실행 경로는 기존 지도용 일일 비용 한도를 적용하지 않는다. 공개 전 고객 단위 요청량, 운영 전체 비용 한도와 공급자 장애 시 대기 정책을 결정하고 구현·검증한다.
- 스마트에디터 ONE과 상품 속성, 카페24 모바일 설명은 자동 범위가 제한돼 있다. 실계정에서 지원 양식과 수동 처리 후 확인·복구 절차를 검수한다. API 경로를 함께 운영할 때만 카페24 OAuth와 스마트스토어 공식 판매자 연동 시험을 출시 범위에 넣는다.
- 운영 상태의 기준은 코드, CI, 배포된 SHA, 실제 셀러 실행 증거다. 지도 베타 검증과 2026-11-24 대표 계정의 본문 저장·복구 기록은 대상 환경과 함께 읽는다.

이번 검사 결과는 백엔드 전체 기준선 1042개 통과·Windows 배포 시험 3개 건너뜀·실제 외부 호출 5개 제외, 변경 후 쇼핑몰 집중 114개 통과다. 프런트는 73개·요청 계약 15개, 타입·빌드·형식, 백엔드 ruff·OpenAPI 일치, 개발·운영 Compose 구성과 로컬 HTTP smoke가 통과했다. 별도 PostgreSQL에서 `0001 → 0004` 마이그레이션을 실행해 기존 시험 계정 1개 보존과 쇼핑몰 테이블 8개를 확인했다. 실제 운영 배포와 고객 위임 시험은 대기다.
