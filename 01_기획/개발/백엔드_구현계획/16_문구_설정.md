# 16. 문구·라벨·설정 파일 전체

- 화면 문구는 프론트가 정하지만, **API가 내려주는 문구**(오류, 제목, 라벨, 메일)는 여기 것을 그대로 쓴다.
- 문구를 바꾸려면 이 파일을 먼저 고치고 코드 상수를 맞춘다.

## 1. 메일 템플릿(`seelo/templates/email/`)

구현 메모(2026-10-29, 15단계): 실제 파일은 `{type}.txt.j2` 10개와 공통 `_base.html.j2`다. 텍스트는 원문을 유지하고 HTML에서만 이스케이프한다. 모든 변형의 제목·링크, 빈 changed_fields의 "없음", KST 날짜를 기존 구현 그대로 검사했다. Mailpit 확인은 실제 SMTP 받은편지함 검증을 대신하지 않는다.

- 파일: `{type}.txt`(텍스트 본문), `{type}.html`(같은 내용을 `_base.html`에 넣은 것), 제목은 `SUBJECTS[type][variant]` 상수.
- Jinja2 `Environment(autoescape=True, undefined=StrictUndefined)`. 변수가 빠지면 렌더 오류로 실패시킨다(빈 메일 방지).
- 공통 변수: `link`(APP_BASE_URL + 화면 경로), `app_name = "seelo"`. `template_params` 키는 snake_case.
- 공통 끝맺음(모든 텍스트 본문 끝): `\n\n— seelo\n이 메일은 발신 전용이에요.`

| type | variant | 제목 | 본문(`.txt`) |
|---|---|---|---|
| `verify_email` | — | [seelo] 이메일 인증을 완료해 주세요 | 안녕하세요, seelo입니다.<br>아래 링크를 누르면 가입이 끝나요. 링크는 24시간 동안 한 번만 쓸 수 있어요.<br>`{{ link }}`<br>직접 가입하지 않았다면 이 메일을 무시해 주세요. |
| `password_reset` | email | [seelo] 비밀번호 재설정 안내 | 아래 링크에서 새 비밀번호를 정해 주세요. 링크는 1시간 동안 한 번만 쓸 수 있어요.<br>`{{ link }}`<br>요청하지 않았다면 이 메일을 무시해 주세요. 비밀번호는 바뀌지 않아요. |
| | social | [seelo] 로그인 방법 안내 | 이 이메일은 `{{ provider_label }}`로 가입되어 있어요. 비밀번호 대신 로그인 화면에서 [`{{ provider_label }}`로 로그인]을 눌러 주세요.<br>`{{ link }}`(= `/login`) |
| `diagnosis_result` | completed | [seelo] 무료 진단 결과가 나왔어요 | ChatGPT와 Gemini에 여러 번 물어본 결과가 나왔어요.<br>· ChatGPT 추천 등장률: `{{ openai_rate_text }}`<br>· Gemini 추천 등장률: `{{ gemini_rate_text }}`<br>결과 보기: `{{ link }}` |
| | failed | [seelo] 측정을 끝내지 못했어요 | 이번 측정을 끝내지 못했어요. 무료 진단 횟수는 차감되지 않았어요.<br>홈에서 다시 시도할 수 있어요(하루 3번까지).<br>`{{ link }}` |
| `fix_requested` | — | [seelo 관리자] 새 자동 정비 신청 | 새 자동 정비 신청이 들어왔어요.<br>· 신청 번호: `{{ request_id }}`<br>· 가게: `{{ store_name }}`<br>`{{ link }}` |
| `fix_decided` | approved | [seelo] 자동 정비 신청이 승인됐어요 | 자동 정비 신청이 승인됐어요. 이제 Google·카카오 관리 화면에서 seelo 계정을 한 번씩 초대해 주세요. 아이디·비밀번호는 필요 없어요.<br>초대 방법 보기: `{{ link }}` |
| | rejected | [seelo] 자동 정비 신청이 승인되지 않았어요 | 이번 신청은 승인되지 않았어요.<br>사유: `{{ reject_reason }}`<br>내용을 확인한 뒤 다시 신청할 수 있어요.<br>`{{ link }}` |
| `map_connection` | connected | [seelo] `{{ provider_label }}` 연결이 완료됐어요 | `{{ provider_label }}` 연결이 완료됐어요. 지금 정보를 읽고 바꿀 내용을 만들고 있어요. 준비되면 다시 알려 드릴게요.<br>`{{ link }}` |
| | reminder | [seelo] 초대가 아직 오지 않았어요 | `{{ provider_label }}`에서 보낸 초대가 아직 seelo에 도착하지 않았어요. 초대 방법을 다시 확인해 주세요.<br>`{{ link }}` |
| `fix_plan_ready` | — | [seelo] 바꿀 내용을 확인해 주세요 | `{{ provider_label }}`에서 바꿀 내용 `{{ item_count }}`개를 준비했어요. 확인한 뒤 [정비 시작]을 눌러 주세요.<br>`{{ link }}` |
| `manual_required` | — | [seelo 관리자] 수동 처리가 필요해요 | 신청 `{{ request_id }}`에서 직접 처리할 칸이 생겼어요.<br>`{% for i in items %}`· `{{ i.provider_label }}` `{{ i.field_label }}` — `{{ i.reason_label }}`<br>`{% endfor %}``{{ link }}` |
| `fix_completed` | — | [seelo] 정비를 마쳤어요 | Google 지도·카카오맵 정보 정비를 마쳤어요.<br>바꾼 항목: `{{ changed_fields \| join(", ") }}`<br>`{{ remeasure_date_text }}`에 같은 질문으로 다시 측정해 전후를 비교해 드려요.<br>`{{ link }}` |
| `report_ready` | — | [seelo] 전후 비교 보고서가 준비됐어요 | 정비 전후를 같은 질문으로 비교한 보고서가 준비됐어요.<br>`{{ link }}` |

- 표의 `<br>`은 줄바꿈이다. `openai_rate_text`: rate가 있으면 `"20.0%"`, 없으면 `"측정하지 못함"`. `remeasure_date_text`: `"11월 30일"`(KST). `provider_label`: 4장 `MAP_LABEL`. 메일 `fix_completed`의 `changed_fields`는 `"Google 지도 영업시간"`처럼 지도+칸 라벨만(값 원문 금지). 비면 "없음"(12단계).
- `_base.html`: 가운데 정렬 600px 표, 맨 위 "seelo" 글자 로고(색 `#285b46`), 본문 단락, `link`가 있으면 같은 색 버튼 하나, 끝맺음. 외부 이미지·추적 픽셀 없음.

| 상수 | 문구 | 쓰는 곳 |

| `GUIDE_ADDRESS` | 주소는 seelo가 바꾸지 않아요. {지도}에서 주소 변경을 직접 신청해 주세요(카카오는 사업자등록증 필요). | 같음 |

| `GUIDE_KAKAO_PHONE` | 카카오맵 전화번호는 파트너센터에서 직접 고쳐 주세요. | 같음 |
| `NOTE_DIFFERS` | 지금 지도 값이 달라요(사장님이 바꿨거나 아직 반영 전) | 보고서 |

```

- `api: null`은 API 모드에서도 수동 처리(D-14 확인 전). 편의 정보는 속성 이름 매핑을 확인한 뒤 `"api": "attributes"`로 바꾼다.
- `price_items.maxItems`, `links.maxItems`, `tags.maxLength`, `services.choices`는 파트너센터 화면을 보고 채운다 `[PoC]`. `choices`가 비어 있으면 `services` 칸 값 검사는 "문자열 목록"만 본다.
- 특별 영업시간(`special_hours`)은 사실 출처가 거의 없어 베타 사전에서 뺐다. 필요하면 `"special_hours": {"label": "특별 영업시간", "type": "special_hours", ...}`를 더하고 type 검사를 만든다.

    day_rows: "css=..."             # 요일 행 반복
    day_toggle: "css=..."
    open_input: "css=..."
    close_input: "css=..."
    add_interval: "css=..."
    save: "css=..."
    saved_ready: "css=..."
  # website, phone, menu, attributes(google) / intro, hours, price_items, links, services, tags(kakao) 같은 방식
```

- 모든 `...`은 PoC에서 저장한 실제 화면 HTML로 정한다(17 3장). 정하지 못한 칸은 그 칸을 `fields`에서 빼고, 코드가 그 칸을 만나면 `manual_required(write_failed)`로 넘긴다.
- 구현 메모(2026-10-28, 13단계): 실제 파일은 09 8.4 형식으로 만들었다(`integrations/browser/selectors/*.yaml`, 값은 모두 빈 칸 `[PoC]`). 위 틀과 다른 이름: `login: {url, logged_in}`(로그인 호스트는 `guards.LOGIN_HOSTS`), `pages.info: {url_template, ready, not_found}`, `store_search.link`(행 안의 링크)·`external_ref`(정보 화면 주소에서 위치 식별값을 뽑는 정규식), 인증 필요·권한 없음 표시는 `attention: {사유: 셀렉터}`. 지금 코드가 읽는 칸 항목은 `read·open_editor·input·save·saved_ready·review_badge`뿐이다. 영업시간처럼 행이 여러 개인 칸(`day_rows` 등)은 PoC 뒤 지도별 클래스에 칸 함수로 더하면서 형식을 정한다.
- 셀렉터는 Playwright 문법(`css=`, `text=`, `role=button[name="저장"]`)만 쓴다. XPath는 쓰지 않는다.
