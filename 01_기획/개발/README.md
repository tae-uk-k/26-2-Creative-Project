| 문서 | 찾을 수 있는 내용 |
|---|---|

기능을 바꿀 때는 [이용 흐름과 화면](../이용흐름과화면.md), [AI 수집과 최소 질문](../AI수집과최소질문.md), [상품정보 정비 기준](../상품정보정비기준.md)을 함께 맞춘다. 같은 규칙을 여러 문서에 다시 정의하지 않고 해당 문서를 연결한다.

남은 구현·결정·사용자 조치는 [운영 현황](../운영/운영현황.md)의 C-01~C-16, D1~D16, U1~U11에서만 추적한다. 날짜별 검증 근거는 [구현 시험 기록](../../03_실험/구현시험/)에 있다. 완료 표시가 없는 작업을 추측으로 완료 처리하지 않는다.

계정·인증·작업 큐·배포의 공통 기반은 지도 베타 때 만들었다. 그때의 백엔드 구현계획·기능 정의·개발 할 일은 [이전 기획 보관](../../98_이전기획/01_기획/개발/)에 있다. 공통 기반의 설계 배경이 필요할 때만 참고한다.
