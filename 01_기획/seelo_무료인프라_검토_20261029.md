# seelo 무료 우선 인프라 검토·구축안

- 확인일: 2026-10-29
- 상태: 공식 자료 조사·조건부 구성안. 가입·결제·서버 확보·배포·ARM 실행 시험은 하지 않았다.
- 방향: [기존 유료 인프라안](seelo_운영인프라_구축계획_20261029.md)보다 무료 구성을 먼저 검토한다. 단기 체험 크레딧은 상시 무료에 포함하지 않는다.
- 결론: 소규모 비공개 베타의 서버·DB·백업·인증서·기본 감시는 무료 한도 안에서 구성할 수 있다. 자원 확보와 실행 검증이 필요하며 실제 AI 측정을 포함한 서비스 전체의 비용 0원을 뜻하지 않는다.

## 1. 추천 구성

| 역할 | 무료 우선 선택 | 한도·조건 | seelo에 적용할 방법 |
|---|---|---|---|
| 서버 | Oracle Cloud Always Free A1 VM | 현재 문서상 계정 합계 2 OCPU·12GB RAM, ARM | VM 한 대에서 API·일반/AI 워커·nginx를 실행. 실제 필요한 메모리만 할당하고 ARM64 검증 |
| DB·큐 | 같은 VM의 PostgreSQL 16 | VM 자원·저장소 한도 안에서 자체 운영 | 현재 SQLAlchemy·Procrastinate 구조 유지, 외부 DB 포트 비공개 |
| 영속 디스크 | OCI Always Free Block Volume | 부트·블록 볼륨 합계 200GB | 처음에는 부트·데이터 합계 100GB 이내로 계획. 콘솔의 무료 대상 여부 확인 |
| 원격 백업 | OCI Object Storage | Always Free-only 계정은 저장 등급 합계 20GB·월 API 50,000회. 체험/유료 계정의 등급별 조건은 다름 | 비공개 버킷에 덤프 업로드·새 DB 복구 시험. 처음에는 Standard 10GB 이내로 계획 |
| 메일 | Resend Free SMTP | 월 3,000통·하루 100통, 검증된 발신 도메인 필요 | 현재 SMTP 어댑터에 연결, 한도 초과 유료 과금 옵션 비활성화 |
| 테스트 주소 | DuckDNS 무료 서브도메인 | 소유한 독립 도메인을 새로 받는 서비스는 아님 | API 접근용 테스트 주소. OAuth·발신 도메인 인증까지 가능하다고 가정하지 않음 |
| HTTPS | Let's Encrypt | 도메인 제어·인증서 검증·갱신 필요 | nginx 유지, HTTP-01 발급·갱신 흐름 추가 |
| 외부 감시 | UptimeRobot Free | 기본 5분 검사 | 실제 HTTPS health 감시·알림 수신 시험 |
| 오류 수집 | Sentry Developer | 1인 무료 계획, 사용량·기능 제한 | API·워커 오류 수집 확인. 유료 체험과 구분 |

서버·스토리지 한도와 자원 회수 조건은 [Oracle Always Free 공식 운영 문서](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)를 기준으로 했다. 과거의 4 OCPU·24GB 소개 자료로 용량을 확정하지 않는다. 실제 계정 콘솔의 무료 한도를 다시 확인한다.

Resend의 월·일 한도는 현재 [공식 요금](https://resend.com/pricing)과 [공식 Markdown 요금표](https://resend.com/pricing.md)에서 확인했다. SMTP는 API 키와 검증된 도메인을 요구하며 STARTTLS를 지원한다. [공식 SMTP 안내](https://resend.com/docs/send-with-smtp)

나머지 무료 범위: [DuckDNS](https://www.duckdns.org/about.jsp), [Let's Encrypt](https://letsencrypt.org/about/), [UptimeRobot](https://help.uptimerobot.com/en/articles/11604710-who-should-use-uptimerobot-s-free-plan), [Sentry](https://sentry.io/pricing/).

## 2. Oracle을 우선 검토하는 이유와 제약

현재 seelo는 API 외에 상시 워커와 PostgreSQL이 필요하다. VM은 기존 Compose 구성을 유지하기 좋다(구조 적합성 판단). 무료 VM의 처리량·메모리 적합성은 아직 실증하지 않았다.

- 홈 리전에서 A1 용량을 확보해야 하며 생성 실패가 생길 수 있다. 가입 때 리전과 실제 선택 가능 자원을 확인한다.
- 공식 문서에 유휴 자원 회수 조건이 있다. 별도 백업과 재구축 절차를 필수로 둔다. 회수를 피하려고 인위적인 부하를 만들지 않는다.
- 계정 신원 확인에 카드 등록을 요구한다. 무료 사용과 카드 등록 불필요는 같은 조건이 아니다. [Oracle FAQ](https://www.oracle.com/cloud/free/faq/)
- 무료 계정에는 SLA가 없다. 서버 재확보 지연을 포함한 복구 시간은 보장할 수 없다.
- ARM64이므로 이미지·의존성의 빌드와 실행을 확인해야 한다. 자동 지도 정비 워커는 초기 비활성화한다.
- 무료 자원을 확보하지 못하면 검증 단계에서 대기·대안을 재평가한다. 유료 계정·유료 VM으로 자동 전환하지 않는다.

## 4. 도메인·메일의 무료 조건

- 보유 도메인이 있으면 해당 DNS에 발신 인증 레코드를 등록해 Resend 무료 한도를 사용할 수 있다. 메일 요금과 도메인 보유 비용을 구분한다.
- 보유 도메인이 없으면 DuckDNS로 API·HTTPS 검증부터 할 수 있다. Google·카카오 OAuth의 실제 등록·소유 확인은 별도로 검사한다.
- 무료 테스트 호스트만으로 Resend 발신 인증까지 된다고 가정하지 않는다. 독립 도메인 확보가 필요할 수 있다.
- 도메인 확보 전 소수 내부 수신 시험은 Gmail SMTP를 별도 후보로 둘 수 있다. 계정에 2단계 인증·앱 비밀번호 사용이 허용돼야 하고 수신·발송 제한을 확인해야 한다. 운영 메일 완료로 간주하지 않는다. [Google 앱 비밀번호 조건](https://support.google.com/accounts/answer/185833?hl=ko)
- 수신 메일함과 회신 경로도 실제 계정으로 확인한다. Resend의 송수신 기능을 함께 쓸 때는 무료 할당량 계산을 확인한다.

## 5. 기존 구축 계획에서 바꿀 것

| 기존 제안 | 무료 우선 변경 |
|---|---|
| Lightsail 월정액 VM | OCI Always Free 확보 가능 여부부터 확인 |
| x86 전제 없이 진행 | Linux ARM64 이미지·API·워커·마이그레이션 실행 시험 추가 |
| Route 53 DNS-01 | DuckDNS 또는 보유 DNS + HTTP-01 기본안. 최초 HTTP 발급·갱신 경로 구현 |
| S3 백업 | OCI Object Storage 전송·원격 검증·복구 어댑터. 같은 계정 중단에 대비한 별도 사본 검토 |
| SES SMTP | Resend Free SMTP. 실제 발신 도메인 없으면 내부 수신 시험까지만 |
| 유료 확장 가능 | 한도 접근 시 자동 증설·유료 옵션 활성화 대신 중단·알림·재계획 |

인증서 자동화·외부 백업 업로드·워커/백업 감시는 여전히 추가 구현 대상이다. 현재 설정 파일을 연결하는 것만으로 모두 끝난 상태가 아니다.

HTTP-01은 최초 인증서를 발급할 HTTP 전용 구성과 갱신용 `/.well-known/acme-challenge/` 경로가 필요하다. 발급 뒤 TLS 구성으로 전환하고 갱신 경로는 유지한다. 현재 nginx의 전체 HTTP 리디렉션 설정을 그대로 두고 완료 처리하지 않는다.

백업은 원격 전송·무결성 확인이 성공해야 완료로 센다. 보관 기한 지난 파일을 자동 영구 삭제하지 않는 기존 규칙을 유지한다. 저장량이 계속 늘 수 있으므로 한도 접근 시 중단·알림·격리/별도 보관 절차가 필요하다.

## 6. 무료에서 제외하거나 별도 확인할 비용

| 항목 | 처리 |
|---|---|
| OpenAI 측정·추출·정비안 | 실제 API·웹 검색은 과금 대상. 별도 크레딧이 제공된다고 가정하지 않음 |
| Gemini·지도 API | 모델·검색·SKU별 무료 한도와 결제 조건을 실제 키·모델 선택 때 별도 확인 |
| 새 독립 도메인 | 등록·갱신 비용을 무료 인프라에 포함하지 않음 |
| 한도 초과 저장·전송·메일 | 무료 범위에서만 구성하고 초과 옵션은 켜지 않음. 예산 알림만으로 지출 차단을 보장하지 않음 |
| 무제한 가용성·지원 | 무료 서버·도구의 운영 조건 안에서만 시험 |

현재 명세는 OpenAI·Gemini 측정을 모두 포함한다. 인프라를 무료로 바꾸더라도 측정 방법·모델·질문·반복 수를 임의로 바꾸지 않는다. 실제 OpenAI 웹 검색 호출은 도구 호출 및 모델 사용 요금이 있다. [공식 API 요금](https://developers.openai.com/api/docs/pricing)

외부 호출 비용도 0원인 검증은 기존 로컬 가짜 연동 모드로 진행할 수 있다. 가짜 연동은 실제 가게 측정 증거가 아니며 운영 환경의 가짜 모드 차단을 풀지 않는다.

## 7. 무료안 실행 순서

1. **가용성 확인:** OCI 계정·홈 리전·A1 확보·공인 IP·디스크·네트워크의 콘솔 무료 조건 확인. 계정 등록·인증은 별도 실제 작업이다.
2. **로컬 보완:** ARM64 실행 시험, HTTP-01 인증서 절차, Object Storage 백업·복구, 워커·한도 점검 도구 준비.
3. **초기 배포:** API·PostgreSQL·일반/AI 워커 배포. 비밀 값은 저장소 밖에 보관하고 자동 정비는 끈다.
4. **주소·메일:** 무료 주소로 HTTPS 검증. 보유 도메인이 있으면 Resend 연결, 없으면 실제 서비스용 메일·OAuth의 미완료 조건을 남긴다.
5. **운영 확인:** 원격 백업 복구·5분 감시·워커 정지·백업 실패 알림. 무료 한도와 사용량 기록.
6. **실제 인수:** API 비용 상한과 키가 준비된 경우에만 동의한 가게로 전체 흐름 2회 검증. 비용 없는 가짜 시험과 구분한다.

무료 VM 확보 시간을 예측할 수 없어 이전의 3~5작업일 일정은 확보·계정 준비 이후의 구현 목표로만 사용한다. 고정 월 인프라비 0원은 무료 한도 내 사용·현재 정책·실제 계정 조건을 전제로 한 목표이며 무기한 보장이 아니다.

- 현재 조사만 수행했다. `.env`·운영 서버·DB·앱 코드·커밋·푸시는 변경하지 않았다.
