- 측정 시각 2026-11-24T10:54:00+09:00 ~ 2026-11-24T11:12:24+09:00
- 모델 gemini-3.8-flash
- Gemini Developer API에서 Google Search grounding을 켰다. 매 요청에 고정 질문 1개와 공통 문장만 넣었다. 이전 응답이나 프로젝트 정보는 전달하지 않았다.
- 문항 순서는 반복별로 섞었다. 서로 다른 질문을 최대 3개씩 실행했다.
- 응답 본문, 종료 상태 STOP, 실제 검색 근거를 모두 확인한 건을 유효로 집계했다. 유효 응답의 API 검색 질의는 171개, 인용 출처는 274개다. 반복 등장한 질의와 출처를 포함한다.
- 소비자용 Gemini와 Antigravity CLI 결과는 각 측정 기록에서 확인할 수 있다. 이번 집계에는 Gemini Developer API만 포함했다.

## 대상 상품 판정

| 대상 | 자연 발견 | 상위 3개 추천 | 상품 URL 인용 |
|---|---:|---:|---:|
| 수박씨 | 0/24 | 0/24 | 0/24 |
| 사차인치 | 0/24 | 0/24 | 0/24 |

상품마다 일반 조건 12건과 해당 원료 지정 12건을 판정했다. 36개 응답에서 두 상품의 정체성과 대상 상품 링크가 확인되지 않았다. Google이 반환한 grounding 인용 274개는 공개 리디렉션의 목적지 URL까지 확인했다. 해당 인용에 두 상품의 스마트스토어·카페24 링크가 없었다.

G01 1회차의 답변 본문에 독한마트로 표시된 링크 하나는 리디렉션에서 404를 반환했다. 이 링크의 목적지는 미확인이다. [인용 리디렉션 확인 기록](인용리디렉션_확인.json)

## 실행 오류

- gemini-api-B0-W01-r2 · TimeoutError
- gemini-api-B0-S02-r3 · TimeoutError

두 타임아웃은 각각 1회 재실행해 복구했다. 오류 응답은 발견·추천률의 분모에서 제외했다. 재실행이 유효하면 해당 문항·반복에 한 번만 반영했다.

2.5 Flash는 API가 신규 사용자에게 모델을 제공하지 않는다는 HTTP 404를 반환했다. 해당 진단을 보관하고 API가 안내한 3.8 Flash로 본 측정을 시작했다.
