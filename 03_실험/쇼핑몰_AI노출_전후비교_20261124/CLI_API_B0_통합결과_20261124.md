# Codex CLI·Gemini API B0 통합 결과

측정일: 2026-11-24. 상태: **두 별도 실험군의 B0 측정 완료**. 상품 정비나 사후 측정은 하지 않았다.

## 실행 조건과 범위

| 구분 | ChatGPT 측정 경로 | Gemini 측정 경로 |
|---|---|---|
| 실행 환경 | Codex CLI, ChatGPT 계정 인증, `gpt-6.2-sol`, 웹 검색 활성화 | Gemini Developer API, API 키 인증, `gemini-3.8-flash`, Google Search grounding |
| 질문 | 고정 질문 12개 × 3회 | 같은 고정 질문 12개 × 3회 |
| 대화 분리 | 질문마다 신규 프로세스와 대화. 사용자 CLI 설정 미적용 | 요청마다 독립 대화. 과거 응답과 프로젝트 정보 미전달 |
| 유효 응답 | 36/36 | 36/36 |

Codex CLI와 Gemini API는 서로 다른 실행 환경이다. 이 결과는 기존 소비자용 ChatGPT·Gemini 웹 앱 결과 및 Antigravity CLI 결과와 합치지 않는다. 이 문서에서 ChatGPT 측정은 소비자용 ChatGPT 웹 앱이 아니라 Codex CLI를 뜻한다.

Codex 정상 실행의 질문 제출 시각은 03:39~11:10 KST다. 이전에 완료한 7건을 유지했고, 같은 날 나머지 29건을 재실행했다. 따라서 Codex B0는 약 7시간 31분에 걸쳐 있다. Gemini API는 10:54~11:12 KST에 실행했다. 두 측정의 실행 시점 차이를 고려해 후속 비교를 해석한다.

## 대상 상품 결과

일반 조건 4문항과 해당 원료 지정 4문항을 각각 3회 실행했으므로, 상품별 평가 분모는 AI별 24응답이다. 하나의 일반 질문에 두 상품이 모두 평가 대상이어도 실행 자체는 1회다.

| 측정 경로 | 대상 | 자연 발견 | 상위 3개 긍정 추천 | 대상 상품 URL 인용 |
|---|---|---:|---:|---:|
| Codex CLI | 수박씨 | 0/24 | 0/24 | 0/24 |
| Codex CLI | 사차인치 | 0/24 | 0/24 | 0/24 |
| Gemini API | 수박씨 | 0/24 | 0/24 | 0/24 |
| Gemini API | 사차인치 | 0/24 | 0/24 | 0/24 |

여기서 0은 **대상 상품의 정체성이나 대상 URL이 응답에서 확인되지 않은 횟수**다. 같은 원료의 다른 제품과 일반 설명은 대상 상품으로 세지 않았다. 상품이 등장하지 않아 대상 상품의 원재료·가격 정확도나 근거 없는 영양 수치는 평가할 수 없었다.

Gemini API의 Google Search grounding 인용은 반복을 포함해 274건이었다. 모두 공개 리디렉션의 목적지까지 확인했으며, 대상 상품 URL은 없었다. 답변 본문에 별도로 표시된 독한마트 링크 1건은 404로 목적지가 미확인이다. 공식 grounding 인용과 구분해 기록했다. Codex CLI의 정상 실행 원문에서도 대상 점포·상품 식별자는 확인되지 않았다.

## 오류와 재실행

- Codex CLI: 최초 36회 중 29회가 사용량 한도로 미완료였다. 2026-11-24에 해당 29개를 각각 1회 재실행해 모두 복구했다. 최초 실패 원문도 보관했다.
- Gemini API: 최초 36회 중 2회가 시간 초과였다. 각 1회 재실행해 복구했다. 최초 오류는 점수에 넣지 않았다.
- 최종 집계는 각 질문·반복에 대해 정상 응답을 1회만 사용했다. 미완료 응답을 발견 실패로 세지 않았다.
- 각 정상 응답의 질문 문구, 검색 사용, 최종 응답을 확인했다. Gemini API의 정상 응답은 모두 `finishReason=STOP`이었다.
