# CLI 별도 측정 결과

실행일: 2026-11-24. Codex CLI B0는 36회 완료했다. Gemini API는 별도 측정으로 완료했다. [통합 결과](../CLI_API_B0_통합결과_20261124.md)

이 기록은 소비자용 ChatGPT·Gemini 웹 앱 결과와 구분한다. Codex CLI와 Gemini CLI는 모델과 검색 실행 경로가 달라 기존 웹 앱 측정과 같은 실험군으로 합치지 않는다.

## Codex CLI

- `gpt-6.2-sol`, 실시간 웹 검색 활성화, `--ephemeral`, 사용자 설정 미적용, 읽기 전용 환경으로 실행했다.
- 기본 12문항 × 3회, 총 36회 실행을 시도했다. 각 실행은 별도 프로세스와 새 세션을 사용했다.
- 최초에는 7회만 정상 완료했고 29회는 Codex 사용량 한도 오류로 미완성이었다. 그중 W04 1회는 검색을 시작했지만 최종 답변을 마치지 못했다.
- 한도 해제 후 미완성 29회를 같은 모델과 질문으로 각 1회 재실행해 **최종 36회 모두 검색과 응답을 확인했다.** 36개 최종 답변에서 실험 대상 상품의 이름과 URL은 확인되지 않았다.
- 최초 미완성 응답을 발견·추천 0점으로 처리하지 않았다. 최초 실패와 `_retry1` 재실행 기록을 모두 보관했다.
- 실행별 `.json`에 질문·시각·모델·검색 여부·완료 상태·응답이 있고, `.jsonl`에 검색과 응답 이벤트 원문이 있다.

## Gemini CLI

- 설치된 0.47.0과 별도로 시험한 0.70.0 모두 기존 Code Assist 인증으로 간단한 테스트에 실패했다.
- 실행 환경의 Gemini API 키, Google API 키, 애플리케이션 기본 사용자 인증은 확인되지 않았다. 현재 연결된 Google Cloud 프로젝트에 Vertex AI 서비스는 활성화되어 있지만 CLI에 쓸 애플리케이션 기본 사용자 인증은 확인되지 않았다.
- 인증 실패로 본 실험 질문은 제출하지 않았다. 기존 인증 방식을 수정하거나 새 인증을 생성하지 않았다.
- 이후 사용자가 API 키를 제공해 Gemini Developer API 측정을 별도로 수행했다. [Gemini API 실행 결과](../Gemini_API_별도측정_20261124/실행결과.md)

## Antigravity CLI의 Gemini 후속 실행

- 사용자의 지적에 따라 설치된 Antigravity CLI `agy` 1.4.0을 확인했다. `gemini-3.8-flash-low`를 지정한 새 대화에서 Gemini 응답과 `search_web` 도구 실행을 확인했다.
- 이 실험군은 `--mode plan`, 새 CLI 프로세스, 고정 질문 및 공통 접미사를 사용했다. 도구 호출과 결과를 `.jsonl`, 응답 및 상태를 `.json`에 보관했다. 소비자용 Gemini 웹 앱이나 이전의 Gemini CLI와 합산하지 않는다.
- 최초 7회 중 G01·G02·G03·W03은 검색과 최종 응답이 완료됐다. 이 4개 응답에서 대상 상품명과 대상 URL은 확인되지 않았다.
- G04·W01은 검색을 실행했지만 150초 제한에서 최종 답변을 회수하지 못했다. CLI가 내부적으로 `SUCCESS`를 반환했더라도 응답이 비어 있고 제한 시간 경고가 있어 미완료로 기록한다. 제한 시점에 대화가 백그라운드에서 계속될 수 있어 추가 상태는 미확인이다.
- W02는 검색 중 모델 용량 제한 오류 `RESOURCE_EXHAUSTED`가 발생해 최종 응답이 완성되지 않았다. 제한 오류가 확인된 뒤 추가 일괄 실행을 중지했다. W02를 한 번 재실행했지만 검색 후 90초 제한에서 최종 답변을 회수하지 못했다. 최초 오류와 재실행 로그를 모두 보관했다.
- 해당 3건은 0점으로 처리하지 않는다. 최초 7회 외 계획 문항은 실행하지 않았다.

## 웹 앱 B0와의 관계

기존 웹 앱 측정은 ChatGPT 13건, Gemini 12건이 확인됐다. Codex CLI와 Gemini API 결과를 그 25건에 합산하지 않는다. 전체 계획의 웹 앱 B0 72회는 미완료다.
