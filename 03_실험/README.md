# 실험과 검증 자료 안내

이 폴더는 실제로 수행한 조사·실험·시험의 기록을 보존합니다. 날짜가 다른 결과는 서로 다른 실험의 증거이며, 최신 기획서의 사본이 아닙니다. 원자료와 수치의 의미를 유지하고 결과 요약의 실험 조건을 먼저 읽습니다.

| 폴더 | 확인할 내용 |
|---|---|
| [구현시험](구현시험/) | 백엔드 단계별 검증, 외부 연동·로그인·배포·운영 시험 기록입니다. |
| [ai-visibility-experiment](ai-visibility-experiment/README.md) | AI 추천 관찰과 분석의 질문·응답·전처리·결과입니다. |
| [지도기반 AI 노출](지도기반_AI노출_20261016/README.md) | 지도 자료를 기준으로 한 AI 관찰·정보 제공 실험입니다. |
| [GEO 조건별 연구](GEO_조건별연구_20261016/) | 정보 작성 조건과 관련한 실험 자료입니다. |

가게의 실제 정보 정비 여부는 수정·공개 반영 기록으로 확인합니다. 추천 결과가 달라졌다는 관측, 서비스 구현 시험, 문서나 UI 시안 제작은 서로 구분합니다. 진행 중이거나 유효한 측정이 없는 실험을 완료된 성과로 계산하지 않습니다.

현재 확인 상태를 빠르게 보려면 [운영 현황](../01_기획/운영/운영현황.md)을 읽으세요.
