# 실험과 검증 자료 안내

이 폴더는 실제로 수행한 실험·시험의 기록을 보존한다. 날짜가 다른 결과는 서로 다른 실험의 증거이며 최신 기획서의 사본이 아니다. 결과 요약을 읽기 전에 실험 조건을 먼저 확인한다.

| [구현시험](구현시험/) | 쇼핑몰 자동화·로직 점검 기록과 공통 기반(계정·보안·인프라·배포·로컬 AI) 시험 기록 |

스토어의 실제 정비 여부는 저장·재조회·공개 반영 기록으로 확인한다. 추천 결과가 달라졌다는 관측, 서비스 구현 시험, 문서·UI 시안 제작은 서로 구분한다. 진행 중이거나 유효한 측정이 없는 실험을 완료된 성과로 계산하지 않는다.

가게·식당·지도 대상의 이전 실험과 지도 베타 구현 시험(단계 04~15)은 [이전 기획 보관](../98_이전기획/03_실험/)에 있다. 현재 확인 상태는 [운영 현황](../01_기획/운영/운영현황.md)을 읽는다.
