# GEO 기법 저장 유지 시험

계획일: 2026-11-28. 상태: **보류**. 2026-11-28 사용자가 실행하지 않기로 했다. 시험 자료와 판정 스크립트는 나중에 쓸 수 있게 보관한다.

## 1. 목적

정비안에 넣을 태그·속성이 각 플랫폼 저장 뒤에도 남는지 확인한다. 결과는 [상품정보 정비 기준](../../01_기획/상품정보정비기준.md) 8절의 구현 범위를 정한다. 기법 번호는 [GEO 기법 확장 조사](../../02_조사/GEO_기법확장_HTML메타데이터_20261128.md) 3절과 같다.

노출 효과는 이 시험에서 측정하지 않는다.

## 2. 대상

| 플랫폼 | 대상 | 조건 |
|---|---|---|
| 카페24 | 새 시험 상품 1개 | 진열 안 함·판매 안 함 |
| 스마트스토어 | 새 시험 상품 1개 | 전시 중지 또는 판매 중지 |

B 실험 상품(카페24 14·15, 스마트스토어 13892740658·13892740830)과 기존 벌꿀·귀리·서리태는 수정하지 않는다.

## 3. 시험 항목

[시험본문.html](시험본문.html)의 표시 T01~T19가 아래 기법을 나타낸다.

| 표시 | 기법 | 표시 | 기법 |
|---|---|---|---|
| T01·T02 | `h2`·`h3` | T11·T12 | `cite`·`time datetime` |
| T03 | 요약 `p` | T13 | `itemprop` 마이크로데이터 |
| T04·T05 | `dl`·`dt`·`dd` | T14 | `aria-label` |
| T06 | `ul`·`li` | T15 | `data-` 속성 |
| T07·T08 | `details`·`summary` 접힘 영역 | T16·T17 | `table` 참고용 |
| T09 | `img alt` | T18·T19 | `script type="application/ld+json"` |
| T10 | `figure`·`figcaption` | 별도 | `class`, `itemscope`·`itemtype`, `section data-seelo` |

## 4. 절차

1. 각 플랫폼에 시험 상품을 비공개 상태로 만든다. 플랫폼에 올린 이미지 주소를 시험본문의 `{{IMAGE_URL}}`에 넣는다.
2. 상세 설명에 시험본문을 HTML로 저장한다. 카페24는 관리자 HTML 입력, 스마트스토어는 커머스API `detailContent` 또는 HTML 작성 화면을 쓴다. 사용한 경로를 기록한다.
3. 관리자 화면 또는 API로 저장된 HTML을 다시 읽어 `저장_카페24.html`·`저장_스마트스토어.html`로 보관한다.
4. 카페24는 관리자 미리보기의 공개 HTML도 `공개_카페24.html`로 보관한다. 서버 응답에 본문이 있는지 함께 기록한다.
5. 판정을 실행한다.

```powershell
python -I 판정.py 저장_카페24.html 판정_카페24.json
```

6. 결과표에 `유지`·`변형`·`삭제`와 필터 주석을 옮긴다.
7. 시험 상품은 비공개로 두거나 삭제한다. 삭제 전에 사용자에게 확인한다.

## 5. 판정

| 판정 | 뜻 | 정비안 반영 |
|---|---|---|
| 유지 | 같은 태그·속성 안에 표시가 남음 | 사용 |
| 변형 | 표시 글자는 남았지만 태그·속성이 바뀜 | 사용하지 않음. 대체 태그를 찾음 |
| 삭제 | 표시가 사라짐 | 사용하지 않음 |

카페24 Froala 편집기가 줄바꿈·속성 순서만 바꾼 경우는 유지로 본다. 판정 스크립트는 태그·속성의 의미만 비교한다.
