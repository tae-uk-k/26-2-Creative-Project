# 지도 정보 제공 통제 실험 사전계획

고정: 2026-10-16, 모델 응답 수집 전. 자연 검색 18셀 파일럿과 별도 실험이다.

## 연구 대상과 한계

CLI에 지도명을 요청하는 것만으로 지도 본문 접근이 검증되지 않았다. 대화형 Antigravity에서 카카오 상세 URL 하나의 읽기를 1회 승인해도 상호 메타데이터만 읽고 메뉴는 확보하지 못했다. HTTP 점검에서 네이버는 429여서 재시도하지 않고, 카카오는 3550바이트 초기 HTML, 구글 검색은 HTML을 받았으나 상세 정보 전달은 검증하지 못했다. 웹 차단을 우회하거나 전역 권한을 해제하지 않는다.

이번에는 연구자가 일반 브라우저에서 읽은 **카카오맵 정보**를 CLI 프롬프트에 동일하게 제공한다. 실제 지도 검색에서 발견되는 확률이나 지도 수정 효과를 측정하지 않는다. 네이버·구글과의 효과 비교도 아니다.

표본은 카카오맵에서 `명동 식당`, `성수 식당`, `망원 식당`을 새로 검색해 장소 목록의 첫 4개 식당씩, 총 12곳을 고정한다. AI 추천 여부는 선정에 사용하지 않는다. 카페·비식당 광고는 제외한다. 검색 기본 정확도순, 사용자가 별도로 중심·거리를 고정하지 않은 해당 시점의 표시 목록이다. 명동 검색은 시청·무교동 등 주변도 포함하므로 행정동 확률 표본으로 일반화하지 않는다. 본 연구 계획의 독립 표본 60곳을 확보한 것은 아니다.

각 상세 페이지에서 주소·업종·가격이 있는 첫 2개 메뉴를 수집한다. 메뉴를 확보하지 못한 경우 해당 식당을 임의 교체하지 않고 결측·기술 제한을 기록한 뒤 실험 가능 범위를 다시 명시한다. 메뉴 설명 작성 주체가 확인되지 않으면 unknown으로 유지한다. 단가/중량/인원 조건은 표시된 경우 그대로 보존하고, 표시가 없으면 추정하지 않는다.

## 2×2 조건

| 조건 | 내용 |
|---|---|
| 메뉴·가격 구체성 낮음 | 업종·지역·주소만 제공 |
| 메뉴·가격 구체성 높음 | 같은 기본 정보에 실제 관측한 메뉴명·표시 가격 2개 추가 |
| 검색어 반복 없음 | 기본 정보의 지역·업종 1회 |
| 검색어 반복 있음 | 같은 지역·업종 문자열을 3회 추가; 새로운 사실·맛 평가·인기도 주장을 추가하지 않음 |

조건은 정보량·길이도 함께 달라진다. 결과를 '메뉴 가격만의 독립 효과'나 '반복 횟수만의 독립 효과'로 좁혀 해석하지 않는다. 특히 가격 보강은 메뉴 종류와 가격 수준도 함께 드러낸다.

4개 조건을 각 지역의 4개 식당에 교차 배정하고 4회 회전해 각 식당이 모든 조건에 노출되도록 한다. 회전 안의 표시 위치와 조건은 4원소 직교 라틴 배치로 균형을 맞춘다. 두 반복은 별도 고정 시드로 상호 익명 코드·순서·조건 대응을 섞는다.

규모: **3지역 × 2CLI × 2반복 × 4회전 = 48개 새 세션**, 응답마다 후보 4곳 중 식사할 곳 2곳을 순위와 함께 선택. 후보×응답 192행, 독립 식당은 12곳이다. 실제 상호·리뷰 수·평점·사진 수·지도 검색 순위·URL은 모델에게 주지 않는다. 단, 메뉴·주소로 상호를 알아볼 가능성까지 완전히 제거한 것은 아니다.

## 출력과 검수

웹 검색·로컬 파일·과거 대화·다른 에이전트를 사용하지 말고 제공된 정보만 판단하도록 요청한다. Codex의 웹 검색은 호출별 disabled. Antigravity는 외부 도구 호출 로그를 검수한다. 최종 JSON은 선택 코드 2개, 이유, 제공 정보 확인을 위한 메뉴명·가격 인용을 기록한다. 도구 호출이 관측되면 프로토콜 위반으로 제외하고 실패와 따로 보존한다.

후보 밖 선택, 중복 선택, 빈 JSON, 미완료, 권한 문제는 유효한 미선택 0으로 바꾸지 않는다. 요청/실제 보고 모델·CLI 버전·원문·프롬프트·배정·입력 해시를 남긴다. 이전 18셀·240회·소비자 데이터에는 합산하지 않는다.

## 분석

주 지표는 후보별 상위 2곳 선택 여부, 보조는 1위와 순위 점수다. 2×2 선택률을 모델별·지역별 제시하고 각 식당 안에서 메뉴·가격 보강 조건과 미보강 조건의 차이를 계산한다. 반복 응답을 독립 식당으로 세지 않는다.

식당·표시 위치를 통제한 탐색적 이항 회귀를 보조로 사용할 수 있으나, 12곳에서 XGBoost를 학습하지 않는다. 식당 단위 차이와 지역별 민감도를 우선 제시하고, 재표집 구간은 소규모·고정 후보의 탐색 범위라는 점을 명시한다. 일반화 가능한 효과를 단정하지 않는다.

이 실험이 보여주는 것은 **같은 후보 집합의 제공 정보 조건을 바꾸었을 때의 선택 변화**다. 실제 지도 노출 향상으로 이어지는지는 별도의 자연 검색·지도 정비 전후 실험으로 확인해야 한다.
