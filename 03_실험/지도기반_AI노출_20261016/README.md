# 지도 기준 CLI 식당 추천 연구

2026-10-16 최신: **별도 정보 제공 통제 실험 96회와 카카오 후보 60곳 상세 수집을 완료했다.** 메뉴·가격 정보 제공의 큰 선택 차이를 관측했고, 같은 정보의 항목별 정리 효과는 지역에 따라 달랐다. [최신 결과·60곳 데이터·한계](수집_검수_후속결과.md), [96회 실험 상세](정보제공_통제실험/README.md).

카카오 60곳의 상세 상호·주소를 대조했고 57곳에서 가격 있는 메뉴 221개를 확보했다. ‘첫 메뉴 2개’가 뒤의 낮은 가격을 놓친 곳이 23곳이라 대표 메뉴 선택 규칙도 별도로 다뤄야 한다. 네이버 동일 지점 업주 소개는 2곳 추가 확인했다. CLI가 지도 본문을 직접 읽는 경로는 여전히 검증되지 않았고, 자연 검색 90회와 네이버·구글 60곳 전수 대응은 미완료다. 통제 실험을 자연 검색 노출 결과에 합산하지 않는다.

아래는 **초기 18셀 접근 파일럿의 보존 기록**이다. 표본 60곳 미고정·통제 실험 미실행이라는 표현은 당시 상태이며 현재 진행은 위 최신 결과를 우선한다.

## 계획과 실제 완료 범위

순서는 출처 접근 점검 → AI 추천과 독립적인 후보 60곳 고정 → 지도 필드 수집 → 90회 반복 추천 → 작성 방식과 노출의 연관성 분석이다. 상세한 조건은 [실험계획](실험계획.md)에 고정했다.

| 단계 | 현재 상태 |
|---|---|
| 3지도 × 3지역 × 2CLI 접근 점검 | **18/18 셀 시도 완료**, 셀별 1회 |
| 정상 JSON 응답 | 13건, 추천 64건 |
| 기술적 미완료 | Antigravity URL 열람 도구 권한 거절 5건. 미노출 0으로 계산하지 않음 |
| 지정 지도 상세 본문 열람 검증 | **0건 확인**, 실제 열람이 입증되지 않은 것이며 모든 식당이 미노출이라는 뜻이 아님 |
| 브라우저에서 지도 필드 수집 경로 점검 | 네이버·카카오·구글 각 1곳, 총 3곳·25개 필드 관측 |
| 본 분석용 독립 표본 60곳 | 아직 고정하지 않음. `candidate_frame.csv`는 헤더만 있는 입력 양식 |
| 본 측정 90회·작성 방식 모형 | 미실행. 지도 본문을 읽는 경로부터 확보해야 함 |

영어 질문·국적·미국 환경 조건은 사용하지 않았다. 지도 이름과 지역만 바꾼 한국어 질문을 새 세션에서 실행했다. 모델에 가게 목록이나 기존 실험 자료를 제공하지 않았다. 이번 질문은 출처 확인 지시를 포함한 연구용 질문이며 소비자 앱 사용과 같다고 해석하지 않는다.

## 지도·CLI별 실제 결과

| 요청 지도 | CLI | 시도 | 정상 응답 | 권한 실패 | 추천 건수 |
|---|---|---:|---:|---:|---:|
| 네이버 | Codex | 3 | 3 | 0 | 14 |
| 네이버 | Antigravity | 3 | 1 | 2 | 5 |
| 카카오 | Codex | 3 | 3 | 0 | 15 |
| 카카오 | Antigravity | 3 | 0 | 3 | 0 |
| 구글 | Codex | 3 | 3 | 0 | 15 |
| 구글 | Antigravity | 3 | 3 | 0 | 15 |

요청 모델은 Codex `gpt-6.1-sol`, Antigravity `Gemini 3.8 Flash (Low)`다. Codex 응답 스트림에는 실제 모델 식별자가 별도로 보고되지 않아 요청값으로 기록했다. CLI 버전은 Codex `0.162.0-alpha.17.2`, Antigravity `1.3.4`다.

정상 추천 **64건 모두 `other_sources`**로 답했다. Codex는 지도 열기 오류·차단 등을 밝히고 블로그, 관광 사이트, 맛집 사이트로 대체했다. Antigravity의 실패 5건은 원문 `denied_actions: read_url`에 근거해 분리했다. 카카오맵 사이트 자체의 실패율로 해석할 수 없다.

Codex 도구 로그에 구글 지도 URL이 반환된 한 사례도 `Total lines: 5` 메타데이터만 있고 식당 상세 필드를 확보했다는 증거가 없었다. Antigravity 스트림은 검색/열람 요청과 `DONE`을 보여도 실제 도구 본문은 제공하지 않는다. URL·도구 완료·모델 자기 보고만으로 지도 본문 열람을 인증하지 않았다.

또한 Antigravity 구글·명동 응답은 `other_sources`라고 쓰면서 5개 추천의 `map_fields_read`에 상호·주소 등을 채웠다. 이 귀속 충돌을 표시하고 실제 지도 특징으로 사용하지 않았다.

## 어떤 식당이 자주 나왔나

| 지역 | 응답에 적힌 상호 | 같은 문자열이 나온 정상 응답 |
|---|---|---:|
| 명동 | 명동교자·하동관 | 각각 4/4 |
| 성수 | 성수다락 | 4/4 |
| 성수 | 대성갈비·소문난성수감자탕 | 각각 3/4 |
| 망원 | 헤키 | 3/5 |

이는 **다른 사이트를 근거로 한 파일럿의 상호 등장**이다. 지역별 모델 구성이 다르고, 지도별·모델별 반복이 1회뿐이다. 서로 다른 지점·별칭은 검증 없이 합치지 않았다. 소개문이 좋아서 노출됐다는 근거, 지도 자체 순위, 식당별 확정 노출률로 사용하지 않는다. 전체 문자열별 집계는 [pilot_name_appearances.csv](pilot_name_appearances.csv)에 있다.

## 지도에 실제 쓰인 정보에서 확인한 점

브라우저에서는 세 지도 모두 상세 페이지를 읽을 수 있었다. 이는 **연구자가 브라우저로 수집할 수 있다는 증거**이며 CLI가 같은 내용을 봤다는 증거는 아니다. 세 곳은 필드 수집 예시이고 본 표본·미노출 대조군이 아니다.

- **네이버 성수다락**: ‘업주’ 표시가 있는 소개문을 펼쳐 확인했다. DOM에서 읽은 소개는 공백 포함 1,962자, 대괄호 제목 5개다. 같은 표현의 반복은 `성수동 핫플` 8회, `성수 아이랑` 11회, `성수 가성비` 7회, `성수 기념일` 6회였다. 소개문 안의 숫자+원 가격은 0회였지만, 별도 메뉴 가격이 없다는 뜻은 아니다. 키워드 반복 효과는 검증하지 않았다. [지도 정보](https://m.place.naver.com/restaurant/1241532707/information).
- **카카오 오레노카츠 성수본점**: `kanana` 장소 요약과 메뉴, 가격, 역 출구·도보 안내를 확인했다. 주차 칸의 ‘무료 주차’에는 `kanana 활용` 표시가 있고 같은 페이지 블로그 미리보기에는 주차 불가가 적혀 있었다. 실제 주차 상태는 미확정으로 두고, AI 요약을 업주 작성 소개로 코딩하지 않았다. 인증 매장 표시도 모든 문구의 작성자를 보장하지 않는다. [지도 상세](https://place.map.kakao.com/2125770186).
- **구글 스케줄성수**: ‘소유자 제공’ 게시물에는 가격 7개, 주소·출구·주차 시간·예약 경로가 있었다. 1,221자의 영문 게시물이며 업주 소개문과 별도 유형으로 기록했다. 제한된 뷰에서 기본 소개문은 확인하지 못해 결측으로 유지했다. [지도 상세](https://www.google.com/maps/place/%EC%8A%A4%EC%BC%80%EC%A4%84%EC%84%B1%EC%88%98/data=!4m5!3m4!1s0x357ca54e39369d0f:0x7046e4c254ffd07a!16s%2Fg%2F11syr2z2t5!19sChIJD502OU6lfDURetD_VMLkRnA!20s8Q99G3V4%2BQ5M?authuser=0&hl=ko&g_ep=EgoyMDI2MTAxMy4wIJJjKgBIAVAD&rclk=1).

따라서 ‘지도에 글이 길다’ 하나로 묶으면 업주 소개·AI 요약·게시물·리뷰가 섞인다. **작성 주체와 정보 유형을 먼저 분리하고, 구체적 사실·가격/단위·방문 안내·반복 표현을 따로 측정**해야 한다.

## 분석 방법과 다음 실행 조건

주 분석은 **규제 로지스틱 또는 반복 구조를 반영한 혼합효과 회귀**다. 소개문 길이·반복·사실 명시·필드 완성도를 주요 특징으로 두고 지역·메뉴·리뷰 규모·지도 순위 등을 함께 기록한다. XGBoost는 식당 수가 확보된 뒤 같은 브랜드 분할에서 예측력을 비교하는 보조 모형으로 쓴다. SHAP과 회귀 계수만으로 정비의 인과 효과를 주장하지 않는다.

지금은 동일한 질문을 90회로 늘리는 것보다 **CLI의 실제 지도 본문 접근을 해결하는 것**이 먼저다. 접근 경로를 확보하면 독립 후보 60곳의 필드를 먼저 고정하고 본 측정을 시작한다. 확보하지 못하면 브라우저 수집 자료를 CLI에 동일하게 제공하는 별도 통제 실험으로 작성 방식에 따른 선택을 검증할 수 있다. 그 실험은 자연 검색에서 발견되는 효과와 구분한다. 아직 이 대안은 실행하지 않았다.

가게 정보를 정비하기 전후의 실제 효과는 이후 비교 식당을 둔 개입 실험으로 확인한다. 이번에는 외부 지도 정보를 변경하지 않았다.
