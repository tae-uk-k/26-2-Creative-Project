# seelo 외부 서비스 키 발급 안내

확인: 2026-10-31 KST. 사용자 일괄 승인에 따라 발급과 서버 적용을 진행했다. 같은 키를 다시 생성하지 않는다.

| NAVER 지역 검색 | 운영 적용·실제 검색 성공. 일 20회·월 600회 제한 |

Chrome 제어와 확장 파일 접근은 복구됐다. Google 실제 콜백과 가입 대기 정보 조회까지 성공했으며 최종 가입 화면은 미배포 상태다. 카카오 아이콘 저장 오류는 남아 있지만 기본 로그인에 필수인 조건이 아니다. account_email 강제 요청을 제거하고 비즈 앱 전환 없이 실제 콜백까지 검증했다. 최신 결과는 카카오_로그인_연동검증_20261031.md를 따른다. 키를 다시 발급하거나 붙일 필요는 없다. 발급된 자격 증명은 저장소 밖 보호 파일 `C:\Users\xodnr\AppData\Local\seelo\secrets\provider-credentials-20261031.json`과 승인된 서버 설정에서 관리한다. 아래는 최초 발급 절차 참고이며 이미 완료한 단계를 다시 실행하지 않는다.
## 키 입력 위치

`C:\Users\xodnr\AppData\Local\seelo\secrets\provider-keys.pending.env`

위 파일을 메모장에서 열어 해당 항목의 `=` 오른쪽에 값을 넣고 저장한다. 키는 채팅·Git·스크린샷에 붙이지 않는다. 이 입력 파일은 자동으로 운영에 적용되지 않는다. 준비된 항목만 검사한 뒤 운영 설정에 병합한다. Google 지도 키는 이미 설정했으므로 다시 넣을 필요 없다.

## 1. OpenAI

1. [API 키 화면](https://platform.openai.com/api-keys)에 로그인/가입한다. seelo 전용 프로젝트를 사용한다.
2. `Create new secret key`에서 이름을 `seelo-prod`로 정하고 생성한다. 키를 입력 파일의 `OPENAI_API_KEY`에 저장한다.
3. [Billing](https://platform.openai.com/settings/organization/billing/overview)에서 무료 잔액·API 크레딧 혜택을 확인한다. 현재 승인에 유료 충전·자동 충전 설정은 포함되지 않는다.
4. 일부 유료 Pro·Business 구독은 API 크레딧을 연결할 수 있다. 가입 7일 이상 등 조건이 있고 같은 이메일의 본인 소유 API 조직에 연결한다. 사용자 계정의 해당 여부는 아직 확인하지 않았다.

키 발급과 호출 가능 잔액은 별개다. 모델 선택·요금표·일일 호출 예산을 설정하기 전에는 AI 워커를 켜지 않는다.

공식: [키 발급](https://developers.openai.com/api/docs/quickstart), [구독의 API 크레딧 조건](https://developers.openai.com/api/docs/guides/chatgpt-api-credits).

## 2. 카카오 지도 + 카카오 로그인

1. [카카오디벨로퍼스](https://developers.kakao.com/) 로그인 → 앱 → 앱 생성. 이름 `seelo`, 실제 운영자 정보 입력.
2. seelo의 카카오맵은 활성화하지 않는다. 첫 활성화 앱에만 무료 쿼터가 있다. 현재 계정은 기존 `복지 데드존` 앱에 무료 쿼터가 배정돼 있어 seelo 카카오맵 활성화는 보류한다. 그 앱을 변경하거나 유료 API·비즈월렛을 연결하지 않는다. seelo 카카오 로그인 설정만 별도로 진행한다.
3. `앱 → 플랫폼 키 → REST API 키`에서 서버 키와 Client secret을 확인한다. 허용 IP를 `34.64.188.249`로 설정한다.
4. 같은 키의 카카오 로그인 Redirect URI에 `https://seelo.site/api/oauth/kakao/callback`을 등록한다.
5. 로그인 ON을 확인했다. 인가 요청에서 scope를 생략해 앱의 동의항목 설정을 따른다. account_email 권한이 없어도 회원번호로 시작할 수 있으며 미제공 이메일은 별도로 입력하고 인증해야 한다. 실제 콜백까지 검증했고 최종 가입·메일 인증은 미완료다.
6. 로그인 전용 KAKAO_OAUTH_CLIENT_ID·KAKAO_OAUTH_CLIENT_SECRET은 운영 적용했다. 지도 API 사용 승인이 없는 동안 KAKAO_REST_API_KEY는 계속 비워 둔다. 비즈 앱 전환·아이콘 재업로드는 기본 로그인의 필수 단계가 아니다.

공식: [앱·키 설정](https://developers.kakao.com/docs/en/app-setting/app), [지도 활성화·무료 쿼터](https://developers.kakao.com/docs/ko/kakaomap/common), [로그인 설정](https://developers.kakao.com/docs/ko/kakaologin/prerequisite).

## 3. 네이버 지역 검색

현재 백엔드는 **NAVER Cloud API HUB** 인증을 사용한다. 구형 개발자센터 Client ID/Secret과 혼용하지 않는다.

1. [네이버 클라우드 콘솔](https://console.ncloud.com/)에 로그인/가입한다.
2. `All Services → Application Services → NAVER API HUB → Subscription`에서 서비스 이용 신청 안내와 지역 검색의 요금 안내를 확인한다. 개인정보 제공·약관 동의는 실제 안내를 읽고 진행한다.
3. **공식 요금 탭에서 검색 API 0~775,000건 0원, 일 최대 25,000건 제한을 확인했다.** 최초 설정은 무료 범위 안에서 낮은 일·월 한도를 적용한다. 요금 정책이 변경되면 재확인하며 GCP 크레딧을 네이버 요금에 사용할 수는 없다.
4. 이용 조건이 확인되면 `Application → Application 등록 → NAVER 검색: 지역`만 선택, 이름 `seelo-prod`로 등록한다.
5. 인증 정보의 Client ID를 `NAVER_API_KEY_ID`, Client Secret을 `NAVER_API_KEY`에 저장한다. 사용 전 일·월 호출 한도를 낮게 설정한다.

공식: [신청·발급·사용 한도](https://guide.ncloud-docs.com/docs/apihub-application), [상품·요금 안내](https://www.ncloud.com/product/applicationService/naverApiHub).

## 4. Google 소셜 로그인

1. [seelo 프로젝트의 Google Auth Platform](https://console.cloud.google.com/auth/overview?project=seelo-prod-20261030)을 연다. 프로젝트 ID가 `seelo-prod-20261030`인지 확인한다.
2. Branding의 앱 이름 `seelo`, 지원 이메일·개발자 연락처는 현재 운영자 Gmail을 사용한다. 공개되지 않은 개인정보처리방침·이용약관 주소를 임의로 등록하지 않는다.
3. 외부 사용자용 테스트 상태로 준비하고 운영자 Gmail을 테스트 사용자에 등록한다. 아직 공개 게시·전체 사용자 로그인 성공을 의미하지 않는다.
4. Clients → Create client → Web application → 이름 `seelo-prod-web`. 승인된 Redirect URI에 `https://seelo.site/api/oauth/google/callback`을 등록한다.
5. Client ID를 `GOOGLE_OAUTH_CLIENT_ID`, Client secret을 `GOOGLE_OAUTH_CLIENT_SECRET`에 저장한다. 백엔드 요청 범위는 `openid email profile`이다.

공식: [Google OpenID Connect 설정](https://developers.google.com/identity/openid-connect/openid-connect).

## Gemini와 실행 전 조건(아래는 기존 API 경로 검토, 현재는 로컬 CLI 시험)

현재 Codex는 서버→PC 로컬 CLI 호출·웹 검색을 실제 검증했다. Gemini 개인 CLI 인증은 Google에서 차단돼 모델을 비워 두었으며 키/과금 경로로 자동 전환하지 않는다. `DAILY_COST_LIMIT_USD=0`은 기존 API 코드상 무제한이다. 현재 상태·실제 승인 시험 메일 10통·남은 사항은 [로컬 CLI 작업 기록](로컬CLI_AI_연동진행_20261031.md)을 따른다. 아래 미호출/미설정 수치는 당시 기록이며 최신 상태를 뜻하지 않는다.

- 현재 백엔드는 Gemini Developer API 키 방식만 지원한다. 설정·모델 값은 비어 있다.
- 2026년 3월 이후 Google Cloud 체험 크레딧은 Gemini Developer API/AI Studio 사용료에 적용되지 않는다. 기존 GCP 프로젝트를 연결하면 무료로 처리된다고 가정하지 않는다.
- Gemini Developer API의 계정별 무료 티어를 별도로 쓰거나, full Vertex AI 인증을 지원하도록 어댑터를 확장해야 한다. 아직 어느 경로도 실제 연결·호출하지 않았다. Express mode도 일반 GCP 무료 프로그램과 구분해야 한다.
- GCP 크레딧 사용 경로로는 full Vertex AI를 우선 검토한다. 현재 VM에는 서비스 계정이 없어 전용 최소 권한 인증과 코드 설정·검증이 남아 있다. 개인 gcloud 로그인 토큰을 운영 서버에 복사하지 않는다.
- 일일 AI 예산은 0, 실제 AI 호출·메일 발송은 0건이다. 키 입력만으로 유료 호출·자동 지도 정비·메일 발송을 시작하지 않는다.

공식: [Gemini 결제](https://ai.google.dev/gemini-api/docs/billing), [Vertex 인증](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/api-keys), [Express mode 구분](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/express-mode/overview).
