## 명세서·구현계획과 다르게 한 것

| 무엇 | 이유 | 문서 반영 |
|---|---|---|
| OAuth를 Authlib Starlette 통합 대신 `Clients.oauth` 어댑터로(state는 직접 비교, 사용자 정보는 userinfo 주소) | 가짜 모드·테스트에서 제공자를 바꾸려고. 구글 id_token 서명 검증 대신 TLS로 구글에서 직접 받음 | 05 5.1, 14 3장 |
| 의미 없는 메일 티켓의 mail-status는 `sent` | 가입 여부를 드러내지 않으려고(05 4.3 "같은 응답"을 상태 조회까지) | 05 4.3 |
| 재설정 메일을 새로 보내면 이전 링크를 막음 | 마지막 메일의 링크만 유효(보안 강화) | 05 7장 |
| 요청 제한 횟수는 결과와 상관없이 바로 커밋 | 409·422로 끝난 요청도 세려고 | 코드 주석 |
| `PendingCompleteResponse`는 없는 값(`user`·`mailTicket`)을 빼고 응답 | 04 4장 형태(`{next, user}` 또는 `{next, mailTicket}`) 그대로 | — |
| 로그인 상태에서 `/api/auth/csrf`는 세션에 묶인 값을 유지(잃었으면 새로 묶음) | 화면이 페이지마다 불러도 CSRF가 깨지지 않게 | 코드 주석 |
| OAuth 클라이언트는 `integrations/http.py`의 `make_client` 대신 Authlib `AsyncOAuth2Client`(httpx, 10초) | 토큰 요청 형식을 Authlib에 맡기려고(`http.py`는 아직 없음) | 05 5.1 |

## 확인한 사실

- 구글 OIDC 주소: https://accounts.google.com/.well-known/openid-configuration (2026-10-27 조회) — 인가·토큰·userinfo 주소, `client_secret_post` 지원, `email_verified` 클레임.
- email-validator 2.3.0 `SPECIAL_USE_DOMAIN_NAMES` = arpa, invalid, local, localhost, onion, test.
- nginx `try_files`로 `/index.html`에 넘어간 요청은 `$uri`가 `/index.html`로 기록돼 화면 경로의 토큰이 로그에 남지 않는다.
