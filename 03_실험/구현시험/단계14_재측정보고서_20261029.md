- `docker compose --profile dev up -d --build`, `FAKE_EXTERNALS=true`, `AUTO_FIX_ENABLED=false`.
- 확인 스크립트: 저장소 밖 `%TEMP%/seelo-remaining-20261029/stage14_flow.py`. `.env` 수정 없음, 시드 비밀번호는 `scripts.seed_demo.DEMO_PASSWORD`를 import하며 출력하지 않았다.
- 첫 흐름: store 14 / 신청 6 / 진단 13 / 재측정 14 / 보고서 1. 칸을 모두 제외한 경우도 완료.
- 두 번째 흐름: store 15 / 신청 7 / 진단 15 / 재측정 16 / 보고서 2. 편의 정보 1칸 승인 → 관리자 수동 완료 → 즉시 재측정 → report_ready.
- DB 확인: `compareFixValues`는 **plan 큐 succeeded**, `generateComparisonReport`는 **report 큐 succeeded**. 작업 인자는 정수 ID만.
- 보고서 2: completed, version 1, interval_days 0, generation_attempts 1. 예약 started·admin, `earlyRemeasure=true`, 같은 질문 3개.
- `fix_logs`: attributes의 before_value는 비어 있음, remeasure_match unknown. 보고서의 beforeValue는 "확인하지 못함". 모르는 값을 채우지 않았다.
- `email_logs`: `report_ready:2` 1행 sent, Mailpit 전달. 실제 SMTP 수신 증거는 아니다.
- 원래 수동 모드·정비 워커 없음 유지. 데이터·볼륨 삭제 없음.
