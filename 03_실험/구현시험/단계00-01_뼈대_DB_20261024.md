## 명세서·구현계획과 다르게 한 것

| 무엇 | 이유 | 문서 반영 |
|---|---|---|
| 모델 도우미 `created_at()` → `created_col()` | 컬럼 이름과 같으면 클래스 안에서 가려져 `TypeError` | 13 10장 고침 |
| `Settings` env 파일을 `("../.env", ".env")`로 | Compose와 로컬 실행이 같은 `.env`를 쓰게 | 13 1장 고침 |
| `.env.example`의 DB 주소를 `localhost`로 | 로컬 실행용. 컨테이너는 Compose가 `db`로 덮어씀 | 16 4장 고침 |
| `create_app(with_queue=False)` 인자 추가 | 테스트에서 작업 큐 연결 없이 앱을 띄우려고 | 코드 주석 |
| `seelo.main:app`을 첫 접근 때 만듦(모듈 `__getattr__`) | import만 해도 설정을 읽지 않게 | 코드 주석 |
| testcontainers 경로 `testcontainers.community.postgres` | 옛 경로 폐지 예정 경고 | 11 2장 고침 |
| `MAIL_TOKEN_FERNET_KEY` 기본값 빈 문자열 | 메일은 2단계부터라 0단계 실행을 막지 않게. 2단계에서 필수 검사 추가 | — |
| 라우터는 health만 연결 | 나머지 라우터는 해당 단계에서 더한다(`api/router.py`의 `ROUTERS`) | — |

## 확인한 사실

- SQLAlchemy 2.1.6에서 `get_raw_connection().driver_connection`이 psycopg `AsyncConnection`(06 3장의 같은 트랜잭션 작업 등록에 필요) → 06 3장에 반영.
- Procrastinate 3.10.0의 `run_worker_async`, `schema_manager.apply_schema_async`, `get_stalled_jobs`, `retry_job`, `cancel_job_by_id_async` 시그니처가 06 문서와 같음.
