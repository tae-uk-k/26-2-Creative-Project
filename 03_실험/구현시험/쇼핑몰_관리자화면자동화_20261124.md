# 쇼핑몰 관리자 화면 자동화 구현 시험

검증일: 2026-11-24. 로컬 코드·테스트 PostgreSQL·합성 HTML 회귀와 실제 스마트스토어·카페24의 브라우저 저장 검증을 구분해 기록한다. 두 플랫폼의 실계정 본문 수정·공개 반영·복구도 완료했다.

## 변경

- 기본 수정 방식을 `COMMERCE_EDIT_MODE=browser`로 정했다. 관리자 위임이 확인된 몰을 대상으로 동작한다.
- 플랫폼 API 토큰 없이 관리자 화면 원본을 수집하고, 기존 승인·저장·재조회·복구 경로를 이용한다.
- 브라우저 원본·수정은 `browser`로 구분한다. API 연결 상태를 인증·쓰기 검증 완료로 바꾸지 않는다.
- 관리 화면의 HTTPS 도메인·몰 식별값·상품번호·원본 해시를 검사한다. 보호할 설정은 저장 전에 대조한다.
- 저장 완료 표시를 기다린 뒤 재조회한다. 불명확한 저장을 재전송하지 않는다.
- 프런트엔드에서 관리자 위임 확인 후 원본 수집을 실행할 수 있다. API 인증 버튼은 브라우저 모드의 필수 절차로 표시하지 않는다.
- 기존 지도 브라우저 세션을 재사용하고 몰별 전용 프로필과 담당자 로그인 도구를 추가했다.

## 검증

| 검사 | 결과 | 범위 |
|---|---|---|
| 백엔드 집중 시험 | **86 통과** | 쇼핑몰 규칙·API·브라우저, PostgreSQL 쇼핑몰 통합, 기존 지도 브라우저 회귀 |
| 신규 실제 Chromium 화면 시험 | 위 86개에 포함 | 합성 HTML에서 두 플랫폼별 입력·저장·재조회·복구, 가격 변경 충돌·다른 상품번호·보안 화면 차단 |
| 신규 PostgreSQL 위임 경로 시험 | 위 86개에 포함 | API 미연결·토큰 없음 상태에서 위임 확인 → 수집 → 승인 → 저장 → 복구 |
| 프런트엔드 | **52 통과** | 브라우저 원본·관리자 위임으로 실행 허용, 권한 회수 시 차단 등 |
| 백엔드 요청 계약 | **10개 통과** | 기존 프런트엔드 요청과 Pydantic 계약 |
| TypeScript·프런트엔드 빌드 | 통과 | `npm run build`, `npm run typecheck` |
| 정적 검사 | 통과 | 변경한 Python의 ruff, Git 공백 검사 |
| OpenAPI | 현재 파일과 일치 | `scripts/export_openapi.py --check` |

백엔드 실행:

```powershell
$env:TEST_PG_PORT='55443'
uv run --group browser pytest tests/unit/test_commerce_browser.py tests/unit/test_commerce.py tests/unit/test_commerce_api.py tests/unit/test_browser_skeleton.py tests/integration/test_commerce.py tests/integration/test_browser_google.py tests/integration/test_browser_kakao.py -q --tb=short
```

처음에는 Playwright용 Chromium이 없어 화면 시험이 실패했다. 공식 배포본을 설치한 뒤 다시 실행했다. 기존 지도 회귀의 DB 시험 1개는 Docker 미기동으로 실패했다. Docker 기동 후 위 75개 집중 시험을 다시 실행해 모두 통과했다. 과거 전체 회귀 955개 결과를 이번 결과에 합산하지 않는다.

## 실계정 결과와 남은 범위

- 실제 화면에서 두 플랫폼의 YAML을 구성했다. 새 `BrowserProduct` 코드로 본문 입력·저장·새 브라우저 재조회·공개 반영·복구를 확인했다.
- 카페24 샘플상품 9번과 스마트스토어 아카시아 벌꿀 원상품 13821774578번을 사용했다. 검증 문구는 모두 제거했다. 가격·재고·판매·구매 제한은 유지했다.
- 카페24 Froala의 코드 보기·전체 선택·줄바꿈 변동, Windows 이벤트 루프, 전용 로그인 세션 유지 문제를 보완했다. 관련 회귀를 추가해 최종 집중 시험 **86개가 통과**했다.
- 실계정 증거와 단계별 JSON·공개 화면은 [검증 결과](../쇼핑몰_관리자화면_실계정검증_20261124/검증결과.md)에 있다.
- 대표 계정으로 검증했다. 별도 고객의 대행사 매니저·부운영자 권한 검증과 스마트에디터 ONE·속성 편집은 남아 있다.
- 운영 서버 배포와 운영 DB 변경은 하지 않았다.
