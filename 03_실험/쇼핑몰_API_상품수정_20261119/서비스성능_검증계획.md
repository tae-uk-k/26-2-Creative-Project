# 예시 쇼핑몰을 이용한 seelo 성능 검증

최신 계획: 2026-11-24 수박씨·사차인치 2종을 네이버·카페24에 등록한 상태를 기준으로 [AI 노출 전후 비교 실험계획](../쇼핑몰_AI노출_전후비교_20261124/실험계획.md)을 작성했다. 현재 파일의 벌꿀 고정 질문과 2026-11-19 보류 상태는 당시 기록이다. 새 실험은 [고정질문 v3](../쇼핑몰_AI노출_전후비교_20261124/고정질문.json)를 사용한다. 아직 노출 측정과 GEO 정비는 실행하지 않았다.

기준일: 2026-11-19. 목표는 **소비자가 실제로 볼 수 있는 예시 쇼핑몰에서 seelo 적용 전후의 결과를 비교하는 것**이다.
API 쓰기 성공만으로 이 목표를 완료 처리하지 않는다. 현재는 네이버부터 진행한다. 카페24 보류는 유지한다.

2026-11-23 후속 구성: 공개 상품은 벌꿀·볶은 귀리분말·볶은 서리태분말 총 3종이다. 사용자 요청으로 실험용 표시를 제거하고 사진·본문·SEO를 정리했다. [상품 3종 기록](상품3종_20261123/실행결과.md)을 최신 기준선으로 사용한다. 이전 A/B 본문·상품기준·고정 질문의 이름·원산지·제조원 기대답은 이 변경 전에 정한 자료이므로 후속 측정 전에 새 구성에 맞게 버전을 올린다. 이번 상품 제작을 seelo AI의 자동 정비 성능 결과로 집계하지 않는다.

## 공개 상태 수정

2026-11-19에는 품절·재고 0·전시중으로 보관했다. 2026-11-23 사용자 승인 후 **SALE + 재고 1개 + 최소 구매수량 2개 + 전시중**으로 변경했다. 1회·1인 최대수량은 각각 2개다. 네이버쇼핑 등록 설정은 true다.
정상 구매자 UI에서 1개는 최소수량, 2개는 재고 부족으로 차단됐다. 공개 Product 구조화 데이터는 InStock이다. 실제 결제와 별도 주문 API 호출은 하지 않았다.
공개 화면 검사는 PC·390×844 모바일 크기·비로그인 접근을 포함했다. 실기기·앱 검사와 구분한다.

공식 근거: [판매·전시 상태별 노출](https://help.sell.smartstore.naver.com/faq/content.help?faqId=17567), [상품 상태·재고 명세](https://apicenter.commerce.naver.com/docs/commerce-api/current/create-product-product).

추가 조사: [네이버 무주문 노출 실험 대안](네이버_무주문_노출실험_대안조사.md). 최신 증거는 [11월 23일 실행 결과](무주문환경_실행결과_20261123.md)에 저장했다. 이미지 안내와 주문 후 취소는 주문 차단 방식으로 선택하지 않았다.

## 실행 순서

1. **공개 접근을 먼저 확인한다.** 스토어 홈, 전체상품 목록, 상품 직접 주소, 상세본문, 품절 표시를 확인한다. 관리자 미리보기는 이 단계의 완료 증거가 아니다.
2. **원자료와 기준선을 고정한다.** 등록일·공개일·본문 해시·이미지·가격·재고·상품 상태를 저장한다. 예시 상품 사양은 실험용 기준임을 명시한다.
3. **수정 전 측정을 실행한다.** 아래 세 종류의 질문을 분리한다. 모델이 페이지를 읽지 못한 실행은 접근 실패로 기록한다.
4. **seelo로 정비한다.** 기존 수작업 B안을 AI 결과로 재사용하지 않는다. 실제 사용한 모델·자료·정비안 ID·변경 필드·승인 범위를 기록한다.
5. **공개 반영을 검증한다.** 재조회에서 새 값이 같고 공개 페이지에서도 같은 내용이 보여야 수정 후 측정을 시작한다.
6. **수정 후 같은 조건으로 측정한다.** 모델·질문·검색 사용·새 대화·언어·반복 수를 맞춘다. 원문과 출처를 보관한다.
7. **비교 결과를 보고한다.** 질문별 사실 정답률, 근거 없는 사양, 조건 적합성, URL 인용, 자연 추천 등장 여부를 각각 계산한다.

## 측정 구분

| 종류 | 모델에 주는 정보 | 측정할 것 | 이 결과로 말할 수 있는 범위 |
|---|---|---|---|
| 페이지 접근 | 상품 URL | 본문 열람·이미지 정보 추출·판매상태 확인 | 페이지를 읽고 이해할 수 있는지 |
| 정보 이해 통제 실험 | 수정 전 또는 후 본문만 제공 | 누락 사실 보완·질문 정답·허위 사양 | 제공된 자료에서의 판단 차이 |
| 자연 추천 | 브랜드·스토어명·URL 없이 구매 조건만 질문 | 추천 등장·출처·조건 적합성 | 실제 검색 환경의 관찰 결과 |

본문을 프롬프트에 넣어 준 실행을 자연 발견으로 집계하지 않는다. 상품 URL을 지정한 조회도 자연 추천으로 집계하지 않는다.
CLI·API 결과와 소비자용 ChatGPT·Gemini 앱 결과는 별도 집계한다.

## 초기 표본

- 공개 여부 확인은 현재 벌꿀 1개로 진행한다.
- 정보 이해 파일럿은 수정 전후 각각 12개 질문을 같은 모델에서 3회 반복한다. 총 72회다. 질문별 3회는 모델 변동 확인용이며 36개 독립 상품을 뜻하지 않는다.
- 자연 추천 파일럿은 조건 질문 6개를 모델별 3회 반복한다. ChatGPT·Gemini를 모두 실행하면 한 시점에 36회다. 페이지 공개·수집 여부를 먼저 확인한다.
- 비교 상품을 확보하면 정비군과 유지군을 같은 기준으로 선정한다. 이 문서의 반복 수는 파일럿 운영안이며 효과 검출에 필요한 확정 표본 수가 아니다.

## 현재 예시몰로 가능한 검사와 남은 준비

현재 상품으로 공개 화면·정보 이해·API 연동을 검사한다. 주문을 막으므로 실제 구매 전환은 측정하지 않는다.
네이버쇼핑 등록 설정 true와 실제 검색 수집을 구분한다. 이번 외부 검색에서는 상품이 확인되지 않았다. 검색 색인과 자연 발견 기준선은 아직 확보하지 못했다.
원자료는 가상 기준으로 유지한다. 제조사·인증·영양 수치를 만들어 넣지 않는다. 정상 UI 경로의 차단 결과를 모든 주문 호출 방식의 검증으로 확대하지 않는다.

## 실패 기록

2026-11-19 공개 페이지 HTTP 조회는 상품·스토어 모두 429를 반환했다. 이는 해당 조회 경로의 접근 실패다. 상품 비공개나 추천 실패로 판정하지 않는다.
현 세션의 브라우저 연결도 사용 불가로 보고됐다. 공개 화면 검증은 별도 상태로 남긴다. API 설정 변경 완료를 공개 확인 완료로 바꾸지 않는다.

2026-11-23에는 브라우저 연결을 확보하여 위 공개 상품 검사를 진행했다. 11월 19일 접근 실패는 과거 기록으로 보존한다. 11월 23일 외부 검색 도구의 직접 열기는 여전히 접근 실패였고 정확한 상품명 검색 결과도 없었다. 브라우저 열람 성공과 검색 수집 확인을 구분한다.
