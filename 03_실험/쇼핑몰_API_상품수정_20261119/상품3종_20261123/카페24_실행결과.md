- 스마트스토어와 동일한 패키지 사진·활용 사진·상세 HTML을 적용했다.

- 상품명·가격·요약·간략설명·페이지 제목·메타 설명·이미지 대체문구를 입력했다.

- 공개 상품명·본문에 실험용 문구를 넣지 않았다.

상품 구성과 이미지는 사용자 승인으로 만든 예시몰 자료다. 실물 제조 자료와 구분해 [상품 구성](상품구성.json)에 기록했다.

## AI 조회와 화면 검증

AI WebMCP 상품 검색에서 신규 3종이 조회됐다. 상품 상세 조회에서 이름·가격·사진과 `display=T`, `selling=T`를 확인했다. 구매자 상품 페이지의 본문은 일반 HTML 텍스트로 읽혔다.

PC 상품 목록과 모바일 390×844 상세 화면을 확인했다. 세 상세페이지의 패키지·활용 사진 6장이 모두 로드됐다. 모바일 페이지 폭은 375px로 가로 넘침이 없었다. 플랫폼 지연 로딩 때문에 스크롤 전 이미지는 1px 대체 이미지로 보일 수 있다. 스크롤 후 원본 너비 1254px·1536px을 확인했다.

스토어 기본 디자인의 Samplemall 로고와 기존 홈 배너는 남아 있다. 이번 작업 범위는 상품 등록·상세페이지·분류·구매 제한이다.
