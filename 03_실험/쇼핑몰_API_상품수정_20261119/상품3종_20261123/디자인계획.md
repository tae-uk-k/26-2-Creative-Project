# seelo 식품 3종 상세페이지

종류: 스마트스토어의 식품 상품 상세본문. 네이버의 외곽 화면·장바구니·구매 기능은 그대로 사용한다.

크림색 바탕·짙은 올리브 글자·절제된 제품 사진으로 세 상품을 통일한다. 별도 폰트 로딩 없이 모바일 기본 한글 서체를 사용한다.
Taste Skill은 글자 크기·간격·위계·정렬·이미지 품질 검사에 적용한다. 기존 플랫폼의 HTML 영역이므로 독립 사이트용 메뉴·효과·모션·스택·무작위 팔레트는 추가하지 않는다.

1. 상품명·용량·짧은 소개를 먼저 보여준다.
2. 새로운 대표 패키지 사진을 크게 배치한다.
3. 식탁에서 사용하는 장면과 세 가지 활용법을 보여준다.
4. 용량·구성·원재료를 항목별 HTML 목록으로 제공한다. 네이버 모바일의 이미지 변환을 피하기 위해 table 태그는 사용하지 않는다.
5. 보관과 섭취 안내를 짧게 쓴다.
6. 제조원·원산지·제조일·소비기한 등 확인되지 않은 항목은 확인 전 상태로 유지한다. 수치·인증·제조사·후기를 만들지 않는다.

사용자 요청에 따라 공개 상품명·사진·본문에서 실험용·가상 상품 문구를 제거한다. 이미지와 상품 구성의 생성 근거는 이 작업 폴더에 보관한다.
사진은 기본 image_gen 도구로 생성한 패키지 및 활용 이미지다. 실제 제조사의 촬영 원본으로 기록하지 않는다.
재고 1개·최소 2개·최대 2개 조합을 보존하며 상품별 정상 구매 경로를 확인한다.
