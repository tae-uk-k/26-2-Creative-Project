## 실험에서 확인한 차이

1. **화면 상품번호와 API 원상품번호는 다르다.** UI의 13883527217은 채널번호다. 목록 API가 돌려준 원상품번호 13821774578을 원상품 수정 경로에 사용했다.
2. **원상품 상세 응답은 원상품번호를 본문에 포함하지 않았다.** 목록 조회에서 확인한 매핑과 요청 URL, 정확한 상품명으로 대상을 고정했다.
3. **HTML은 저장 후 표기가 바뀐다.** 작은따옴표가 `&#39;`로 바뀌고 표 내부 들여쓰기가 제거됐다. 원문 해시 비교만으로 저장 실패를 판정하면 안 된다. 글자·태그·속성을 대조하고 실제 화면을 확인했다.
4. **상세이미지는 HTTPS CDN 주소를 사용해야 했다.** 대표이미지 입력값의 `shop1.phinf.naver.net`을 HTTPS로만 바꾸면 깨졌다. 편집기에 표시된 실제 이미지의 `shop-phinf.pstatic.net` 주소로 수정했다. 최종 미리보기에서 원본 1254×1254 이미지 로딩을 확인했다.
5. **초기 재고 0 등록은 거부됐다.** 처음부터 판매대기·전시중지로 등록했다. 이후 판매 상태 API로 SUSPENSION을 적용하고 원상품 PUT으로 재고 0을 설정했다. 판매 중 상태로 전환하지 않았다.

첫 실행(`20261119T071334_062025`)은 본문 저장 후 문자열 차이를 탐지했다. 초기 이미지 주소도 PC 미리보기에서 깨졌다. 해당 실행을 복구하고 이미지 주소와 비교 기준을 수정한 뒤 최종 실행을 다시 진행했다. 초기 기록도 보존했다.

## 다시 실행하기

작업 폴더는 이 문서가 있는 폴더다. Python은 프로젝트 백엔드의 가상환경을 사용한다.

```powershell
$seeloPython = '..\..\04_MVP\seelo\backend\.venv\Scripts\python.exe'
& $seeloPython api_experiment.py naver-token
& $seeloPython api_experiment.py prepare smartstore 13821774578
```

`prepare`가 출력한 실행 폴더를 아래 인자로 넣는다. 쓰기 전에 해당 실행의 `plan.json`에서 원본과 변경안을 확인한다.

```powershell
& $seeloPython api_experiment.py apply '.local\runs\실행폴더'
& $seeloPython api_experiment.py verify '.local\runs\실행폴더'
& $seeloPython api_experiment.py rollback '.local\runs\실행폴더'
```

이 스크립트는 상품번호·상품명·비판매 상태를 검사한다. 가격·재고·옵션·배송을 정비 대상으로 받지 않는다. 현재 값이 실험 적용 결과와 다르면 복구를 차단한다. 쓰기 응답이 불명확하면 자동 반복하지 않는다.
2026-11-23 현재 무주문 설정은 이 스크립트의 재고 0 보호 조건과 다르므로 위 재실행 명령은 중단된다. 후속 본문 자동 실험 전에 보호 조건을 현재 설정에 맞게 갱신한다.
키·토큰·원본 응답은 `.local/`에 저장했다. Git에서 제외했고 Windows 접근 권한을 현재 사용자와 SYSTEM으로 제한했다. 공개 문서나 커밋에 복사하지 않는다.
