# 스마트스토어 무주문 실험 환경 적용 결과

실행일: 2026-11-23. 사용자 승인 후 기존 가상 벌꿀 상품에 적용했다.

후속 사용자 지시로 공개 실험용 표시를 제거하고 상품을 총 3종으로 늘렸다. 최신 이름·사진·본문·검증은 [상품 3종 실행 결과](상품3종_20261123/실행결과.md)를 따른다. 아래는 무주문 환경을 처음 적용했을 때의 기록이다.

네이버 기본 품절·재입고 문구가 사라졌고 구매 버튼이 표시됐다.
실험용 상품명·이미지·본문 안내는 유지했다. 상품명·가격·본문·이미지·원자료를 바꾸지 않았다.
허용한 상태·재고·구매수량·전시·네이버쇼핑 등록 외 전체 API 필드는 원본과 일치했다.

## 구매자 화면 검사

Chrome의 기존 로그인 세션에서 검사했다. 모바일 검사는 같은 브라우저를 390×844로 설정한 반응형 화면 검사다. 실제 휴대전화·네이버 앱 검사가 아니다.

| 경로 | 입력 | 관찰 결과 |
|---|---|---|
| PC 구매하기 | 2개 | “재고가 부족합니다. 1개 이하로 구매해주세요.” 경고. 상품 페이지에 머무름 |
| PC 구매하기 | 1개 | “2개 이상부터 구매하실 수 있습니다.” 경고. 상품 페이지에 머무름 |
| PC 장바구니 | 2개 | 재고 부족 경고. 장바구니 담기 완료 안내 없음 |
| PC 장바구니 | 1개 | 최소 2개 경고 |
| PC 선물하기 | 2개 | 재고 부족 경고. 상품 페이지에 머무름 |
| 모바일 바로구매 | 2개 | 재고 부족 경고 |
| 모바일 장바구니 | 2개 | 재고 부족 경고 |
| 모바일 바로구매 | 1개 | 최소 2개 경고 |
| 비로그인 공개 접근 | 상품 URL | 별도 세션에서 로그인 링크와 상품·수량·가격·구매 버튼 확인 |
| 비로그인 구매하기 | 2개 | 로그인 필요 안내. 로그인 진행·인증은 하지 않음 |

실제 주문·결제를 실행하지 않았다. 확인한 것은 정상 구매자 UI 경로의 차단이다. 별도 주문 API 직접 호출·기존 장바구니·실기기·앱 경로는 검사하지 않았다.
브라우저 경고창 이후 연결이 지연되는 경우 새 검사 탭으로 이어갔다. 마지막 검사 후 모바일 크기 설정을 해제했다.

## AI 접근·수집 확인

브라우저에서 공개 상품의 제목·이미지·본문·가격을 읽었다. 비로그인 접근도 확인했다.
DOM의 `application/ld+json`에서 Product와 InStock을 확인했다. 일반 품절 상태로 제공되던 신호와 구분한다.
메타 설명은 기존 값 `[seelo] 미정`이다. 이번 작업에서는 본문이나 메타 설명을 정비하지 않았다.

외부 검색 도구의 `"seelo" "아카시아 벌꿀"` 검색에는 결과가 없었다. 같은 도구의 상품 URL 직접 열기도 접근 실패였다.
이 도구의 접근 실패를 상품 비공개로 판정하지 않는다. 검색 색인 반영·URL 없는 자연 발견·seelo 적용 전후 추천 성능은 아직 측정하지 않았다.
