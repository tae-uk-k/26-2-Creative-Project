# seelo

seelo는 온라인에 흩어진 정보를 조사하고 실제 페이지를 정비하는 서비스입니다.

**현재 진행할 쇼핑몰 대상은 스마트스토어·카페24 두 곳입니다.** 가입, 관리자 권한, 상품 정비의 기준은 [쇼핑몰 진행 지침](02_조사/쇼핑몰_타깃플랫폼과_수정수행방식_20261117.md)에서 확인합니다. 이 범위는 2026-11-18 사용자 결정입니다.

Google 지도·카카오맵의 기존 베타 기획과 구현 기록은 별도로 남아 있습니다. 이 기록을 쇼핑몰의 구현 완료 상태로 사용하지 않습니다.

쇼핑몰 작업은 **[쇼핑몰 진행 지침](02_조사/쇼핑몰_타깃플랫폼과_수정수행방식_20261117.md)**부터 읽으세요. 기존 지도 기획은 [서비스 기획서](01_기획/서비스기획서.md)에서 확인합니다.
