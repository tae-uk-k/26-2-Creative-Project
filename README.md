# seelo

seelo는 여러 플랫폼의 가게 정보를 정리하고, AI가 가게를 이해해 관광객의 조건에 맞춰 찾을 수 있도록 돕는 서비스입니다. 현재 베타는 Google 지도·카카오맵 정비와 ChatGPT·Gemini의 정비 전후 측정으로 시작합니다.
