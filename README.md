# seelo

seelo는 스마트스토어·카페24 판매자의 상품 상세페이지를 AI가 정확히 이해하도록 정비하는 서비스다. AI가 같은 상품의 자료를 먼저 조사해 정비안을 만들고, 판매자가 승인한 항목만 위임받은 관리자 화면에서 수정한다. 정비 전후의 AI 노출은 같은 조건으로 측정한다.

| 결정 | 날짜 |
|---|---|
| 대상 플랫폼은 스마트스토어·카페24 두 곳만 진행한다. | 2026-11-18 |
| 기본 수정 방식은 관리자 위임 → 관리자 화면 브라우저 자동화다. | 2026-11-24 |

처음 읽는다면 **[서비스 기획서](01_기획/서비스기획서.md)**부터 읽는다. 가입·권한·API 절차는 [쇼핑몰 진행 지침](02_조사/쇼핑몰_타깃플랫폼과_수정수행방식_20261117.md)을 따른다.
