# 식당 AI 추천 노출 선행조사

- 조사 기준일: 2026-10-01
- 연구 대상: 한국 식당, 특히 외국인 관광객이 ChatGPT·Gemini·네이버 AI에 장소를 물어보는 상황
- 조사 범위: 학술 연구, 플랫폼 공식 문서, 국내외 산업 조사, 경쟁 서비스
- 제외 범위: 인터뷰, 실제 식당 정보 수정, 개입 실험

## 1. 조사 방법과 검수 기준

학술 연구, 공식 플랫폼 자료, 산업 사례를 분리해 수집한 뒤 다음 기준으로 검수했다.

1. 논문·공식 문서를 업체 블로그보다 우선했다.
2. 표본, 질문 수, 모델, 지역, 반복 횟수가 확인되지 않는 수치는 낮은 등급으로 분류했다.
3. `상관관계`, `통제된 인과효과`, `업체 주장`을 구분했다.
4. 웹페이지가 검색·인용되는 것과 식당이 추천되는 것을 구분했다.
5. 단일 응답이 아니라 모델·질문 표현·시점에 따른 변동성을 확인했다.
6. 한국에 직접 적용할 수 있는 근거와 해외 결과를 분리했다.

### 근거 등급

| 등급 | 기준 |
|---|---|
| A | 동료심사 학회·학술지 또는 플랫폼 공식 문서 |
| B | 방법과 표본이 공개된 학술 프리프린트 |
| C | 방법 일부가 공개된 업체 자체 조사 |
| D | 대행사 성공 사례, 홍보성 주장, 재현 정보 부족 |

## 2. 먼저 나온 결론

### 확인된 사실

1. **식당 AI 노출은 하나의 순위가 아니다.** 검색 활성화, 크롤링·색인, 후보 검색, 답변 포함, 답변 내 순서, 인용, 정보 정확도, 방문 전환은 서로 다른 단계다.
2. **검색·지도에서 읽을 수 있는 정확한 정보가 기본 조건이다.** OpenAI, Google, Bing, 네이버, Anthropic, Perplexity 모두 접근 가능한 공개 정보와 최신 데이터의 중요성을 공식적으로 설명한다.
3. **식당을 직접 조사한 연구에서는 웹사이트, 가격 정보, 리뷰량, 제3자 언급이 추천 진입과 연관됐다.** 하지만 정보 수정 후 추천이 증가한다는 인과효과는 아직 확인되지 않았다.
4. **별점과 리뷰 수의 역할은 같지 않다.** 최신 발리 연구에서는 별점은 추천 진입보다 이미 추천된 식당의 상위 배치와 관련됐고, 리뷰 수는 추천 진입과 관련됐다.
5. **AI마다 결과가 다르고 같은 질문도 결과가 흔들린다.** 따라서 한 번 물어본 결과는 노출 성과로 사용할 수 없다.
6. **네이버는 한국 식당에 직접적인 별도 경로다.** 플레이스 에이전트와 AI 롱테일 검색은 스마트플레이스 정보, 메뉴, 방문자 리뷰, 블로그 후기, 예약 가능 정보를 활용한다고 공식 발표했다.

### 아직 확인되지 않은 주장

- 영문 소개를 추가하면 ChatGPT·Gemini 추천률이 오른다.
- `Restaurant` 구조화 데이터를 넣으면 AI 추천 순위가 오른다.
- Google·네이버·Instagram의 문구를 완전히 동일하게 맞추면 AI 노출이 오른다.
- `llms.txt`를 만들면 AI 노출이 오른다.
- 특정 리뷰 수 또는 별점 문턱을 넘으면 반드시 추천된다.
- 웹사이트 정보 정비가 실제 방문·예약·매출 증가로 이어진다.

이 항목들은 서비스 설명에서 확정 사실로 쓰지 않고 개입 실험의 가설로 둬야 한다.

## 3. AI 추천 노출을 보는 구조

```text
공개 정보 존재
→ 크롤링·지도·플레이스 접근 가능
→ 검색·색인 후보에 포함
→ 사용자의 지역·조건 질의와 매칭
→ AI가 식당을 답변 후보로 선택
→ 답변에 식당명·이유·출처 표시
→ 정보 정확성 확인
→ 사용자의 지도 확인·예약·방문
```

한 단계의 성공을 다음 단계의 성공으로 해석하면 안 된다. 예를 들어 사이트가 크롤링됐다고 식당이 추천되는 것은 아니며, 답변에 인용됐다고 방문이 발생한 것도 아니다.

## 4. 식당 추천을 직접 조사한 핵심 연구

### 4-1. 발리 식당·카페·바 전수 감사

**Pitenin, _Invisible to the Machine_ (2026)**  
[arXiv 원문](https://arxiv.org/abs/2608.07069)

- 등급: B, 프리프린트
- 범위: 발리 Canggu·Ubud의 음식점·카페·바 4,776곳
- 모델: ChatGPT, Claude, Gemini, Perplexity
- 측정: 96개 페르소나형 질문, 7일, 검색 기반 답변 2,208회
- 설계: 사전등록, 2주 뒤 재측정, 데이터·프로토콜 공개

주요 결과:

- 전체 식당의 85.6%가 네 모델 어디에서도 한 번도 추천되지 않았다.
- Google 리뷰 50개 이상인 비교적 자리 잡은 식당도 72.6%가 추천되지 않았다.
- 추천 답변 진입과 연관된 변수는 리뷰량(OR 1.64), 자체 웹사이트(OR 1.92), 가격 정보(OR 1.54), 제3자 웹 언급(OR 1.44)이었다.
- 별점은 추천 진입과 뚜렷한 관계가 없었지만(OR 0.89), 이미 추천된 식당 중 첫 번째 배치와는 관련됐다(OR 1.17).
- Foursquare 등록은 추천 진입이나 순위에 긍정적 관계가 없었다.
- 모델별 상위 20개 식당의 일치도는 Jaccard 0.33~0.54로 낮았다.
- 허구 식당 생성보다 폐점 식당을 추천하는 정보 노후화 문제가 더 현실적이었다.

해석:

- `추천 진입`과 `추천된 뒤의 순서`를 별도 지표로 측정해야 한다.
- 웹사이트·가격·외부 언급은 우선 실험할 가치가 높다.
- 관찰연구이므로 “웹사이트를 만들면 추천된다”는 인과 주장은 할 수 없다.
- 관광지인 발리 두 지역의 결과를 한국 전체로 일반화할 수 없다.

### 4-2. 미국 도시의 식당 추천 편향

**Chen, Weng & Moro, _Large language models create an uneven informational layer over cities_ (2026)**  
[arXiv 원문](https://arxiv.org/abs/2607.06260)

- 등급: B, 프리프린트
- 범위: 미국 5개 도시, 304개 동네
- 모델: GPT-4o-mini, Gemini 2.0 Flash, Llama 3.3
- 설계: 동네별 가상 사용자 320개, 자유 추천과 실제 식당 100곳 중 선택하는 제한 추천 비교

주요 결과:

- 자유 추천에서는 허구 식당이 평균 36.8%였다.
- 검증된 실제 식당 목록을 후보로 제공하면 허구 추천은 거의 사라졌다.
- 실제 후보 목록 안에서도 평균 47.5%의 식당은 어떤 사용자 프로필에도 추천되지 않았다.
- 고정된 후보 집합에서도 Yelp 리뷰 수가 많을수록 비추천 가능성이 낮은 관계가 관찰됐다.
- 동일 후보 안에서도 사용자 소득, 관광객 여부 같은 프로필이 추천 가격대와 식당 특성에 영향을 줬다.

해석:

- `실재 식당을 정확히 말하는가`와 `다양한 식당을 골고루 추천하는가`는 다른 문제다.
- 추천 질문의 페르소나와 조건이 결과를 바꾸므로 질문 세트를 고정해야 한다.
- 리뷰 수는 인과효과가 아니라 관찰된 연관이다.
- 비영어권·한국 환경으로의 일반화는 별도 검증이 필요하다.

## 5. GEO·생성형 검색 연구

### 5-1. GEO의 출발점

**Aggarwal 외, _GEO: Generative Engine Optimization_ (KDD 2024)**  
[arXiv](https://arxiv.org/abs/2311.09735) · [ACM DOI](https://doi.org/10.1145/3637528.3671900)

- 등급: A
- 10,000개 질의와 25개 분야를 사용했다.
- Google 상위 문서 5개를 GPT-3.5에 미리 제공한 뒤 콘텐츠 표현을 바꿔 답변 내 출처 가시성을 측정했다.
- 인용, 직접 인용, 통계 추가 등이 해당 벤치마크의 가시성 점수를 높였고 최대 40% 증가를 보고했다.

중요한 한계:

- 이미 검색되어 모델 입력에 들어간 문서가 답변에서 얼마나 사용되는지 본 실험이다.
- 문서가 실제 웹검색에서 발견되는지, 식당이 추천되는지, 트래픽이 늘어나는지는 입증하지 않았다.
- Perplexity 실험도 자연 검색 노출 실험이 아니라 본문 파일을 직접 제공한 조건이다.
- 따라서 `40% 증가`를 식당 추천 상승률로 홍보하면 안 된다.

### 5-2. 경쟁하는 두 출처 중 무엇을 먼저 인용하는가

**Vishwakarma 외, _What Gets Cited_ (SIGIR 2026)**  
[arXiv](https://arxiv.org/abs/2605.25517) · [ACM DOI](https://doi.org/10.1145/3805712.3808445)

- 등급: A
- 6개 LLM, 18개 콘텐츠 요인, 252,000회 비교 실험
- 두 문서를 모델 입력에 직접 넣고 한 요인만 바꾼 뒤 첫 인용 출처를 측정했다.
- 주제 적합성과 입력 순서가 가장 큰 요인이었다.
- 명시적인 가격과 최근 날짜도 일관된 긍정 효과를 보였다.
- 완전성과 신뢰 단서는 작은 효과, 형식만 바꾸는 편집은 영향이 작았다.

적용 범위:

- 가격·최신성·질문 적합성이 답변 내 인용에 영향을 줄 가능성은 비교적 강한 통제 근거다.
- 그러나 두 문서가 이미 모델에 제공된 실험이므로 자연 검색 발견이나 식당 추천 진입 효과는 아니다.

### 5-3. 인용과 실제 답변 기여는 다르다

**Zhang 외, _From Citation Selection to Citation Absorption_ (2026)**  
[arXiv](https://arxiv.org/abs/2604.25707)

- 등급: B, 사전 제출 초안
- ChatGPT·Google·Perplexity의 602개 프롬프트와 21,143개 유효 인용을 분석했다.
- 인용 출처 수와 최종 답변에 실제로 영향을 준 정도가 다르다고 보고했다.
- 구조, 의미 적합성, 수치·비교·절차처럼 추출 가능한 근거가 많은 페이지가 더 깊게 활용되는 경향이 있었다.
- Q&A 형식 자체는 자동으로 유리하지 않았다.
- 영어가 모든 플랫폼에서 일관되게 유리하지도 않았다.

이 연구 자체가 기술한 대로 결과는 기술적 관찰이며 인과효과로 해석하면 안 된다.

### 5-4. 최신 비판적 검토

**Martinez, _Optimizing Visibility in Generative Engines: A Critical Survey_ (2026)**  
[arXiv](https://arxiv.org/abs/2607.14035)

- 등급: B, 프리프린트
- 2023~2026년 연구 45편을 검토했다.
- GEO를 검색 활성화, 색인, 검색, 재정렬, 인용, 답변 흡수, 사용자 행동으로 구분했다.
- 현재까지 가장 강한 인과증거는 이미 검색된 문서가 답변에서 인용·활용되는 단계에 집중돼 있다고 평가했다.
- 장기간·여러 플랫폼에서 자연 발견과 전환을 안정적으로 높인 방법은 확인하지 못했다고 결론 냈다.
- 반복 측정, 질문 변형, 비교집단, 인간 검수를 최소 프로토콜로 권고했다.

## 6. 플랫폼 공식 문서에서 확인한 것

### 6-1. OpenAI·ChatGPT Search

공식 자료: [ChatGPT Search](https://help.openai.com/en/articles/9237897-chatgpt-search) · [게시자 FAQ](https://help.openai.com/en/articles/12627856)

- `OAI-SearchBot`을 허용해야 공개 페이지가 ChatGPT Search 요약·인용 후보가 될 수 있다.
- CDN·방화벽에서도 공식 검색봇 IP를 차단하지 않아야 한다.
- `GPTBot`은 학습용이며 Search 노출 제어와 역할이 다르다.
- ChatGPT Search는 관련성과 신뢰성을 포함한 여러 요인을 사용하며 배치를 보장하지 않는다.
- 추천 질문에서 웹검색이 실제로 활성화됐는지 별도로 기록해야 한다.

판정: **검색 후보 자격의 공식 근거는 있지만 식당 추천 순위 공식은 없다.**

### 6-2. Google Search·Business Profile·Maps

1. **모니터링 도구**: 여러 AI에 질문해 멘션과 출처를 추적한다.


## 10. 연구 가설로 남길 항목

### 우선 가설

- H1. 메뉴·가격·음식 종류가 텍스트로 공개된 식당은 조건형 질문에서 추천 등장률이 높다.
- H2. 자체 영문 페이지가 있는 식당은 영어 질문에서 추천 등장률과 정보 정확도가 높다.
- H3. 지도·홈페이지·SNS의 영업정보가 일치하면 폐점·영업시간 오류가 줄어든다.
- H4. 혼밥·채식·할랄·알레르기·결제 같은 조건 정보가 있으면 해당 조건 질문의 충족률이 높다.
- H5. 제3자 관광·지역 사이트의 사실 기반 언급이 있으면 추천 등장률 또는 인용률이 높다.
- H6. 개입 효과는 ChatGPT·Gemini·네이버에서 서로 다르다.

### 보조 가설

- 구조화 데이터는 AI 추천보다 검색·정보 해석 단계에 먼저 영향을 준다.
- 리뷰 수는 추천 진입과 관련되지만 별점은 추천된 뒤의 순서에 더 관련될 수 있다.
- 최신 리뷰와 최신 수정일은 오래된 식당 정보 오류를 줄일 수 있다.

- 웹검색·지도 grounding 사용 여부
- 질문 언어
- 사용자 위치와 지역 표현
- 질문 원문과 패러프레이즈 묶음
- 새 대화·메모리 비활성화
- 날짜와 시간
- 반복 횟수
- 비교집단

측정값도 분리해야 한다.

- 검색 또는 grounding 활성화 여부
- 식당 추천 등장률
- 상위 3개 등장률
- 평균 추천 순서
- 자체 페이지·지도·제3자 출처 인용률
- 메뉴·주소·영업시간 정보 정확도
- 질문 조건 충족률
- 모델 간 일치도
- 반복 실행 변동폭

## 12. 최종 판단

현재 가장 방어 가능한 설명은 다음과 같다.

> AI에게 더 자주 노출되는 확정 공식은 아직 없다. 다만 최신 식당 연구와 플랫폼 공식 문서는 AI가 식당을 찾고 설명할 수 있도록 정확한 지도·플레이스 정보, 읽을 수 있는 메뉴와 가격, 자체 웹페이지, 리뷰와 제3자 언급, 최신 영업정보를 갖추는 것이 중요한 후보 조건임을 보여준다. 한눈은 이 조건들을 정비한 뒤 같은 질문을 반복해 실제 추천 변화가 생기는지 검증해야 한다.

따라서 서비스의 핵심은 `GEO 비법 판매`가 아니라 **측정 가능한 가설에 따라 식당 정보를 개선하고, 같은 조건의 전후 실험으로 효과를 검증하는 것**이어야 한다.
