# 지도 메뉴 정비 예시 2건

- 제작일: 2026-11-06
- 시작 파일: `index.html`. 카카오·Google 전환, 정비 전후 비교, 메뉴 확대·전체 보기, 1:1 화면 제공.
- 실제 지도 정보는 수정하지 않은 로컬 시안이다.
- 이번 사례 선정은 정보 정비 예시 제작용이며, 이전 추천 측정 결과와 합산하지 않는다.

## 1. 카카오맵 — 파르코 서울숲점

- 서울 성동구 서울숲2길 44 1층.
- 실제 상세 URL: https://place.map.kakao.com/465733251#menuInfo
- 2026-11-06 메뉴 탭에서 이름·가격 19개, 메뉴판 사진 30개를 확인했다.
- 이름·가격은 존재하지만 첫 세 리조또의 재료 설명과 소스 선택 조건은 텍스트 메뉴와 연결되지 않았다.
- 같은 페이지 메뉴판 사진의 문구를 읽어 세 메뉴의 설명 칸으로 옮겼다. 가격·메뉴명·판매 단위를 임의로 변경하지 않았다.
- 근거 원본: `images/kakao_menuboard.jpg`. 문구별 출처 URL은 `evidence.json`에 기록했다.
- 현재 사진은 이용자가 올린 메뉴판 자료다. 공식 작성자로 단정하지 않았다.

## 2. Google 지도 — 힛사츠와자(Hissatsuwaza)

- 서울특별시 마포구 망원동 410-26.
- 장소 식별자: `0x357c990006a61961:0x93b46c4afa816b00` / `/g/11xsrqylhh`.
- 2026-11-06 Chrome의 실제 메뉴 → 차슈멘 탭에서 설명 원문을 확인했다.
- 기본 구성, 계란 미포함, 중량별 추가금, 무료 요청이 한영 혼합 한 문단으로 붙어 있었다.
- 같은 사실을 한국어 세 문단으로 정리했다. 차슈멘 기본 가격은 해당 설명 칸에서 확인되지 않아 추가하지 않았다.
- IAB 제한 보기에서는 메뉴를 확인할 수 없었다. 실제 메뉴를 제공한 Chrome 화면을 근거로 사용했다.
- 근거 원본: `images/google_original.png`, `source/google_menu_evidence.json`.

## 디자인 재현 방식

- 카카오: 당일 실제 DOM, 원본 CSS, 사진, SVG 아이콘을 로컬에 보존했다. 기존 메뉴 설명 클래스 `desc_item2`에만 문구를 추가했다.
- Google: 당일 실제 지도 캡처 픽셀을 유지하고 설명 영역만 교체했다. 원본의 12px 글자, 16px 행간, 0.2px 자간, `rgb(94,94,94)` 색상을 적용했다. 지도·검색창·탭·장소 표시는 원본 캡처다. 개인 계정과 저장 목록 영역은 잘라냈다.
- 비교 도구의 버튼과 BEFORE/AFTER 표시는 지도 프레임 바깥에 배치했다.
- 실제 지도 편집 화면의 입력 제한과 저장 성공을 확인한 산출물은 아니다. 화면에서 보이는 정보 정비 내용을 제안하는 시안이다.

## 재현

1. 브라우저에서 관측한 원문은 `source/`, 캡처는 `images/`, 원본 화면 자산은 `assets/`에 보존했다.
2. `python build_examples.py`로 원본 기반 네 개 화면을 재생성한다.
3. `index.html`은 파일로 직접 열거나 이 폴더에서 로컬 HTTP 서버로 확인한다.
4. 정적 검수는 `static_qa.json`, 브라우저 검수는 `browser_qa.json`, 픽셀 보존 검수는 `image_qa.json`에 기록했다.
5. `python compose_previews.py`로 검수 렌더에서 `images/kakao_before_after.png`, `images/google_before_after.png`를 생성한다. 전체 Google 정비 후 이미지는 `images/google_after.png`다.
6. 카카오 DOM 재현과 실제 캡처의 작은 픽셀 차이는 세 번째 메뉴판 사진 주변에 한정됐다. 완성 비교 PNG에서는 메뉴 정비와 무관한 상단을 원본 픽셀로 보존했다. Google 완성 이미지는 설명 교체 영역 밖의 픽셀이 원본과 동일함을 확인했다.
7. 지도 전환 양방향, 메뉴 확대·전체 보기 전환, 근거 펼치기, 메뉴명·가격 19개 유지, 정비한 설명 세 항목 표시를 실제 브라우저에서 확인했다.
8. 전환 직후 이전 iframe 화면이 남았던 중간 캡처는 `images/qa_intermediate/`에 따로 보존했다. 최종 비교 이미지와 구분한다.
