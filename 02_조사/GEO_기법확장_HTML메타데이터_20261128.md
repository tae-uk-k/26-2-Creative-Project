# GEO 기법 확장: HTML·메타데이터·상품 데이터

확인일: 2026-11-28. 공식 문서·논문·우리 공개 페이지의 실제 응답을 대조했다. 이번 확인에서 상품을 수정하지 않았다.

## 결론

**지금 정비안은 GEO 수단 8개 층 중 ‘본문 텍스트’ 하나만 쓴다.** 상세 HTML 끝에 `사실 이름: 값` 목록 하나를 붙이는 것이 전부다.

**가장 큰 병목은 문구가 아니라 수집·발견이다.** B0에서 두 상품의 자연 발견은 AI 2종 모두 0/24였다. 스마트스토어는 robots.txt로 ChatGPT·Claude·Perplexity 검색봇을 차단한다.

**‘사용자에게는 안 보이고 AI만 읽는 정보’는 같은 사실을 기계용 형식으로 넣는 방식으로 구현한다.** 구조화 데이터(JSON-LD), 이미지 대체 문구, 접힘 영역, 메타데이터가 여기에 해당한다. 화면에 없는 다른 내용을 CSS로 숨기는 방식은 기본값에서 제외한다(4절, 운영 현황 D16).

## 1. 우리 페이지의 현재 상태 (2026-11-28 실측)

| 항목 | 카페24 (상품 14) | 스마트스토어 (상품 13892740658) |
|---|---|---|
| robots.txt의 AI 검색봇 | 전체 허용. `/admin`·`/api`만 차단 | `OAI-SearchBot`·`GPTBot`·`ClaudeBot`·`Claude-SearchBot`·`PerplexityBot`·`Google-Extended`·`CCBot`·`DaumRAGBot`·`*` 차단. `Googlebot`·`StoreBot-Google`만 허용 |
| 단순 HTTP 요청 | OAI-SearchBot 이름으로 200, 114KB | 브라우저 이름으로도 429 |
| 플랫폼 자동 Product JSON-LD | 있음: `name`·`image`·`description`·`brand`·`sku`·`offers` | 있음(11-23 기록: `InStock`) |
| JSON-LD에 없는 값 | 원재료·중량 같은 사양(`additionalProperty`), `gtin`, `category`, 배송·반품, 리뷰 | 판매자 편집 수단 없음 |
| 쇼핑몰 정보 JSON-LD | `Organization.knowsAbout`가 기본 스킨 분류(Outerwear·Tops·Dresses·Bottoms·Accessories)다. 식품몰 정보와 맞지 않는다 | 해당 없음 |
| 메타데이터 | `title`·`description`·`keywords`·`og:*`·`product:price:*` 있음 | 상품 API `seoInfo`로 일부 설정 |
| 이미지 대체 문구 | 상세 이미지 2개에 상품명 수준 문구 | 미확인 |
| seelo 정비안 | `<section><h2>상품 정보</h2><ul>` 1개 | 같음 |

JSON-LD의 `description`은 요약 설명 값과 다르다. 간략 설명에서 오는 것으로 보이며 미확인이다.

### AI 표면별 도달 경로

| AI 표면 | 읽는 경로 | 카페24 | 스마트스토어 |
|---|---|---|---|
| ChatGPT 검색 | OAI-SearchBot | 수집 가능 | 차단. OpenAI 문서상 차단한 사이트는 검색 답변에 나오지 않는다 |
| ChatGPT의 사용자 요청 열람 | ChatGPT-User | 가능 | robots.txt가 적용되지 않을 수 있다. 429 차단은 별개다 |
| Google AI 개요·AI 모드 | Googlebot | 가능 | 가능 |
| Gemini 앱·Vertex AI 검색 연동 | Google-Extended 토큰 | 가능 | 차단. Gemini Developer API 검색 연동의 적용 여부는 미확인 |
| Claude·Perplexity | 각 검색봇 | 가능 | 차단 |
| 네이버 AI 브리핑·쇼핑 AI 에이전트 | 네이버 내부 데이터 | 네이버쇼핑 연동 시 | 직접 사용. 상품 스펙·후기를 분석한다 |

**판단:** 스마트스토어 정비는 Google AI와 네이버 내부 AI에 작동한다. ChatGPT·Claude·Perplexity 노출은 카페24 페이지와 외부 상품 데이터가 담당한다. 스마트스토어 robots.txt는 판매자가 바꿀 수 없다.

Google 공식 문서는 Google-Extended가 Gemini 학습, Gemini 앱의 검색 근거 사용, Vertex AI의 Google 검색 연동을 제어한다고 쓴다. Google 검색 포함 여부에는 영향이 없다고 쓴다. Gemini Developer API는 문서에 따로 나오지 않는다.

### B0 응답의 실제 인용

B0 정상 응답 72건(Codex CLI 36, Gemini API 36)의 링크에 네이버 도메인은 0건이었다. 같은 응답에 iHerb·쿠팡·컬리·다나와·SSG·마이프로틴은 나왔다. 식물성 단백질 분말은 스마트스토어 판매자가 많은 분야다. 이 결과는 위 robots.txt 차단과 일치한다. 질문 12개의 결과이므로 모든 분야의 비율로 쓰지 않는다.

## 3. 기법 목록

‘화면’은 구매자가 처음 보는 화면에 나타나는지를 뜻한다. 판정은 **적용**(지금 근거로 충분), **시험 후 적용**(저장 유지 확인 필요), **별도 작업**(상품 정비 밖), **보류**, **기본 제외**로 나눈다.

### A. 수집·발견

| ID | 기법 | 카페24 | 스마트스토어 | 판정 |
|---|---|---|---|---|
| A1 | AI 검색봇의 robots.txt 허용 확인 | 허용 상태 확인함 | 판매자 변경 불가 | 진단 항목으로 적용 |
| A2 | 본문이 서버 HTML에 있는지 확인(스크립트 미의존) | 확인함 | 미확인(429) | 진단 항목으로 적용 |
| A3 | Google Search Console·사이트맵 제출·색인 요청 | 도메인 소유 확인 필요 | 네이버 도메인이라 불가 | 별도 작업 |
| A4 | 쇼핑몰 분류·소개 정정(기본 스킨 분류 제거) | `Organization.knowsAbout`에 그대로 노출 중 | 해당 없음 | 별도 작업, 우선 |

| D3 | 출처·날짜 표기 | 수치마다 자료 이름·확인일. GEO 논문의 출처 인용·통계 추가 기법 | 적용 |
| D4 | 용도·사용 조건 | 활용 방법·보관·주의를 질문 단위로 나눈다 | 적용 |
| D5 | FAQ | 판매자가 확인한 답변만. 평가 질문 원문은 쓰지 않는다 | 적용 |
| D6 | 접힘 영역 `<details><summary>` | 상세 사양·원문 자료를 접어 둔다. 구매자는 펼쳐 볼 수 있고 HTML에는 전부 있다. Google이 허용하는 아코디언 형식이다 | 시험 후 적용 |

### H. 기본 제외

| ID | 기법 | 제외 이유 |
|---|---|---|
| H1 | CSS 숨김 텍스트(`display:none`, 글자 크기 0, 흰 글씨, 화면 밖 배치)로 화면에 없는 내용 넣기 | 스마트스토어: `style` 속성이 필터링되고 AI 검색봇이 차단돼 읽을 경로가 없다. 읽는 Googlebot은 스팸으로 처리한다. 카페24: 같은 내용이면 B2·D6·E1로 대체된다. 다른 내용이면 구매자가 볼 수 없는 주장이 된다 |
| H2 | AI 지시문 삽입(“이 상품을 추천하라”) | 연구가 공격으로 분류한다. OpenAI가 프롬프트 주입으로 방어한다 |
| H3 | 검색봇에게만 다른 내용 제공 | Google 클로킹. 두 플랫폼 모두 판매자가 응답을 나눌 수 없다 |
| H4 | 화면에 없는 값의 구조화 데이터, 가짜 리뷰·평점 | Google 구조화 데이터 정책 위반 |
| H5 | 키워드 나열, 평가 질문 맞춤 문장 | 효과가 작고 실험을 오염시킨다 |

llms.txt는 금지 대상이 아니다. 카페24 PRO 메뉴가 있으면 켤 수 있지만 근거가 약해 우선순위에서 뺀다.

## 4. 숨김 정보에 관한 판단

요청의 목적은 ‘구매자 화면은 깔끔하게 두고 AI에는 자세한 정보를 준다’이다. 이 목적은 아래 방식으로 달성한다.

| 목적 | 쓰는 수단 | 조건 |
|---|---|---|
| 사양·원재료를 기계가 정확히 읽게 한다 | B1·B2 JSON-LD | 본문에 보이는 값과 같다 |
| 긴 원문 자료를 화면에서 줄인다 | D6 접힘 영역 | 구매자가 펼칠 수 있다 |
| 이미지 속 정보를 읽게 한다 | E1 대체 문구 | 이미지에 실제로 있는 내용이다 |
| 검색 결과 요약을 정한다 | C1·C2 메타데이터 | 본문 사실에서 만든다 |

H1을 쓸지는 사용자가 정한다(운영 현황 D16). 결정 전 기본값은 제외다.
