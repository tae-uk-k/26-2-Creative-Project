# 기존 리뷰·정보의 표현 정비 추가 검토

작성: 2026-10-29. 실제 가게 화면 관측: 2026-10-28.

## 현재 범위

사용자 요청으로 **리뷰 답변 대행·초안·수정·게시를 제외**했다. 리뷰는 메뉴·영업·시설 정보에서 혼동되는 점을 찾는 참고 자료로만 사용한다. 확인된 사실은 업주 승인 후 매장 정보 칸에서 정비한다.

## 두 가지 실제 가게 시안

`index.html`에서 가게를 고르고 BEFORE / AFTER로 전환한다. 명동피자는 기존 카카오맵 메뉴 시안을 연결하며, 힛사츠와자는 실제 Google 지도 캡처를 바탕으로 설명 한 칸을 재현한다. 실제 지도와 검색이 작동하는 복제본은 아니다.

**동반 파일:** 명동피자 화면은 옆의 `../지도UI_비포애프터_명동피자_20261028/` 폴더의 before.html·after.html·assets를 사용하므로 해당 폴더를 유지한다. 기존 파일은 덮어쓰지 않았다.

### 1. 명동피자: 메뉴·세트·런치의 이용 조건 정리

- 기존에 만든 카카오맵 메뉴 8개 정비 시안으로 교체했다.
- 영어 음식 설명, 평일 런치 주문 마감, 세트 인원·전체 구성·선택 수를 명확히 전달한다.
- 원래 메뉴 이름의 의미·브랜드 표현, 가격 31개·사진 40개·고객 리뷰·업주 답변·평점은 유지한다.
- 미확인 게딱지 밥의 재료·맵기·조절 가능 여부는 추가하지 않는다.

### 2. 힛사츠와자: 한 문단의 여러 조건을 선택 기준별로 분리

- 변경: Google 차슈멘 설명 1칸. 메뉴명·옵션·수량·추가금·한국어·영어를 유지.
- 기본 구성: 차슈 2장·멘마 2개·김 1장, 계란 미포함.
- 면 중량: 150g·200g 추가금 없음 / 300g +1,000원.
- 무료 요청 선택: 초생강 / 멘마 제외 / 적양파 많이.
- 각 한국어 조건 바로 아래에 같은 의미의 영어를 붙인다. 소제목은 별도 플랫폼 옵션 필드를 새로 만드는 것이 아니라 설명 한 칸 안의 짧은 문구다.
- 사진 가격으로 기본 메뉴 가격을 추정하지 않았다. 추가금 1,000원을 메뉴 총액으로 바꾸지 않는다. 무료 요청을 기본 구성이나 무제한 제공으로 바꾸지 않는다.

## 추가로 발견할 수 있는 표현 정비 방향

| 현재 표현·상황 | 고칠 수 있는 방향 | 수정 범위·조건 |
|---|---|---|
| 메뉴 이름·번역·토핑·유료 옵션이 한 문단에 혼합 | 기본 구성 → 선택 → 추가금·제외 조건 순으로 나눔 | 해당 설명 1칸. 기존 조건·부정형·수량 보존 |
| “안 매운 줄 알았다”는 리뷰가 있음 | 현재 메뉴판·업주에게 확인한 맵기만 메뉴 설명 앞부분으로 이동 | 해당 메뉴 설명 1칸. 모든 크림 메뉴를 순한맛으로 묶지 않음 |
| “8천 원”과 “공기밥 별도”가 떨어져 보임 | 가격 가까이에 별도 비용 조건을 붙이고 영문에도 동일하게 기재 | 해당 설명만. 미확인 밥값·1인 식사 총액은 만들지 않음 |
| “주차 편함”, “아이와 좋음”, “외국인에게 친절”이라는 후기 | 시설·이용 정책으로 전환하기 전 업주 확인 질문을 만듦 | 확인 전 공개 칸 변경 0개. 무료 주차·유아의자·상시 영어 응대로 확대하지 않음 |
| 한 번의 “2시간 대기” 또는 “대기 없음” 후기 | 날짜가 있는 경험은 후기 그대로 두고 현재 예약·대기 접수 방법만 확인·보완 | 리뷰·평균 대기시간 변경 없음. 공식 예약 안내가 확인됐을 때 전용 링크 정비 |
| “최고”, “명소”, “아이에게 안전” 같은 평가형 문구 | 업주의 브랜드 표현은 보존하되, 새 안내에는 확인 가능한 조리·구성·이용 조건 사용 | 기존 소개 통째 교체 금지. 필요한 사실 구절만 제안 |
| 오래된 행사·품절·휴무 설명이 상시 소개와 섞임 | 현재 적용 여부를 확인해 날짜·기간을 공지에 적고 상시 정보와 분리 | 업주 소유 공지에 한정. 타인 사진·과거 후기를 삭제하거나 고치지 않음 |

## 공식 근거와 한계

- 이는 사람이 이해하기 쉽고 AI가 잘못 결합하기 어려운 표현을 만들기 위한 제안이다. AI 추천·인용이 증가한다는 인과 효과를 검증한 결과는 아니다.
- 2026-10-29 브라우저 제어가 Work 설정에서 비활성화돼 새 화면 열람·렌더링·탭 클릭 검증은 못 했다. 카카오 상세 URL의 web 열람도 실패했다. 10월 28일 원본 캡처와 당시 공개 본문을 사용했으며, 최신 재확인으로 표시하지 않는다.
- 정적 검사: 리뷰 답변 수정 예시 제외, 외부 서버 자산 의존 없음, 로컬 연결 파일 존재, 명동피자 가격 31개 동일, JavaScript 구문 정상. 실제 지도 반영·업주 승인은 수행하지 않았다.
