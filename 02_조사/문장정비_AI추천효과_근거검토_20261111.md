# 문장 정비가 AI 추천을 늘리는가: 연구·공식 지침 근거 검토

조사일: 2026-11-11 · 대상: Google 지도·카카오맵의 소개와 메뉴 정보를 정비하는 seelo

## 1. 질문에 대한 판단

**문장을 바꾸면 AI의 답변 내 선택·활용이 달라질 수 있다는 실험 근거는 있다. 그러나 같은 사실의 표현만 다듬어 실제 식당의 자연 검색 추천 등장률을 높인다는 근거는 현재 확인한 자료에서 충분하지 않다.**

연구들은 서로 다른 문제를 측정한다. 이미 읽을 자료가 주어진 상황에서 인용 분량이 증가한 결과, 후보 상품의 순위가 달라진 결과, 공개 웹에서 새로운 가게가 발견되는 결과를 구분해야 한다. 연구 하나의 긍정적 숫자를 지도 정비의 예상 성과로 옮기면 이 구분이 사라진다.

이전에 제안한 소개 길이·문장 수·메뉴 설명 구조는 과잉 입력을 막고 이해를 돕기 위한 편집 규칙이다. 그 분량이 AI 추천을 가장 많이 늘리는 최적값이라는 실험 근거를 확보한 것은 아니다.

현재 판단은 다음과 같다.

| 질문 | 이번 조사로 판단할 수 있는 정도 |
|---|---|
| AI가 읽을 문장 표현이 선택·인용에 영향을 주는가? | 그렇다는 통제 실험이 있다. 다른 모델·도메인·지표에서는 효과가 작거나 음수인 결과도 있다. |
| 쉬운 문장·줄바꿈·짧은 설명이면 일관되게 더 추천되는가? | 일관된 규칙으로 채택하기 어렵다. |
| 질문에 필요한 사실을 명확히 연결하는 것은 의미가 있는가? | 공식 지침과 질문–본문 관련성 연구가 뒷받침한다. 실제 지도 편집 효과는 별도 확인할 문제다. |
| 지도 소개·메뉴만 고쳐 한국 식당의 ChatGPT·Gemini 자연 추천률을 높였는가? | 이번에 검토한 학술 자료에서는 이 조건을 직접 충족하는 연구를 찾지 못했다. 업체의 단일 사례 주장은 있으나 비교 설계가 약하다. |

## 2. 먼저 구분할 개입과 성과

### 2.1 문장 정비의 네 종류

| 개입 | 예 | 무엇이 달라지는가 |
|---|---|---|
| 문체 교정 | 같은 사실을 유지하고 어색한 문장을 자연스럽게 고침 | 주로 표현·가독성 |
| 사실 관계의 재배치 | 흩어진 ‘2인’, ‘39,900원’, ‘세트 구성’을 같은 항목에 붙임 | 정보량은 같아도 적용 대상과 조건의 연결이 선명해짐 |
| 누락 사실 보완 | 없던 주문 마감·최소 주문량·가격 단위를 확인해 추가 | AI가 판단할 수 있는 정보 자체가 늘어남 |
| 접근·출처 정비 | 사진 속 정보의 텍스트 제공, 지점 메뉴 링크 연결, 실제 사용 출처의 오류 정정 | 발견·접근·수집할 자료와 경로가 달라짐 |

이 네 작업을 함께 해놓고 결과를 ‘문장 교정의 효과’로 부르면 원인을 알 수 없다. 영문 설명 추가도 기존 의미의 번역인지 새로운 음식·이용 정보의 추가인지 기록해야 한다.

### 2.2 연구에서 말하는 노출은 같은 숫자가 아니다

`공개 반영 → 검색·자료 발견 → 후보 선택 → 답변의 가게 추천·인용 → 이용자 행동`

| 측정값 | 의미 | 해석할 때 주의할 점 |
|---|---|---|
| 답변 내 출처 기여도 | 특정 자료에서 가져온 내용의 분량과 위치 | 가게가 추천된 응답 비율과 다름 |
| 인용 순서·후보 순위 | 주어진 후보 중 먼저 인용·추천됐는지 | 자연 검색에서 후보로 새로 진입했는지는 별개 |
| URL 인용률 | 답변에 해당 페이지 링크가 나타났는지 | 링크가 가게를 지지하는 추천인지 따로 읽어야 함 |
| 가게 추천 등장률 | 정상 응답 중 해당 가게가 실제 추천된 비율 | seelo의 주된 성과 질문에 가까움 |
| 사실 정확도 | 가격·인원·시간·지점·이용 조건을 맞게 설명했는지 | 추천 횟수가 같아도 개선될 수 있음 |

인용이 없다는 사실만으로 AI가 해당 페이지를 읽지 않았다고 확정하지 않는다. 소비자 화면에서 보이는 출처와 API에서 관측되는 검색 목록도 같은 자료로 취급하지 않는다.

## 3. 핵심 논문 여섯 편

아래는 요약 기사 대신 논문 본문의 방법·결과·한계·부록을 확인한 자료다. 공개 원고와 출판사 원문의 접근 상태는 7절에 따로 기록했다.

### R1. GEO: Generative Engine Optimization — 긍정적 근거의 실제 범위

- Aggarwal 외, KDD 2024. 열람 판본: arXiv v3, 2024-06-28.
- Google 상위 5개 자료의 정제된 본문을 후보로 고정하고 GPT-3.5 기반 답변을 비교했다. 테스트 질문 1,000개에서 표현·인용·수치 등의 변경을 평가했다.
- 표 1의 유창성 개선은 위치를 반영한 출처 기여도 19.3 → 24.7이다. 직접 계산하면 약 28% 상대 증가다. 이는 **가게 추천률이 28%p 증가했다는 수치가 아니다.**
- 중요한 부록 C.1: Perplexity 검증도 200개 사례의 자료를 파일로 업로드하고 그 파일만 사용하도록 했다. 공개 웹의 수정·재수집·자연 발견 실험이 아니다.
- 판단: 같은 사실의 표현이 답변에서 얼마나 활용되는지 바꿀 가능성을 지지한다. 지도 소개만 고쳐 새로운 추천을 얻는 단계까지 입증하지는 않는다.

[본문 §3.1·표 1·부록 C.1](https://arxiv.org/html/2311.09735v3) · [출판 DOI](https://doi.org/10.1145/3637528.3671900)

### R2. C-SEO Bench: Does Conversational SEO Work? — 일반적인 문장 기법의 약한 효과

- Puerto 외, NeurIPS 2025 Datasets and Benchmarks. 열람 판본: arXiv v3, 2025-10-20.
- 상품 추천·질의응답의 6개 도메인에서 문장 유창성, 쉬운 말, 권위적 표현, 통계·출처 추가 등을 비교했다. GPT-4o-mini·Claude 3.5 Haiku·o3·o4-mini를 사용했다.
- 대다수 방법의 인용 순위 개선이 제한적이었다. 일부는 순위를 낮췄고, 질문 답변 과제와 Haiku에서 유의한 긍정 효과를 확인하지 못했다고 보고한다.
- 이 연구도 후보 문서를 먼저 제공한 실험이다. ‘Best SEO’ 비교는 문서를 AI 입력의 앞쪽으로 직접 옮긴 조건이므로 실제 SEO 작업을 시행한 효과와 같지 않다.
- 판단: 문장을 다듬으면 여러 모델·업종에서 일관되게 이득이라는 주장에 대한 중요한 반대 근거다. R1과는 평가 지표가 달라 완전히 동일한 재현 실험으로 설명하면 안 된다.

[본문 §4.2·§6.2–6.4·표 3–4](https://arxiv.org/html/2506.11097v3) · [NeurIPS 게재 확인](https://proceedings.neurips.cc/paper_files/paper/2025/hash/27aa3aeff0f8460a7b43d30fa6c5c032-Abstract-Datasets_and_Benchmarks_Track.html)

### R3. SAGEO Arena — 본문만 고치면 앞단 검색에서 손해가 날 수 있음

- Kim 외, KDD 2026. 열람 판본: arXiv v2, 2026-08-07.
- 171,003개 문서로 검색 → 재정렬 → 답변 생성 파이프라인을 구성했다. 수정 문서를 다시 색인해 전체 과정을 재실행했다. 기본 구성은 BM25·Qwen3-Reranker·GPT-5-mini다.
- 표 2에서 본문만 쉬운 말로 바꾸면 검색 상위 20개 진입률이 0.58 → 0.52, 재정렬 상위 10개 진입률은 1.00 → 0.84였다. 유창성 개선의 최종 인용 성과는 거의 늘지 않았다. 다른 검색기에서도 본문 단독 수정의 약한 결과가 이어졌다.
- 제목·설명·헤딩 등 구조 필드를 함께 다루는 방식은 일부 단계에서 더 나았다. 하지만 연구자가 구성한 검색 시스템이며 소비자 ChatGPT·Gemini 지도 추천 실험은 아니다.
- 판단: 본문을 보기 좋게 바꾸는 것과 실제로 후보에 진입하는 것은 별개다. 지도에서 편집할 수 없는 HTML 구조를 이 결과만 보고 추가 기능으로 제안해서도 안 된다.

[본문 §3.3–3.4·표 2·§5.4](https://arxiv.org/html/2602.12187v2) · [출판 DOI](https://doi.org/10.1145/3770855.3818146)

### R4. LIVE-GEO — 실제 웹에서의 긍정 결과도 ‘후보 URL 제공’ 조건

- Do GEO Gains Survive the Live Web?, 2026-10-31 제출. 열람: arXiv v1. 이번 검토에서는 사전공개 연구로 다뤘다.
- 가상의 80개 브랜드·18개 제품군에 원문과 5개 재작성 방법을 적용하고 실제 웹에 게시했다. ChatGPT·Gemini·Grok 웹 인터페이스에서 비교했다.
- 일부 재작성 방법이 후보 내 1위 선택을 더 많이 받았다. 그러나 부록 D는 후보 상품 URL을 먼저 제공하거나 브랜드 페이지에서 후보를 찾도록 하고, 그 자료로 순위를 매기게 한다.
- 상품 설명과 댓글도 재작성 대상이다. 실제 가게의 업주 소개 한 칸을 교정한 실험과는 다르다. 후보 URL 순서만 바꾸어도 ChatGPT의 특정 방법 1위 비율이 73.8%와 93.8%로 달랐다.
- 판단: 공개 웹을 읽힌 뒤의 선택에는 문장 영향이 있을 수 있다는 최신 보강 근거다. 이름 없는 새 식당이 일반 질문에서 발견되는 효과의 직접 근거로 쓰기 어렵다.

[본문 §1·§4.2–4.3·부록 D](https://arxiv.org/html/2611.01126v1) · [제출일 확인](https://arxiv.org/abs/2611.01126)

### R5. What Drives AI Citations? — 글의 모양보다 질문 적합성과 검색 진입

- Chen·Koudas, 2026-10-10, arXiv v1 사전공개본.
- 두 시장의 90일 응답 158,099개·인용 468,037개를 분석했다. 질문과 제목·문단의 의미가 잘 맞는 페이지가 더 많이 인용됐다.
- FAQ·스키마·요약 상자 등의 겉모양은 사이트 간 비교에서는 좋아 보이지만 같은 사이트 안의 페이지 비교에서는 관계가 약해졌다. API 재실행에서 AI 자체 검색 결과의 순서가 인용과 강하게 연결됐다.
- 연구진도 페이지 특성의 분석은 관찰 연관이라고 명시한다. 수집 후 API 재실행은 소비자 앱과 다를 수 있고, Perplexity는 재실행하지 못했다.
- 판단: ‘실제 질문에 답할 내용이 있는가’를 우선하라는 근거다. FAQ를 붙이거나 길이를 줄이는 작업 자체를 독립적인 성과 원인으로 확정할 수는 없다.

[본문 §4·§6.1–6.4·§8 한계](https://arxiv.org/html/2610.15033v1)

### R6. Invisible to the Machine — 음식점에 가장 가깝지만 관찰 연구

- Pitenin, 2026-08-07, arXiv v1 사전공개본.
- 발리 음식점·카페·바 4,776곳과 4개 AI의 검색 연결 API 응답 2,208개를 분석했다. 자체 사이트·가격 정보·리뷰량·외부 언급 등과 추천 진입의 연관을 보고했다.
- 실제 식당 정보를 수정해 비교한 실험은 아니다. 본문 §7은 인과 효과가 아니며 소비자 앱 대신 API를 사용했다고 명시한다. 리뷰 본문의 풍부함이 검색을 높이는지도 후속 질문으로 남겼다.
- 판단: 문장 수나 영어 비율보다 가게에 대해 확인 가능한 정보가 충분한지 조사할 이유를 준다. 한국 지도 문장을 정비했을 때 추천이 얼마나 증가하는지는 이 연구로 계산할 수 없다.

[본문 §5.3·§6.6·§7](https://arxiv.org/html/2608.07069v1)

## 4. 실제 운영자가 제시하는 글쓰기 지침

### S1. Google Search Central

[생성형 AI 검색 최적화 가이드](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)는 기존 검색·품질 체계, 고유한 경험과 유용한 정보, 읽기 쉬운 문단·헤딩을 강조한다. 다른 글을 일반적으로 요약하거나 누구나 만들 수 있는 내용만 늘리는 방식과 구분한다.

[AI 기능과 웹사이트 안내](https://developers.google.com/search/docs/appearance/ai-features)는 핵심 정보의 텍스트 제공, 공개 본문과 구조화 데이터의 일치, 최신 비즈니스 프로필 정보를 권한다. 특정 문장 길이나 AI 전용 문체의 효과 수치를 제시하지 않는다. 적용 대상은 Google Search의 AI Overviews·AI Mode다.

### S2. Microsoft의 직접적인 문장·구조 지침

[2025-10-08 공식 글쓰기 안내](https://about.ads.microsoft.com/en/blog/post/october-2025/optimizing-your-content-for-inclusion-in-ai-search-answers)는 다음을 권한다.

- 제목·설명에서 페이지가 다루는 대상과 질문을 자연어로 명확히 표현한다.
- 한 문단에 다른 주제를 섞지 않고, 질문과 직접적인 답을 가까이 둔다.
- 복잡한 비교에는 목록·표를 쓰고, 핵심 사실을 이미지·PDF에만 두지 않는다.
- 긴 텍스트 덩어리와 키워드 반복을 피한다.

[2026-02-10 Bing 공식 안내](https://blogs.bing.com/webmaster/2026/2/Introducing-AI-Performance-in-Bing-Webmaster-Tools-Public-Preview/)도 명확한 구조·근거·최신성·형식 간 일치를 권하며 실제 인용 페이지와 검색어를 보면서 개선하도록 설명한다. 이는 운영사의 실무 지침이며 문장별 인용 상승률을 비교한 논문은 아니다.

### S3. 지도의 사실 관리에 관한 Google 지침

[Google 지역 검색 안내](https://support.google.com/business/answer/7091?hl=en)는 정확하고 충실한 프로필, 관련성·거리·인지도를 설명한다. 이는 지도 정보의 완전성을 관리할 직접 근거이지만 ChatGPT·Gemini의 문장 교정 효과를 측정한 자료는 아니다.

**지도에 적용할 부분:** 질문에 필요한 메뉴·가격 단위·영업·이용 조건을 지원되는 전용 칸에서 명확히 연결한다. 웹사이트용 H1·메타 설명·JSON-LD·긴 FAQ 표를 지도 소개에 그대로 옮기지 않는다.

## 5. 지도 문구만 바꿨다는 업체 사례도 검토함

### C1. Harvest SEO의 Google Business Profile 키워드 사례

[테스트 기록](https://aiseoexpert.sg/proof/ai-tests)은 프로필 설명에 GEO·AEO·AI SEO 서비스 용어를 추가한 뒤 AI 인용이 관측됐다고 주장한다. [사례 본문](https://aiseoexpert.sg/proof/)도 지역 질문의 실제 화면을 제시한다.

다만 자사 단일 사례이며 독립 비교 가게가 없다. 수정 전후의 충분한 반복 측정과 다른 변화의 배제도 공개 본문만으로 확인하기 어렵다. 두 페이지의 시행 연도가 각각 2025년과 2026년으로 다르다. 출처 표기를 단순 문체 교정으로 볼 수도 없다. 핵심 서비스에 관한 질문 적합성을 보완한 작업이다.

판단: 지도 설명 수정의 **후보 사례**로 참고하되 인과 효과를 입증한 근거로 채택하지 않는다. 날짜가 확인되는 전후 원문·전체 반복 결과·비교군 자료가 있어야 더 평가할 수 있다.

### C2. Crimson Salt의 19개 도시 지역 검색 조사

[자사 조사](https://crimsonsalt.com/industry-trends/google-business-profile-chatgpt-ranking/)는 도시별 질문을 한 세션에서 한 번씩 실행했다. 자료 출처도 검색 서버 로그가 아니라 AI가 설명한 출처라는 점을 자체 명시한다. 지역별 단서로는 참고할 수 있으나 지도 문구 변경 전후의 비교가 아니어서 교정 효과의 증거로 사용하지 않았다.

## 6. seelo에 대한 의견과 의문을 해결할 방법

### 6.1 현재 기준을 어떻게 읽어야 하는가

현재 정비 기준은 ‘잘못된 사실·누락·불명확한 조건을 줄이는 기준’으로 의미가 있다. 하지만 규칙을 잘 지킨 글에 높은 점수를 주고 그 점수를 AI 노출 상승의 예측값처럼 쓰는 것은 다른 문제다.

**문장 교정만을 상품의 핵심 작동 원리로 삼기에는 근거가 약하다.** 더 설득력 있는 검토 대상은 다음 연결이다.

`실제 질문에서 필요한 정보 확인 → AI가 사용하는 출처 점검 → 해당 가게의 누락·오류·조건 관계 정비 → 공개 반영 확인 → 같은 질문으로 추천·정확도 비교`

문장 정비의 목적도 두 가지로 구체화하는 편이 낫다.

1. **같은 사실을 더 정확하게 읽게 하기:** 인원·총액·추가금·요일·제공 조건의 잘못된 연결을 줄이는지 본다.
2. **답할 근거가 없던 질문에 사실을 제공하기:** 현재 제공하는 메뉴·서비스의 누락을 채운 뒤 그 조건의 질문에서 추천 후보가 되는지 본다.

‘정갈한 문장’, ‘짧은 문장’, ‘영문 병기’는 이 두 목적을 구현하는 편집 수단으로 둔다. 영업시간·전화·가격·사이트 링크를 함께 바꿨다면 각각 기록해 문체 효과와 합치지 않는다. 리뷰 답변 대행은 기존 제외 결정을 유지한다.

### 6.2 확인할 가설과 비교군

아래는 문헌 검토에서 도출한 검증 제안이며 실제 수행 결과가 아니다.

| 비교군 | 바꾸는 것 | 알 수 있는 것 |
|---|---|---|
| A. 유지 | 아무것도 바꾸지 않음 | 시간 경과·모델 변화에 따른 변동 |
| B. 표현만 | 사실·분량을 가능한 한 맞추고 문장·순서만 정리 | 표현·관계 재배치의 효과 |
| C. 사실 보완 | 문체를 크게 바꾸지 않고 확인된 누락 정보만 추가 | 정보 충실도의 효과 |
| D. 사실+표현 | C와 같은 사실을 더 명확히 정리 | B와 C를 결합했을 때의 추가 효과 |

- 실제 가게를 사전 조건에 따라 배정하고 가게·지점 단위로 비교한다. 비슷한 가게가 확보되지 않으면 시차를 둔 순차 적용을 검토한다. 같은 가게에 서로 다른 문장을 동시에 공개할 수 있다고 가정하지 않는다.
- 사전·사후에 같은 질문·모델·언어·위치 조건을 쓰고, 여러 날 반복한다. 상호·URL을 먼저 주지 않는 자연 추천 질문과 상호를 주는 사실 확인 질문을 따로 측정한다.
- 대표 질문 외에 표현을 바꾼 검수 질문도 둔다. 매번 같은 이름을 앞에 주는 테스트는 가게 발견 효과의 검증이 아니다.
- 주 지표는 가게 추천 등장률, 보조 지표는 사실 정확도·조건 충족·관측 출처다. API에서 검색이 관측되는 경우에만 검색 후보 진입을 별도 분석한다.
- 사후 전후 차이에서 유지군의 전후 차이를 뺀 값을 보고, 가게·질문 단위의 불확실성과 모델별 차이를 함께 평가한다. 한 가게의 수십 번 호출을 서로 다른 수십 개 가게로 취급하지 않는다.
- 표본 수는 ‘그룹당 몇 곳이면 입증’처럼 고정하지 않는다. 파일럿에서 변동과 실질적으로 의미 있는 최소 차이를 정한 뒤 규모를 산정한다.

후보 카드를 AI에게 직접 주는 실험은 B와 C의 작동 가능성을 보는 데 쓸 수 있다. 실제 지도 정비를 검증하려면 공개된 수정 정보가 반영된 뒤 **가게 이름과 URL을 주지 않는 추천 질문**에서 유지군과 비교해야 한다.

### 6.3 기존 내부 자료와의 연결

현재 저장된 [96회 후보 카드 실험 안내](../03_실험/지도기반_AI노출_20261016/정보제공_통제실험/README.md)는 자연 검색과 분리해 읽어야 한다. [11월 3일 두 집단 최종 검수 보고서](../03_실험/GEO_두집단_지도비교_20261103/최종보고서_미완료.md)는 확정 비교 쌍 0개·추천 호출 미실행으로 기록돼 있다. 이 저장 자료들은 이번 질문의 ‘실제 지도 문장 정비가 추천률을 늘렸는가’를 해결한 결과가 아니다.

원래부터 정보가 충실한 가게와 부실한 가게를 비교하는 관찰 연구도 유용하지만, 유명세·가격·업종·검색 순위 등의 남은 차이가 있다. 가능하다면 실제 변경의 종류를 나눠 적용한 비교가 더 직접적인 답을 준다.
