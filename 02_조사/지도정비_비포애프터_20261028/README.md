# 지도 정보 정비 Before / After

- `index.html`을 열면 된다. 별도 설치·외부 CDN·로그인이 필요 없다.
- `images` 폴더와 `evidence` 폴더를 HTML 옆에 유지한다.
- 실제 가게 6곳의 Google·카카오 공개 화면 12곳을 2026-10-28에 확인했다.
- 18개 사례의 AFTER는 승인 전 정비 제안이다. 실제 지도 수정·정보 수정 제안 제출은 하지 않았다.
- 가게·상황·상태 필터, 검색, 변경점 강조, 근거 화면 확대, 인쇄/PDF를 제공한다.
- 등록된 소개의 실제 작성 주체나 관리 화면 지원이 확인되지 않은 경우 그 한계를 해당 사례에 표시한다.
- 전화 정정은 공식 지점 안내와 대조했다. 사진 가격·판매 여부·영어 응대·주차 등의 미확인 값은 확정된 사실로 표시하지 않는다.
- 리뷰는 필요한 취지를 요약하고 원문 링크·근거 화면을 제공한다. 후기 작성자의 상세 이력을 별도 데이터로 재배포하지 않는다.
- 재생성: `python build_report.py`. 조사 데이터가 자동으로 최신화되는 명령은 아니다.
