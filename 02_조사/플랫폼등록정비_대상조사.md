# 가게 정보 등록·정비 지원 플랫폼 조사

확인일: 2026-11-09 · 대상: 외국인 관광객을 받고 싶은 국내 음식점·카페·바

**추가 지원 후보는 Tripadvisor·Bing, 국내 맛집 정보의 우선 검증 후보는 다이닝코드·식신·뽈레·테이블링으로 제안한다.** 네이버는 기본 가게 정보 관리의 주요 후보로 유지하고, 캐치테이블 글로벌·Instagram 등은 가게의 이용 상황에 따라 붙인다.

이 순서는 내부 출처 관찰과 공식 등록·관리 기능을 함께 고려한 기획 판단이다. 이번에는 공개 안내와 저장된 실험 자료를 조사했으며, 계정 가입·사업주 인증·권한 위임·실제 정보 수정은 실행하지 않았다. 현재 베타의 직접 수정 범위는 Google 지도·카카오맵으로 유지한다.

## 1. 선정 기준

가게가 실제로 등록돼 있거나 신규 등록을 신청할 수 있는지, 소개·메뉴·가격·시간 등을 고칠 수 있는지, seelo가 공식 권한 또는 접수 경로로 일을 도울 수 있는지 확인한다. 그다음 관광객의 이용 상황과 기존 AI 답변에서의 출처 관찰을 함께 본다.

출처에 자주 나타나는 플랫폼이라도 사업주가 직접 편집하는 서비스인지, 운영팀에 수정 제안을 보내는 서비스인지에 따라 지원 방식이 달라진다. 사장님에게 다시 여러 설문을 받기보다, 이미 모은 동일 지점의 사실을 각 플랫폼 형식에 맞춰 재사용하는 방향으로 설계한다.

## 2. 기존 실험에서 관찰한 출처

사용 자료는 [한국어 CLI 추천 정리표](../03_실험/ai-visibility-experiment/cli_한국어_탐색/확장분석/recommendations_clean.csv)다. 파일의 `agy`·`codex` 실행 경로에서 각각 120개, 총 240개 응답에 나온 1,200개 추천 행을 대상으로 `sources_raw_model_do_not_train`의 URL을 다시 집계했다.

## 6. 출처로 중요하지만 별도 접근이 필요한 곳

VisitSeoul·VisitKorea는 내부 관찰에서 자주 나타난 관광 정보 출처다. 미쉐린도 여러 응답에서 기재됐다. 다만 이번에는 이들에 대해 일반 사업주가 자유롭게 등록·편집하는 관리 경로를 확인하지 못했다. 기존 소개의 사실 정정·관광 정보 제보·편집 또는 제휴 접수 경로를 검증할 후보로 둔다.

미쉐린은 공식 도움말이 레스토랑 추천과 선정·평가원 절차를 따로 다룬다. 이를 사업주가 프로필을 만들어 목록에 즉시 등록하는 기능으로 설명하지 않는다. [미쉐린 선정 관련 공식 도움말](https://intercom.help/michelin-guide-apps/en/collections/9773306-the-michelin-guide-restaurant-selection)

관광·맛집 기사나 다른 사람이 쓴 리뷰는 수정 권한이 있는 가게 프로필과 구분한다. 현재 상품의 리뷰 답변 대행 제외 범위도 유지한다.

## 7. seelo의 확장 순서 제안

### 1차: 등록·정비 지원 상품을 구체화할 대상

Google·카카오를 기본으로 유지하면서 **Tripadvisor와 Bing**의 국내 매장 등록·인증·편집을 먼저 시험한다. 네이버는 공식 외부 관리 경로를 함께 확인한다. 확인된 필드부터 기존 기준 사실을 재사용하고 승인·반영 확인을 연결한다.

### 병행: 출처 관찰을 바탕으로 운영 경로를 검증할 대상

**다이닝코드·식신·뽈레·테이블링**의 신규 등록·사업주 권한·정보 수정 접수·제휴 여부를 확인한다. 이 순서는 내부 출처 관찰을 반영한 조사 우선순위다. 직접 편집·수정 제안·입점 신청을 서로 다른 작업으로 정의한다.

### 2차: 가게에 맞는 채널을 선택

예약·웨이팅을 운영하는 가게는 캐치테이블 글로벌·테이블링을, 공식 SNS를 운영하는 가게는 Instagram·Facebook을 검토한다. 동네 수요도 목표로 하면 당근·카카오톡 채널을, 중화권 고객이 목표라면 샤오홍슈를 추가한다. 가게마다 모든 플랫폼에 일괄 가입하도록 설계하지 않는다.

### 이후: 관광 편집 채널·국가별 기능 확대

VisitSeoul·VisitKorea 등은 정보 제보·정정의 접수 경로를 확인한 뒤 별도 지원으로 검토한다. Apple 지도는 한국의 장소 관리 지원 경로가 확인될 때 우선순위를 다시 정한다.

## 8. 각 후보를 지원 대상으로 확정할 때의 확인 항목

1. 같은 한국 지점을 찾아 기존 등록을 확인하고, 미등록이면 해당 업종·지역의 신규 신청이 가능한지 확인한다.
2. 사장님 인증과 외부 관리 권한 또는 공식 제안·제휴 접수 방법을 확인한다.
3. 실제 편집 가능한 칸과 반영 절차를 확인한다. 정보 정비만 가능한지, 별도 입점·계약이 필요한지 구분한다.
4. 기존 자료로 채울 수 있는 항목을 먼저 만들고, 사장님 보완 질문은 기존 신청 전체 최대 3문항 규칙을 유지한다.
5. 승인된 한 항목의 수정과 공개 반영을 시험한 뒤 지원 목록에 추가한다. 이후 같은 사실의 변경을 여러 플랫폼에 어떻게 반영할지 설계한다.

판정 결과는 ‘바로 편집’, ‘검수 접수’, ‘입점·제휴’, ‘사장님 실행 지원’, ‘경로 미확인’으로 기록한다. 실제 계정 시험 전에는 후보를 이미 연동·자동 정비 가능한 플랫폼으로 표시하지 않는다.
