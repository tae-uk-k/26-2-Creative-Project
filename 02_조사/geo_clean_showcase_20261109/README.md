# Google·카카오 지도 GEO 정보 정비 예시

2026-11-09 제작. 두 가게와 주소·전화·평점·리뷰 수·운영 조건은 가상 설정이다. 실제 지도에 게시한 자료가 아니다.

## 보기

- `index.html`: 두 지도 화면을 나란히 보는 비교 페이지.
- `google.html`: 소담면가 망원점, Google 지도 형식의 개별 페이지.
- `kakao.html`: 온담식탁 성수점, 카카오맵 형식의 개별 페이지.
- `preview.html`: 브라우저 검수 화면을 담은 단일 HTML. iframe이 제한되는 뷰어에서도 볼 수 있다.
- `images/`: 수정하지 않은 브라우저 검수 스크린샷 3장.

사진을 누르면 확대하고, 메뉴·사진·정보 탭을 누르면 해당 내용으로 이동한다. 길찾기·저장·공유는 화면을 표현하는 비작동 요소다. 온라인 지도 기능을 구현한 서비스가 아니다.

## 정리한 정보

| 구분 | 온담식탁 성수점 | 소담면가 망원점 |
|---|---|---|
| 소개 | 27자 한 문장, 수제비·제육의 특징 | 한 문장, 우동·소바·돈가스 특징 |
| 메뉴 | 메뉴명·가격·1인분·2인 세트 총액 | 메뉴명·가격·1인분·1인 세트 총액 |
| 구성 | 밥 포함, 돼지고기 중량, 세트별 수량 | 면 중량, 육수 제공 방식, 세트 구성 |
| 주문 조건 | 맵기 선택, 평일 세트 주문 시간 | 곱빼기 추가금, 세트 시간, 변경 추가금 |
| 기본 정보 | 주소·지점명·영업시간·마지막 주문을 전용 영역에 표시 | 동일 |

소개에 메뉴판 전체를 복사하지 않고, 가격·단위·필수 조건을 각 메뉴와 연결했다. 기존 가상 사례의 메뉴 가격은 그대로 사용했다. 알려지지 않은 예약·주차·알레르기 정보를 추가하지 않았다. 이미지나 지도 안에 숨긴 AI 전용 정보도 넣지 않았다.

## 사진·디자인

내장 `image_gen`으로 가상 식당별 2×2 사진 시트를 한 장씩 생성했다. 각 사진 시트는 실내·대표 메뉴·두 번째 메뉴·세트 사진 4컷으로 구성한다. 원본을 `assets/kakao_photos.png`, `assets/google_photos.png`에 보존했다. 화면에서는 CSS로 필요한 사진 구역을 표시하며, 생성 원본의 픽셀을 편집하지 않았다.

생성 프롬프트 전문은 `image_prompts.json`에 저장했다. 핵심 요청은 ‘같은 가상 식당에서 촬영한 일관된 자연광 음식·실내 사진 4컷, 글자·로고·테두리 없음’이다.

카카오의 로고는 프로젝트에 보존된 지도 UI 자료를 재사용했다. 글꼴·탭·색·사진·메뉴 정보 배치는 두 플랫폼의 기존 UI를 참고한 시안이다. 카카오와 Google의 원본 앱 화면을 그대로 캡처한 결과물은 아니다. 비교용 바깥 제목·플랫폼 표시는 정비 설명용 프레임이다.

## 확인

- 브라우저에서 비교 페이지와 각 개별 페이지의 사진·본문 표시를 확인했다.
- 각 개별 페이지에서 사진 확대·닫기 동작을 확인했다.
- 카카오 개별 페이지의 메뉴 탭 이동을 확인했다.
- 카카오 소개 40자 이내, 원래 가상 메뉴 6개 가격 유지, 필수 주문 조건 표시를 확인했다.
- JavaScript 구문 검사를 통과했다.

## 재생성

프로젝트 루트에서 `python 02_조사/geo_clean_showcase_20261109/build_showcase.py`를 실행하면 기존 가상 사례를 바탕으로 두 페이지와 비교 화면을 생성한다. 사진 파일은 이미 폴더 안에 있으므로 별도 요청 없이 표시된다. `showcase.css`와 `showcase.js`가 화면 스타일과 확대 동작을 담당한다.

기존 실험·비포애프터 파일은 변경하지 않았다. 연구 측정값이나 노출 개선 수치를 포함하지 않는다.
