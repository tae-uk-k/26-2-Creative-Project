# 조사 자료 안내

여기는 기획 판단에 사용한 근거와 사례를 보관하는 곳입니다. 현재 서비스 규칙은 [기획 문서](../01_기획/README.md)에서 확인합니다. 조사 문서의 수치·서비스 기능·관찰 결과는 각 문서가 확인한 시점을 기준으로 읽습니다.

| 찾는 내용 | 읽을 자료 |
|---|---|
| 서비스 문제와 배경, 주요 출처 | [서비스 배경과 근거](서비스배경과근거.md) |
| 지도 정비에 참고한 도구·논문·구체적 판단 사례 | [지도 정비의 근거와 판단 사례](지도정비_근거와판단사례.md) |
| 현재 AI 판단·질문 규칙 | [AI 수집과 최소 질문](../01_기획/AI수집과최소질문.md) |
| 현재 소개·메뉴·시간의 작성·반영 규칙 | [지도정보 정비 기준](../01_기획/지도정보정비기준.md) |
| 실제 실험과 구현 검증 | [실험 자료 안내](../03_실험/README.md) |

지도 UI 예시와 조사 시안은 설명을 위한 자료입니다. 실제 매장 수정·공개 반영·성과의 증거는 별도의 확인 기록으로 구분합니다. 여러 날짜의 조사 문서가 있어도 이를 서비스 기획서의 이전 버전으로 사용하지 않습니다.
