# 실제 지도 페이지의 추가 정보 항목 조사

확인일: 2026-11-09. 실제 공개 상세 페이지를 열어 HTML·탭·화면을 확인했다. 관리자 계정에서 수정·게시하지 않았다. 아래의 ‘공식 지원’은 공개 가이드의 범위이며, 해당 매장 관리자 화면에서 같은 입력 칸을 직접 확인했다는 뜻은 아니다.

## 앞선 시안에서 달랐던 점

앞선 `geo_clean_showcase_20261109`는 직접 작성한 CSS로 비슷한 화면을 만든 시안이었다. 실제와 동일한 복제라고 설명할 수 없었다. 이번 폴더에서는 실제 DOM을 복사하여 내용만 교체하고 원본 CSS를 연결했다.

- 카카오: 실제 `container-doc`, `top_basic`, `board_photo`, `tab_primary`, `list_goods`와 원본 SVG 아이콘을 사용했다. 메뉴의 사진·설명 행은 명동피자 실제 DOM에서 가져왔다. 카카오 본문은 내부 600px와 테두리를 합친 602px, 사진 격자는 552px다. 실제 페이지와 재현본의 메뉴 글꼴은 16px/20px, 탭은 15px/20px로 일치한다.
- Google: 실제 `m6QErb`, `TIHn2`, `RWPxGd`, `RcCsl`, `iP2t7d`와 메뉴·속성 DOM 및 Google 원본 CSS를 사용했다. 실제 상세 패널 너비 408px, 검색창 너비 376px를 유지했다. 임의로 만들었던 둥근 메뉴 카드나 가격 배치를 사용하지 않았다.
- 가상 매장명·소개·메뉴·이미지는 예시 값이다. 제목 길이와 정보 유무에 따라 높이가 변한다. Google 지도 배경은 참고 화면 이미지이며, 계정 표시를 가리고 가상 매장 라벨을 덧붙였다. 지도 캔버스의 실시간 검색·이동까지 복제한 것은 아니다.
- Google의 ‘소유자 설명’과 카카오의 소개 문구는 별도 정비 후보로 보존했다. 오늘 조사한 공개 화면에서는 해당 소개 블록을 직접 확인하지 못했으므로 임의의 소개 카드 UI를 넣지 않았다. 이번 화면은 실제로 읽은 메뉴·기본 정보·속성·태그 DOM을 사용한다.

## 실제 조사에서 발견한 정합성 문제

같은 ‘서울숲2길 44’ 주소의 파르코 공개 화면에서 카카오는 `11:30~21:30` 및 `15:00~17:00 브레이크타임`, Google은 `오후 10:30` 종료로 표시됐다. 서로 다른 채널 값을 임의로 정답 처리할 수 없다. 실제 정비에서는 업주의 최신 운영표와 각 관리자 화면을 대조할 필요가 있다.

공식 지원 문서에는 소유자가 수정할 수 있는 속성과 방문자 응답 등으로 채워지는 속성이 함께 존재한다고 설명돼 있다. 따라서 ‘지도에 보인다’와 ‘우리가 관리자 권한으로 입력할 수 있다’를 구분해야 한다.
