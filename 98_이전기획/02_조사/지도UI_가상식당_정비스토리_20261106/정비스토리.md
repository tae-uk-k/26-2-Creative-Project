# 가상 식당 지도 정보 정비 스토리

매장·소개·메뉴·메뉴판·가격은 모두 정비 과정을 설명하기 위한 가상 설정이다.

## 카카오맵 — 온담식탁 성수점

### 원래 상태

소개: 정성을 담은 한 끼, 온담식탁입니다.

메뉴: 수제비 9,000원 / 제육 11,000원 / 온담세트 28,000원

### 정비에 사용한 가상 원자료

- K1 기존 지도 소개: 정성을 담은 한 끼, 온담식탁입니다.
- K2 기존 텍스트 메뉴: 수제비 9,000원 / 제육 11,000원 / 온담세트 28,000원
- K3 가상 메뉴판 1페이지: 들깨수제비 9,000원 · 1인분 · 매장에서 반죽한 수제비 · 공깃밥 포함. 매콤제육정식 11,000원 · 1인분 · 돼지고기 200g · 공깃밥과 밑반찬 3종 포함. 온담 2인 세트 28,000원 · 2인 세트 총액 · 들깨수제비 1개 + 제육볶음 400g + 공깃밥 2개.
- K4 가상 메뉴판 2페이지 / 주문 안내: 들깨 육수는 매일 아침 매장에서 끓입니다. 제육에는 국내산 돼지고기를 사용합니다. 제육정식은 보통·덜 맵게 중 선택할 수 있습니다. 온담 2인 세트는 평일 11:30~14:00에만 주문할 수 있습니다.

### 정비 후

소개: 정성을 담은 한 끼, 온담식탁입니다. 매장에서 반죽한 수제비에 매일 끓인 들깨 육수를 더하고, 국내산 돼지고기로 제육정식을 준비합니다.

- 들깨수제비 9,000원 — 1인분 · 매장에서 반죽한 수제비와 매일 끓인 들깨 육수. 공깃밥 포함. (근거: K2, K3, K4)
- 매콤제육정식 11,000원 — 1인분 · 국내산 돼지고기 200g, 공깃밥, 밑반찬 3종 포함. 맵기 선택: 보통 / 덜 맵게. (근거: K2, K3, K4)
- 온담 2인 세트 28,000원 — 2인 세트 총액 · 들깨수제비 1개 + 제육볶음 400g + 공깃밥 2개. 평일 11:30~14:00 주문 가능. (근거: K2, K3, K4)

기존 지도에는 감성적인 소개 한 줄과 수제비·제육·온담세트의 가격만 있었다. 메뉴판 1페이지에서 정확한 메뉴명·인분·구성·중량을, 2페이지에서 조리 방식·원산지·맵기·세트 주문 시간을 추출했다. 기존 소개의 첫 문장은 유지하면서 실제 음식 특징을 보완하고, 모든 메뉴에 가격·판매 단위·포함 구성·해당 조건을 연결했다. 세트의 시간 조건을 가게 전체 영업시간으로 확대하지 않았다.

## Google 지도 — 소담면가 망원점

### 원래 상태

소개: 동네에서 편하게 즐기는 한 끼. 정성껏 준비하겠습니다.

메뉴: 소바 9,000원 / 우동 9,500원 / 소담세트 14,500원

### 정비에 사용한 가상 원자료

- G1 기존 지도 소개: 동네에서 편하게 즐기는 한 끼. 정성껏 준비하겠습니다.
- G2 기존 텍스트 메뉴: 소바 9,000원 / 우동 9,500원 / 소담세트 14,500원
- G3 가상 메뉴판 1페이지: 냉메밀소바 9,000원 · 1인분 · 메밀면 180g · 무즙·대파·와사비 · 육수 별도 제공. 유부우동 9,500원 · 1인분 · 가다랑어포·다시마 육수 · 유부 2장 · 면 곱빼기 +1,500원. 소담 점심세트 14,500원 · 1인 세트 총액 · 냉메밀소바 1개 + 미니돈가스 1개.
- G4 가상 메뉴판 2페이지 / 이용 안내: 돈가스는 주문 후 매장에서 튀깁니다. 소담 점심세트는 평일 11:30~14:00에만 판매합니다. 점심세트의 냉메밀소바를 유부우동으로 변경하면 500원이 추가됩니다.

### 정비 후

소개: 동네에서 편하게 즐기는 한 끼. 가다랑어포와 다시마로 우린 우동, 냉메밀소바와 매장에서 튀긴 돈가스를 준비합니다.

- 냉메밀소바 9,000원 — 1인분 · 메밀면 180g, 무즙·대파·와사비. 육수는 별도로 제공합니다. (근거: G2, G3)
- 유부우동 9,500원 — 1인분 · 가다랑어포·다시마 육수와 유부 2장. 면 곱빼기 +1,500원. (근거: G2, G3)
- 소담 점심세트 14,500원 — 1인 세트 총액 · 냉메밀소바 1개 + 주문 후 튀긴 미니돈가스 1개. 평일 11:30~14:00 판매. 유부우동 변경 +500원. (근거: G2, G3, G4)

기존 지도에는 분위기 위주의 소개와 소바·우동·세트의 가격만 있었고, 포함 구성과 선택 비용은 연결되지 않았다. 메뉴판에서 면 종류·중량·육수·토핑을 읽고, 이용 안내에서 돈가스 조리 방식과 점심세트의 시간·변경 추가금을 추출했다. 이를 소개의 음식 특징과 각 메뉴 설명으로 나누어 정리했다. 곱빼기 1,500원은 우동에, 변경 500원은 점심세트에만 붙였다.

자료에 없어 추가하지 않은 정보: 알레르기 전체 목록, 예약 가능 여부

## 디자인·자료 구분

카카오 UI는 앞서 확보한 원본 CSS와 메뉴·소개 카드 클래스를 재사용했다. Google UI는 원본 지도 화면의 바깥 틀과 측정한 메뉴 글자·간격을 바탕으로 재구성했다. 가상 상호·메뉴·가격이므로 실제 장소 URL과 연결하지 않았다. 실제 매장 사진은 사용하지 않고 가상 메뉴판 4장을 직접 만들었다. 실제 지도 게시나 AI 추천 측정은 하지 않았다. 기존 실제 매장 예시 폴더는 보존했다.
