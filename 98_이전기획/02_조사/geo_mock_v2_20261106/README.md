# 가상 식당 지도 정비 비교 v2

이전 버전은 그대로 보존했다. 사용자의 요청에 따라 두 가상 식당의 비포 문구를 더 미흡하게 구성했다.

- 소개: 반복 검색 키워드, 방문 요청, 모호한 판매 조건이 뒤섞인 문단.
- 메뉴: `수제비(인기)`, `제육`, `세트메뉴`, `소바(추천)`, `우동`, `세트`처럼 불명확한 이름.
- 설명: `메뉴판 참고`, `맵기는 말씀해주세요`, `점심만`, `변경 추가` 등 단위·구성·시간·비용이 연결되지 않은 표현.
- 애프터: 같은 가상 원자료에서 정확한 메뉴 이름·음식 특징·판매 단위·포함 구성·맵기·시간·추가금을 추출해 전용 칸에 연결.
- 메뉴 가격 6개는 동일하다. 실제 추천 측정 또는 실제 식당의 정보 정비 효과로 사용하지 않는다.

## 카카오 표시 보완

카카오 비교 JPG를 새 파일명으로 저장했다. `index.html`은 비교 이미지 두 장을 HTML 내부에 직접 포함한다. iframe, JavaScript, 외부 CSS, 로컬 서버가 없어도 비교 화면이 보이는 구조다. 이전 사용자의 카카오 미표시 원인은 브라우저 제어 제한 때문에 재현하지 못했으며 특정 원인으로 단정하지 않았다.

## 제작과 확인 범위

- `build_virtual.py`: 이전 원본 지도 CSS를 사용하는 소개·메뉴 HTML 8개와 가상 메뉴판 4장 생성.
- `export_comparisons.py`: 보존된 지도 UI 틀에 가상 문구를 정적 문서 이미지로 구성. 브라우저 캡처라고 표기하지 않는다.
- `build_preview.py`: 이미지가 포함된 단일 비교 HTML과 스토리 문서 생성.
- 최종 JPG는 이미지 뷰어로 직접 열어 확인했다. 모든 설명이 화면 범위 안에 들어가는지 좌표로 확인했다.
- 현재 이 채팅의 브라우저 제어가 `Local browser use is disabled in Work settings`로 차단되어 새 HTML의 브라우저 재검수는 수행하지 못했다. 설정 변경과 앱 재시작은 하지 않았다.
