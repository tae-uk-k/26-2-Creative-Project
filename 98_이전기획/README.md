## 현재 문서와의 관계

- **공통 기반:** 계정·인증·CSRF·작업 큐·배포는 지도 베타 때 만들어 쇼핑몰도 그대로 쓴다. 설계 배경은 [백엔드 구현계획](01_기획/개발/백엔드_구현계획/00_읽는순서.md)의 01(구조·환경)·05(인증·보안)·06(작업 큐)·13(코드 골격)을 참고한다. 현재 동작은 코드와 [서비스 명세서](../01_기획/개발/서비스명세서.md)를 따른다.
- **공통 구현 시험:** 단계 00~03·16, GCP·인프라 구축, 외부 키, 로컬 CLI AI, 자동 배포, 카카오 로그인 기록은 현재 [구현 시험](../03_실험/구현시험/)에 남겼다.
- **코드:** `04_MVP/seelo` 안의 지도 베타 기능 코드(가게 식별·진단·지도 정비·보고서)는 삭제하지 않았다. 문서만 옮겼다.
- **발표·디자인 자료:** `05_발표자료/결과물`의 지도 베타 시안은 발표 기록이라 옮기지 않았다.
