## ② 실제로 어떤 GEO 정보 특성이 달랐는가?

메뉴·가격이 연결되면 판매 단위가 없어도1점이라는 사용자 결정을 적용했다. 주요 메뉴·조건 전반이 명확해야2점이며, 일부 항목의 `250g`, `4pc`만으로 전체를2점 처리하지 않았다.

- **실제 이용 조건은 메뉴 탭 외 공식 예약에도 있었다.** 심퍼티쿠시에는 룸6~8인·최소주문200,000원, 누메로도스에는 예약6인까지·초과인원 연락·라스트오더20:00, 시칠리블루스에는2인 세트별 선예약·콜키지1병 조건이 확인됐다. 이들을 정보 미흡군으로 단정하지 않았다.
- **일부 매장은 주메뉴 전체에 적용되는 규정이 실제 메뉴판에 있었다.** 원조남산왕돈까스 명동본점의 `단 1인 1메뉴 주문 시` 밥·스프·샐러드 제공/리필 규정과 추가주문3,000원 할인 문구를 판독했다. 또또칼국수에는 `1인1메뉴 주문`, 보리밥 식사수량 제공 및 맛 조절 안내가 있었다.
- **판매 경로별 가격 차이와 같은 판매 경로의 충돌을 구분했다.** 정성의 매장 등심12,500원(210g)과 배달13,500원(200~220g)은 별도 경로다. 반면 채육·망원돈까스·장모님멸치국수의 지도 텍스트와 매장 메뉴판 가격 차이는 남겨 두었다.
- **전화번호가 다르다고 곧바로 타 지점으로 처리하지 않았다.** 미테이블의0507번호는 실제 스마트콜 연결 설명을 확인했다. 같은 지점의 시간 차이는 두 출처 값을 병기했다.
- **다른 가게 사진이 메뉴판 목록에 섞인 사례를 분리했다.** 누메로도스에 연결된 일부 메뉴판 분류 사진은 PIZZERIA LAGO 표기로, 해당 지점의 메뉴 단위 증거로 쓰지 않았다.

현재 43곳×3항목의 재검수 표에는 **23개 항목만 근거가 연결된 잠정 점수**, 나머지106항목은 미판정으로 남아 있다. 이는 점수0이 아니다. [항목별 재검수](analysis/복구후_판정검수_20261103_01/GEO_항목별_재검수.csv), [실제 문구·출처](analysis/복구후_판정검수_20261103_01/실제문구_출처표.csv).

이후 추가한 장모님멸치국수·파르코 공식 연결 관측은 최신 상세 원문에 보존했다. 장모님멸치국수에서는 `현금 계산시 1인당 찐계란1개`, `포장용기값 1인 메뉴당500원씩 추가`가 판독됐으며, 멸치국수 텍스트5,000원/사진6,000원 차이가 있어 A군·매칭 가격을 확정하지 않았다. 파르코 공식 연결에는 해당 지점 방문예약1~4명 안내가 확인됐으나 전체 조건 점수는 보류했다.

## ③ 추천 등장률은 각각 얼마였는가?

**A: 산출 불가 / B: 산출 불가 / B-A: 산출 불가.** 확정 표본0곳, 식당 추천 시도0회, 유효 응답0회이므로0%라고 적을 수 없다. 식당별 등장 횟수·평균 순서·질문별 차이도 미산출이다.

브라우저에서는 실제 지도 상세가 열렸다. 그러나 고정한 Codex CLI 0.166.0-alpha.5.1 / gpt-6.1-sol / 내장 live web search에서는 이번 복구 후 중립 점검에서도 카카오맵·Google 상세 열기가 `Internal Error`로 끝났다. **브라우저 복구와 CLI 검색 도구 복구는 별개다.** 로컬 설정이 꺼져 있다는 원인 추정은 하지 않았다.

최신 중립 시도: `readiness/20261103T045308643611Z-NEUTRAL-EXACT-DETAIL-T1.jsonl`. 종료코드0은 모델 응답 종료를 뜻하며 지도 접근 성공이 아니다. [7회 중립 점검 감사](analysis/상세검수_20261103_06/CLI_중립점검.json).

## ④ 추천 답변은 어떤 정보를 근거로 삼았는가?

식당 추천 응답이 없으므로 아직 말할 수 없다. 조사에서 발견한 정보 특징을 AI가 실제 추천 이유로 사용했다고 바꾸어 쓰지 않았다. 출처 사용률·사실 오류·조건 누락·지점 혼동 건수도 미산출이다.

## ⑤ 어떤 정보부터 정비할 필요가 있는가?

다음은 **이번 추천 성과로 검증한 우선순위가 아니라 상세 조사에서 실제 발견한 검수 항목**이다. 매장 정보는 수정하지 않았다.

1. 같은 지점·같은 판매경로의 메뉴 가격 차이를 확인한다. 배달·포장·매장 가격은 구분한다.
2. 대표 식사 메뉴에 인분·세트·수량·중량과 포함 구성을 연결한다.
3. 실제 적용되는 최소주문·예약 인원·주문마감·리필·추가비용을 해당 메뉴/서비스에 연결한다.
4. 지도·공식 안내의 영업시간과 지점 링크를 대조한다. 스마트콜은 연결 의미를 확인한다.

관찰 비교가 완료되더라도 기존 매장 상태 간 차이이며 실제 정보 정비 전후의 개선 효과로 표현하지 않는다. 현재 발표에 사용할 수 있는 A/B 등장률 문장은 없다.
