## ④ A/B의 실제 AI 노출률은 각각 얼마인가?

**A: 산출 불가 / B: 산출 불가.** 확정 쌍 0개, 집단별 매장 0개, 실제 식당 추천 시도 0회, 유효 응답 0회다. 이는 효과 차이 0 또는 노출률 0%를 의미하지 않는다.

가게 이름·집단·점수·가설을 숨긴 새 세션에서 추천하라는 순서를 지키기 위해 집단 미성립 상태에서 90회를 먼저 실행하지 않았다. 요청된 전체 실험의 완료 조건은 충족하지 못했다.

| 구분 | 실제 상태 |
|---|---|
| 90개 측정 셀 | 지역3 × 질문3 × 반복10 구성·난수20261103으로 순서 보존 |
| 식당 추천 호출 | 0회 |
| 미실행 | 90셀 |
| 실제 추천 호출 실패 | 0회 — 호출 자체가 없었음 |
| 원문 추천 답변·추천 추출 행 | 없음 — 만들어 채우지 않음 |
| 집단 노출률·매장별 노출률·쌍별 차이 | 미산출, null/빈칸 |

별도 준비성 점검에서는 Codex CLI `0.166.0-alpha.5.1`, 요청 모델 `gpt-6.1-sol`, live 웹 검색·low reasoning·read-only·새 빈 폴더·ephemeral 설정으로 **식당이 아닌 카카오맵 서비스 홈페이지 URL 질문**을 실행해 정상 종료를 확인했다. 실제 내부 모델 스냅샷 ID는 반환되지 않아 요청 모델명과 구분해 기록했다.

공식 지도 API의 별도 중립 점검은 Google HTTP403(IP 제한), Kakao HTTP401로 실패했다. 접근 설정은 변경하지 않았다. 이 API 오류는 90회 추천 측정의 실패 건수에 포함하지 않았고, 브라우저에서 수행한 지도 조사와도 구분했다. 90회를 실행하지 않은 직접 이유는 집단 미성립이다.

## ⑤ 어떤 질문과 매장 쌍에서 차이가 나타났는가?

**실제 추천 결과가 없어 질문별·쌍별 노출 차이는 판단할 수 없다.** 정보 표시 차이를 노출 차이로 바꾸어 보고하지 않는다.

예산·점심 시간·국적을 추가하지 않은 식사·첫 방문·대표 메뉴 질문 세 유형을 각 지역에 고정했다. 공통으로 카카오맵·Google 공개 정보 확인, 정확한 지점·추천 이유·메뉴·가격·출처·미확인 사실 추측 금지를 요청하도록 보존했다. 예비 문구의 `성수을`은 의미·조건을 유지한 문법 정정으로 `성수를`로 고쳤으며 실제 호출에는 어느 문구도 아직 쓰지 않았다.

질문 조건이 확정 표본에 공평하게 적용되는지에 대한 최종 판정 역시 집단이 없어 완료되지 않았다. 90셀 목록은 **실행 증거가 아니라 미실행 상태를 포함한 목록**이다.

## ⑥ 추천 답변이 실제로 어떤 정보를 근거로 삼았는가?

식당 추천 답변이 없으므로 확인할 수 없다. 조사자가 본 메뉴·조건·지도 URL을 모델이 실제 사용한 추천 근거라고 주장하지 않는다.

따라서 추천 이유별 사용 정보, 카카오·Google 실제 출처 사용률, 사실 오류·조건 누락률, 평균 추천 순서, 식별 불가 건수의 결과 해석은 모두 미실시다. 준비성 점검의 공식 홈페이지 링크를 식당 추천 출처로 바꾸어 집계하지 않았다.

## ⑦ 기존 매장 간 관찰 차이와 실제 정보 정비 효과를 구분하면 무엇을 말할 수 있는가?

이번 설계가 성립하더라도 기존 매장 간 관찰 비교다. 정보량·브랜드·방문객·리뷰 구성 등 잔여 차이와 실제 정보 정비 효과를 동일시할 수 없다. 실제 정비 이력이 확인되지 않은 매장에 SEO 적용/GEO 적용 이력 라벨을 붙이지 않았다.
