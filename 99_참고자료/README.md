# 참고 자료 안내

현재 기획에 직접 쓰지 않지만 계속 보관할 수업 자료를 둔다. 최신 기준은 [기획 문서 안내](../01_기획/README.md)에서 찾는다.

| 위치 | 무엇이 있는가 | 언제 보는가 |
|---|---|---|
| [과제자료](과제자료/) | 프로젝트 수업의 과제 자료 | 수업의 제출·과제 맥락을 확인할 때 |
| 작업자료 | 기존 임시 생성물·검수 스크립트를 옮긴 로컬 자료. Git 추적에서 제외한다. | 과거 작업을 추적할 필요가 있을 때만 |

서비스 선정 이전 주제, 지도 베타 화면 기준의 디자인 참고, 2026-11-09 정리 내역은 [이전 기획 보관](../98_이전기획/99_참고자료/)으로 옮겼다. 참고 내용을 채택할 때는 해당 주제의 현재 기준 문서만 고친다.
