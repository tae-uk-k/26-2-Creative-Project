# 참고 자료 안내

현재 서비스 기획에 직접 사용하지 않는 고유한 자료를 한 곳에 모았습니다. 이 폴더에는 변경 전 기획서나 같은 문서의 날짜별 사본을 쌓지 않습니다. 최신 기준은 [기획 문서 안내](../01_기획/README.md)에서 찾습니다.

| 위치 | 무엇이 있는가 | 언제 보는가 |
|---|---|---|
| [디자인참고](디자인참고/화면디자인참고.md) | 화면 구성에 참고한 국내외 공개 서비스의 관찰 기록입니다. | 배치·정보 밀도·입력 흐름의 참고가 필요할 때 봅니다. |
| [이전주제](이전주제/README.md) | 서비스 선정 이전의 아이디어 조사, 토론 팩트체커와 발표 코치 관련 고유한 자료입니다. | 과거에 검토한 주제와 조사 내용을 확인할 때 봅니다. |
| [과제자료](과제자료/) | 프로젝트 수업의 과제 자료입니다. | 수업의 제출·과제 맥락을 확인할 때 봅니다. |
| 작업자료 | 기존 임시 생성물·검수 스크립트를 이동한 로컬 자료입니다. | 과거 작업을 추적할 필요가 있을 때만 봅니다. Git 추적에서 제외합니다. |
| [정리 내역](정리내역.md) | 이번에 자료를 어디로 옮겼고 어떤 중복·이전 파일을 휴지통으로 이동했는지 설명합니다. | 이동된 파일의 위치를 찾을 때 봅니다. |

참고 자료에서 현재 기능을 다시 정의하지 않습니다. 참고 내용을 채택할 때는 해당 주제의 현재 기준 문서만 갱신합니다.
