# 네이버 시각 기준 확인 및 적용

확인일: 2026-11-11

네이버 전체 서비스에 동일한 하나의 공개 UI 규격이 있다고 가정하지 않는다. 이번 시안은 네이버 메인·검색의 시각 기준을 사용한다. 스마트플레이스·로그인 페이지의 다른 글꼴을 혼합하지 않는다.

| 항목 | 확인한 기준 | seelo 적용 |
|---|---|---|
| 배경 | 네이버 메인 body 실측 #FFFFFF | 모든 제품 화면 흰색 |
| 본문 글자 | 네이버 메인 body 실측 #2E2E2E | 동일한 중성 회색 |
| 글꼴 | -apple-system, BlinkMacSystemFont, Malgun Gothic, 맑은 고딕, helvetica, Apple SD Gothic Neo, sans-serif | 동일한 시스템 스택. Windows는 맑은 고딕. Pretendard 강제 지정 제거 |
| 메인 카드 | 뉴스스탠드 실측 radius 8px | 카드 8px, 입력·버튼 4px |
| 브랜드 컬러 | 공식 브랜드 가이드 #03C75A | 지표 막대·상태 점 |
| 주요 버튼 | 메인 실시간 CSS --color-primary-background-default #03A94D | 해당 채움 + 흰 글자 |
| 레이아웃 | Figma 223:541의 각 화면 | 기존 10개 구조 유지 |

## 서비스별로 구분한 내용

- 메인: 시스템 글꼴을 실제 적용하고 있음.
- 로그인 CSS: Pretendard를 기본 변수로 선언. 메인의 글꼴이라고 일반화하지 않음.
- 스마트플레이스 CSS: 시스템 스택과 NanumSquareNeo 계열을 별도 선택자에서 선언. 메인과 혼합하지 않음.
- 커뮤니티 DESIGN.md는 공식 규격이 아니므로 원본 CSS 및 실제 화면 실측을 우선함.

## seelo에 맞춘 조정

- 메인 포털의 14.7px 본문을 그대로 축소하지 않고, 기존 사용자 요구에 맞춰 본문 17px·메타 16px로 조정.
- 큰 제목 30px·대시보드 28px, 주요 버튼 20px·700은 seelo용 크기 조정. 네이버 전사 표준이라고 주장하지 않음.
- 네이버의 서비스별 여러 강조색 중 사용자가 요청한 그린만 사용. 플랫폼 원본 로고는 보존.
- 민트빛 캔버스, 올리브색 본문, 큰 연녹색 패널과 20px 카드 모서리 제거.
