# seelo 서비스 화면 10개

- 기준: Figma `223:541`의 최종 디자인.
- HTML 디자인 검토용이며 가입·인증·정비 등 서비스 기능은 연결하지 않았다.
- 상단 네비게이션, 중앙 제목, 화면별 카드 구조를 유지했다.
- 강조색은 그린으로 제한한다. 지표 `#03C75A`, 주요 버튼 `#03A94D`, 본문 `#2E2E2E`와 흰 배경 `#FFFFFF`를 구분한다. 내부 화면에 지도 배경을 사용하지 않았다.
- 최신 기획의 Google·카카오 우선 정비, AI 선조사, 누락 정보 최소 질문, 준비된 변경만 승인하는 방식을 반영했다.
- 정비안과 보고서는 원본처럼 중앙 한 열의 세로 화면이다.

## 확인

`index.html`에서 10개 화면을 각각 열 수 있다. 각 화면 아래의 ‘다음 시안’은 디자인 비교용이다.

## 다시 생성

이 폴더에서 `npm install`, `npm run build` 실행. 실제 `@toss/tds-mobile` 2.5.1의 버튼·입력란·체크박스·리스트·진행률을 정적 HTML로 렌더링한다.

## 검수

- 10개 HTML HTTP 200 및 참조 에셋 존재 확인.
- 이전 버전은 브라우저 데스크톱 1280px, 모바일 390px에서 확인했다.
- 네이버 메인 기준 개편 후 Chrome 실제 데스크톱 1800px·모바일 CSS 390px에서 10개 화면의 배경·글꼴·가로 넘침을 확인했다.
- 네이버 메인 원본과 수정한 화면의 계산된 스타일을 직접 비교했다. 캡처: `검수/네이버기준_내가게.jpg`, 결과: `검수/네이버기준_브라우저검수.json`.
- 화면별 원본 노드: `화면목록.json`.
- 브라우저 캡처: `검수/`.

## 네이버 메인 기준 적용

- 기준과 원본 출처: [디자인기준_확인.md](디자인기준_확인.md).
- 배경 #FFFFFF, 본문 #2E2E2E, 시스템 글꼴(Windows 맑은 고딕)로 통일했다.
- 카드 8px, 버튼·입력란 4px, 지표 #03C75A, 주요 버튼 #03A94D와 흰색 글자를 적용했다.
- 본문 17px·보조 16px는 가독성을 위해 seelo에 맞춘 조정이다.
- 민트 배경·초록빛 본문·대형 둥근 카드를 제거했다.
- 원본 Figma의 화면 구조와 10개 화면 수를 유지했다.

추가 페이지는 사용자 피드백과 승인 후 제작한다.
