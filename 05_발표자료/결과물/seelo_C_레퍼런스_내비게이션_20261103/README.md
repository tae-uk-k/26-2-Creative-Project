# 시안 C 내비게이션 재설계

2026-11-03 / 발표자료 모음 12:2 / C 620:11 / 전체 9장

## 확인한 기준

- Apple 디자인 스킬: 시각적 위계, 절제된 표면, 일정한 간격.
- Toss Design System 스킬: 중립색과 명확한 상태 구분. 모바일 컴포넌트를 데스크톱 내비게이션에 그대로 쓰지 않고 원칙만 반영.
- https://www.ascent.me/ : 로고와 메뉴의 크기 대비, 흰색 헤더와 얇은 경계.
- https://linear.app/ : 간결한 메뉴와 명확한 타이포 위계. 어두운 색상은 차용하지 않음.
- https://www.framer.com/ : 메뉴 간 간격과 로고 비율 확인.

## 반영

- 하나의 감싸는 도형 유지: 1728 × 88, 모서리 20.
- 흰색 표면, 연회색 1.2px 테두리, 작은 그림자.
- 메뉴 첫 위치 x440 → x244로 옮겨 로고 옆 빈 공간 감소.
- 메뉴 글자 22 → 24, 현재 장 SemiBold / 나머지 Medium.
- 현재 장 #FFC54F, 비활성 글자 #6B7684.
- 9장 모두 수동 편집 구조 유지.

## 검증

- 9장 본문 해시 변경 없음.
- 원본·A·B 시안 해시 변경 없음.
- C 프로토타입 연결 0개 유지.
- 내비게이션 자식 범위 넘침 0개, 장별 선택 항목 1개.
- 누락 폰트 없음. 내비게이션 오토레이아웃 0개.
- 실제 렌더 확인: 초기 get_screenshot 캐시가 이전 화면을 반환해 node.screenshot으로 최신 화면을 확인함.
