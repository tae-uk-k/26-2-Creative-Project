# 시안 C 첫 페이지 글라스 가게 개선

- 복사본: https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC/?node-id=796-12
- 위치: 발표자료 모음 / 시안 C의 오른쪽 / 시안 C · 1페이지 · 글라스 가게 개선
- 원본 620:12 보존. 원본 C 9장과 가게 외 텍스트·배치 변경 없음.
- 글라스모피즘 스킬 참고: 투명도, 반사광, 밝은 유리 가장자리, 겹침과 그림자.
- 앰버와 클리어 유리를 교차한 차양, 두꺼운 유리 정면·측면, 반사광과 창빛, 간판 비율 수정.
- 편집 가능한 도형 31개와 텍스트 1개. 이미지로 평탄화하지 않음.
- 유리 효과 9개, 오토레이아웃 0개, 프로토타입 연결 0개.
- 원본 가게는 복사본 안에 숨긴 레이어로도 보관.
