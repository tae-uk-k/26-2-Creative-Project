# seelo 옐로우 색상 비교

원본 52개 노드를 보존하고, 도형 6종 × 색상 8종으로 48개 비교안을 같은 피그마 페이지 오른쪽에 추가했습니다. 모든 복사본의 글자 로고는 검정입니다.

- 단색·배색: https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC?node-id=400-2
- 배색·그라데이션: https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC?node-id=400-220
- 기준색: 카카오 옐로우 #FEE500
- 공식 색상 출처: https://developers.kakao.com/docs/ko/kakaologin/design-guide

K01 옐로우 단색 / K02 차콜 / K03 코발트 / K04 플럼 / K05 코퍼 / K06 크림·옐로우·골드 / K07 옐로우·오렌지 / K08 옐로우·라벤더

검증: 원본 속성 변경 0개, 비교안 48개 글자 검정 확인, 영역 밖 요소 없음. 두 보드 스크린샷으로 시각 검수 완료.
