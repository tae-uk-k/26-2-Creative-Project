## 디자인 결정

기존 08_window_stage.html의 멀티윈도 랜딩을 기준으로 새로 디자인했다. 앞서 만든 키네틱 기반 HTML을 옮긴 것이 아니다.

- 흰색 바탕과 중립 회색, 명확한 블루 행동 색상
- 어두운 테두리 대신 미세한 구분선과 옅은 그림자로 창 표현
- 얇은 창 헤더와 편집 가능한 기하학적 가게 모형으로 랜딩의 시각 언어 유지
- 상단 메뉴를 사용하는 가벼운 웹 서비스 구조
- 진단: 모델별 지표 → 주변 가게 비교 → 질문과 참고 출처 → 정보 정비 신청
- 정비안: 진단 요약 → 문제 → 변경 전후 → 필수 확인 → 승인
- 전후 비교: 모델별 변화 → 주변 가게 변화 → 질문별 변화 → 실제 반영한 정보
- 모바일: 열을 단순화하고 변경 전후를 세로로 배치. 본문 16px 중심, 56px 버튼

원본 와이어프레임에서 오래된 ‘지도·SNS별 수정 문구 제공’, ‘지도 연결 보류’는 새 디자인에 적용하지 않았다. 현재 기획서의 Google·카카오 직접 정비와 승인·2주 뒤 재측정을 반영했다.
