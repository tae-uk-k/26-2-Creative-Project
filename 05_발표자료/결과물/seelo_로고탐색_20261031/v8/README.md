# 선택한 두 로고의 라운드 추가

첨부 이미지에 해당하는 기존 P06·P12 SVG 원본을 사용했다. 래스터를 다시 그리거나 새로운 패턴으로 바꾸지 않고, 네 조각의 배치와 큰 곡선을 유지하며 각 조각의 모서리를 필렛 처리했다.

- D01: 첫 번째 패턴 / 약한 라운드 (원본 120좌표 기준 2.6)
- D02: 첫 번째 패턴 / 더 둥근 라운드 (5.2)
- D03: 두 번째 패턴 / 약한 라운드 (2.6)
- D04: 두 번째 패턴 / 더 둥근 라운드 (5.2)

기존 v7 비교판에 네 안을 추가하고, v8/index.html에는 추가된 안만 모았다. SVG 24개는 원본 구성 4개와 Figma 내보내기 20개다. HTML과 svg 폴더를 함께 보관한다.
