# seelo 로고 조형 07

삼각형을 나열하는 방식에서 벗어나 합집합·차집합으로 외곽과 내부 여백을 함께 설계한 네 안. 외곽과 내부 모서리를 라운드 처리했다.

삼각형 개수는 더하는 기본 도형과 파내는 기본 도형을 모두 포함한다. 최종 심볼의 채움 비율은 seelo 글자를 제외한 120×120 정사각형에서 계산했다. 합집합과 차집합, 코너 보정을 적용한 실제 벡터 면적이다.

| 안 | 구성 | 기본 삼각형 수 | 채움 |
|---|---|---:|---:|
| B01 | 삼각형 하나에서 두 삼각형을 파내 획의 굵기를 만든 구성. | 3 | 35.44% |
| B02 | 반전된 두 삼각형에 각각 삼각형 여백을 둔 구성. | 4 | 63.85% |
| B03 | 두 삼각형을 겹쳐 합친 뒤 중심 삼각형을 비운 구성. | 3 | 57.2% |
| B04 | 세 삼각형을 합쳐 연결하고 작은 삼각형 여백을 둔 구성. | 4 | 56.32% |

index.html과 svg 폴더를 함께 보관한다. SVG 글자는 윤곽선으로 변환되어 설치 폰트 없이 열린다. 폰트와 심볼은 Figma 원본에서 수정할 수 있다.
