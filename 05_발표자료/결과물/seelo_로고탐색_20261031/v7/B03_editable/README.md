# B03 삼각형 편집본

[피그마 편집 프레임](https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC/창의프로젝트?node-id=384-2)

기존 완성 로고를 보존하고, 같은 페이지 오른쪽에 ‘B03 / 삼각형 편집’을 추가했다.

- 01: 왼쪽 검정 면
- 02: 오른쪽 검정 면
- 03: 가운데를 비우는 삼각형

오른쪽 세 벡터는 각각 독립된 도형이며 꼭짓점은 3개다. 이동·회전·크기·모서리 라운드를 개별 조절할 수 있다. Enter로 벡터 편집에 들어가 꼭짓점을 움직인다.

왼쪽 조립본은 (01 + 02)에서 03을 빼는 라이브 Boolean이다. 레이어를 펼쳐 내부 삼각형을 수정하면 조립 모양이 바뀐다. 원래 완성본은 건드리지 않았다. 새 편집본은 원래 삼각형 좌표를 복원한 것이며, 원래 완성 벡터에 적용했던 교차부 후처리 대신 각 꼭짓점의 네이티브 라운드를 썼다.

triangle-01.svg~triangle-03.svg는 독립 파일이다. SVG 내보내기본과 별개로 Figma 원본은 세 꼭짓점과 라운드 수치를 유지한다.
