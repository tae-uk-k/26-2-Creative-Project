# seelo 로고 탐색 02

추상 패턴 12안(P01–P12), 폰트 12안(F01–F12), 각각 단색·반전·그라데이션 총 72개.

패턴은 특정 사물이나 서비스 의미를 그리지 않고 삼각형, 사각형, 사분원, 사선과 곡면의 비율·반복·여백을 조합했다. 글자와 심볼은 Figma에서 편집할 수 있다.

비교: `index.html`. 원본: `svg` 폴더. 폰트 글자는 SVG 내보내기에서 윤곽선으로 변환했다. HTML과 svg 폴더를 함께 보관한다.

[피그마 폰트](https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC/창의프로젝트?node-id=366-3)
