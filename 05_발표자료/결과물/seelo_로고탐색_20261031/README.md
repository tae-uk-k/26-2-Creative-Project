`index.html`을 열어 비교한다. 번호 옆 체크박스를 고르고 ‘선택한 안만 보기’를 켜면 선택 방향만 남는다. 브라우저를 닫으면 선택은 유지되지 않는다.

`svg` 폴더의 45개 파일은 피그마에서 내보낸 원본이다. 텍스트를 벡터 윤곽선으로 변환했으므로 폰트가 없어도 동일한 모양을 유지한다. 흰색 반전 SVG는 투명 배경이므로 어두운 배경에서 확인한다. HTML과 svg 폴더를 함께 유지한다.
