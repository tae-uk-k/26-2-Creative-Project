# seelo 로고 탐색 09 · 삼각 조형 패턴

6개 방향 / 흑백·반전·흑백 그라데이션. 기존 로고와 파일은 교체하지 않았다.

삼각형은 더하는 도형과 파내는 도형을 합쳐 4개 이하. 120×120 정사각형에서 합집합·차집합·라운드 적용을 반영한 최종 벡터 면적을 계산했다. 글자는 제외한다.

|안|패턴 규칙|삼각형 수|채움|
|---|---|---:|---:|
|E01|반전된 두 면 · 같은 비움 반복|4|58.67%|
|E02|세 삼각형 · 대각으로 이어지는 적층|3|43.36%|
|E03|평행 대각 · 삼각 비움의 반전|4|41.51%|
|E04|위아래 반전 · 두 삼각 비움|4|58.33%|
|E05|같은 삼각형 · 90도 회전 반복|4|67.71%|
|E06|두 크기의 삼각형 · 대각 맞물림|4|50.87%|

[Figma 전체 비교](https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC/창의프로젝트?node-id=388-2)

Figma의 ‘seelo · 로고 09 · 삼각 조형 패턴’ 페이지 위쪽에는 완성본, 아래쪽에는 원본 삼각형 23개의 독립 벡터가 있다. 각 도형의 꼭짓점은 3개이며, 위치·회전·크기·라운드가 개별 편집 가능하다. 검정은 더하는 면, 회색은 파내는 도형이다. 완성본은 교차부 곡선 후처리가 포함된 벡터이며, 분리본은 재조합용 원본 좌표다.

파일:
- index.html: 여섯 안 비교, 흑백·반전·그라데이션 전환, 선택 필터
- svg/*-lockup.svg: 심볼과 글자 조합
- svg/*-word.svg: 글자 윤곽선
- svg/*-A/B/C-mark.svg: 심볼 단독
- svg/*-part-01.svg 등: 원본 삼각형 23개 단독 파일
- svg/*-source.svg: 재현 스크립트의 완성 벡터
- build_patterns.py / geometry.json: 원본 삼각형 좌표, 조합, 면적 계산
- pattern-preview.png: 단색 심볼 비교

HTML과 svg 폴더를 함께 보관한다.
