# seelo 쇼핑몰 랜딩페이지 시안

[세 시안 비교](index.html)에서 각 랜딩과 모바일 미리보기를 열 수 있다. 스마트스토어·카페24 판매자가 상품 정보를 점검하고 정비안을 승인하는 서비스의 디자인 시안이다.

| 시안 | 화면에서 보여주는 내용 | 룩앤필 |
| --- | --- | --- |
| [기하학형](geometry.html) | AI에 보내는 구매자 질문을 정비안으로 연결한다. 호환 크기와 보관 방식의 변경 내용을 직접 전환해 볼 수 있다. | [bauhaus-design](https://github.com/capsrock/bauhaus-design-skill)의 비대칭 열 배치와 원호를 적용했다. |
| [타이포그래피형](typography.html) | 한 문장의 질문에서 시작해 변경 전후 설명을 대조한다. 이용 순서를 세로로 읽는다. | [web-typography](https://github.com/simongonzalezdc/web-typography-skill)의 유동 크기와 행간 규칙을 적용했다. 한글 명조 제목과 시스템 고딕 본문을 사용한다. |
| [이미지 중심형](photography.html) | 정비 화면을 대표 이미지로 보여준다. 진단, 승인, 공개 확인 화면을 단계별 이미지로 배치했다. | 사진 구도를 잡을 때 사용하던 시선과 컷 역할 기준을 서비스 화면에 적용했다. 메인 화면 하나를 크게 두고 과정별 이미지를 따로 배치했다. |

## 화면의 근거

- 상품 선택, 자료 확인, 정비안 승인, 상세페이지 반영과 공개 확인은 프로젝트의 현재 작업 흐름에서 가져왔다. [쇼핑몰 관리자 화면 자동화](../../../01_기획/개발/쇼핑몰_관리자화면자동화.md)
- 접이식 노트북 거치대와 스펙은 흐름을 설명하기 위한 샘플이다. `assets/screens/`의 이미지는 이 샘플을 바탕으로 구성한 서비스 화면 시안이다.
- 화면 목업은 정적 HTML과 CSS로 만들고 Chromium에서 렌더링했다. 데스크톱과 모바일에 맞춰 대표 이미지의 구성과 글자 크기를 조정했다.
