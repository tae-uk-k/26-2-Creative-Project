# seelo 제품 화면 디자인

기준: `01_기획/한눈_기획서.md`의 9장 화면 구성, `01_기획/한눈_명세서.md`의 화면 범위.
시각 기준: 기존 `07_kinetic.html`과 `assets/kinetic-live.css`.

## 열기

- 전체 화면 목록: `http://127.0.0.1:8769/12_product_design/index.html`
- 내 가게: `S07.html`
- 무료 진단 결과: `S11.html`
- 정비안 확인: `S13.html`
- 정비안 확인 완료 상태: `S13-ready.html`
- 전후 비교: `S16.html`
- 디자인 시스템: `DS.html`

기존 S01 키네틱 랜딩은 수정하지 않았다. 화면 목록의 ‘키네틱 랜딩’에서 열 수 있다.
새 디자인은 35개이며, 전체 목록과 미리보기용 HTML 6개를 별도로 제공한다.

## 범위

디자인과 화면 이동만 제공한다. HTML/CSS로 내보냈으며 서비스 기능은 구현하지 않았다.

- API 호출, 회원가입, 인증, 이메일 발송, AI 측정, 지도 연결, 지도 수정, 저장 없음
- 링크는 다음 디자인 화면을 보여 주는 용도
- 운영 버튼은 스타일만 제공하며 실제 승인·거절·탈퇴를 실행하지 않음
- 별도 하단 ‘화면 목록’ 도구는 디자인 검토용이며 실제 서비스 UI에 포함하지 않음
- 화면의 가게·이메일·수치·측정일·정비 내역은 디자인을 채우는 고정 데이터이며 실제 운영 결과가 아님
- 실제 seelo 초대 계정과 법적 문서는 확정된 자료를 연결하는 자리만 디자인함

## 디자인 시스템

토큰은 `assets/design.css`의 `:root`에 모았다.

| 구분 | 규칙 |
|---|---|
| Coral | `#f15a36` / 강조 타이포·기하 도형 |
| Blue | `#304fbb` / 정보·선택 상태 |
| Ink | `#202b3b` / 기본 글자 |
| Primary | `#243a6b` / 주요 버튼 |
| Cream | `#fff2d9` / 가게 모형 배경 |
| 서체 | 로컬 Pretendard Variable |
| 크기 | 페이지 제목 42px, 섹션 24px, 소제목 18px, 본문 16px, 보조 14px |
| 모바일 | 제목 31px, 본문 15px, 입력 16px |
| 간격 | 4·8·12·16·24·32·40·48px |
| 표면 | 흰색 기본, 중립색 1px 구분선, 카드 8px·버튼 5px 반경 |
| 도형 | 원·기울어진 캡슐·아치, 인증·빈 상태에 집중 |
| 움직임 | hover 180ms, 화면 타일 250ms; 제품 화면에는 스크롤 스냅 없음 |
| 반응형 | 1180px·960px·720px 기준으로 열과 메뉴를 조정 |

### 공통 컴포넌트

- Button: primary / secondary / text / small / disabled. 키보드 포커스 표시 포함.
- Field: 기본 / 도움말 / 오류. 각 필드와 라벨 연결, 이메일·비밀번호 입력 타입 구분.
- Badge: 기본 / 정보 / 확인 필요. 색상과 상태 문구를 함께 사용.
- Navigation: 사이드 메뉴 / 좁은 화면의 펼침 메뉴 / 페이지 내 탭.
- Data: 모델별 지표, 전후 비교, 질문별 결과, 출처 목록, 주변 가게 표.
- Feedback: 단계 진행, 정상 0%, 측정 실패, 승인 확인, 탈퇴 확인.
- Plan: 현재 값 → 변경 값, 지도별 탭, 확인 필요 입력, 승인 대기·완료 상태.

무료 진단에는 구체적인 정비 내용을 노출하지 않는다. 상세 정비안은 연결 이후 화면에만 배치했다.
Google의 관리자 권한과 카카오의 운영자 권한을 구분했다. 계정 비밀번호 입력으로 지도를 연결하는 화면은 만들지 않았다.

## 소스와 내보내기

`build.cjs`는 디자인 작성·내보내기용이다. 브라우저에서 실행되는 서비스 스크립트가 아니다.

```powershell
node build.cjs
```

실행하면 이 폴더 안의 디자인 HTML과 `screens.json`을 다시 생성한다. 생성된 HTML을 직접 수정하기보다 `build.cjs`와 `assets/design.css`를 수정한다.
출력 파일을 열 때 `assets` 폴더와 상위 폴더의 로컬 폰트를 함께 유지해야 한다.
