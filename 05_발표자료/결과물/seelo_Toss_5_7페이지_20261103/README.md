## 수정 사항

- 2장: 원형 그래프를 숨기고 이전의 174px 파란 `53%` 숫자로 복원했다. 축약한 설명은 유지했다.
- 3장: 이전 토스 버전의 본문 38px·40px Bold와 원래 강조 색상, 세 단계 도식의 크기·간격을 복원했다. 추가했던 화살표는 숨겼다. 발표자 이름은 복원하지 않았다.
- 4장: 주제를 `서비스 개념과 핵심 기능`으로 수정했다. 사용자 요청 문구 `구글·카카오의 메뉴·가격·영업시간 등을 대신 고쳐주기`를 핵심 기능 안에 넣었다. 승인·반영 설명은 작은 두 행으로 줄이고, 원본의 5단계 흐름과 역할 분담을 유지했다.
- 5·7장: 백지 원본과 관련 제품 와이어프레임의 내용·연결을 대조해 제작했다. 구체적인 출처는 `와이어프레임_반영표.md`에 기록했다.
- 1장과 기존 표지 비교안의 디자인은 유지했다. 본문 페이지에는 이름을 넣지 않았다.
- 새 5·7장은 기존 1~4장 아래에 두고, 공통 요소와 표지 비교 구역은 그 아래로 옮겼다. 원래 발표자료 번호를 유지하기 위해 분모 없는 `01`·`02` 형식으로 번호를 표시했다.
- 이전 4장은 초안 구역의 `580:63`에 보관했다. 원본 백지 PPT와 Apple 시안은 수정하지 않았다.

## 검수

- 각 장 1920 × 1080, 편집 가능한 텍스트·도형·벡터·컴포넌트.
- 실제 Figma 렌더링 `전체구성.png`로 시각 검수.
- 최종 텍스트 겹침 0, 누락 글꼴 0, 자동 레이아웃 부모 밖 텍스트 0.
- 원본 4·5·7장 텍스트 변경 0. 원본 전체 루트 포함 269개 노드 유지.
- 원문 대응 39개는 기록된 텍스트와 일치. 5장 `매장 정보 자동정비` 표시명만 사용자 요청에 맞춰 `구글·카카오 정보 수정`으로 변경했다.
- 현재 보이는 1–5·7장에 `자동정비` 표기 0. 이름은 표지에만 표시.
