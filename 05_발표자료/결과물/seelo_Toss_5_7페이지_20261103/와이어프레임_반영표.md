# 와이어프레임과 백지 PPT 반영표

백지 PPT의 장별 주제와 범위를 기준으로 만들고, 실제 제품 와이어프레임의 기능·순서·용어와 대조했다.

| 발표 장 | 백지 PPT | 반영한 내용 | 대조한 제품 와이어프레임 |
| --- | --- | --- | --- |
| 4 · 서비스 개념과 핵심 기능 | 468:42 | 핵심 기능 안에 지도 정보 대신 수정, 실제 정보 확인·승인, 지도 반영·결과 기록, 5단계 사용 흐름 | 214:544 정비안 확인·승인 / 214:634 정비 진행·반영 결과 |
| 5 · 개발 범위 · 후속 개발 | 468:100 | 진단: AI별 등장률·순서, 출처, 주변 가게, 수정 항목. 수정: 기존 정보·출처 대조, 승인, Google·카카오 반영, 변경 이력. 비교: 2주 뒤 동일 조건 재측정, 전후 비교, 반영 상태. 베타 범위 및 후속 개발 3개 | 213:917 무료 진단 결과 / 214:544 승인 / 214:634 반영 / 215:285 전후 비교 |
| 7 · 시스템 아키텍처 · 데이터 흐름 | 468:127 | Frontend → Backend → PostgreSQL → Worker → 외부 연동의 원본 연결 방향. 가게 등록 → 정보 수집 → 질문·AI 측정 → 추천 추출·지표 → 저장·화면 표시. 3문항×2개 AI×10회, 3초마다 진행 조회, 실패 호출 별도 기록 | 213:805 수집·측정 진행 / 213:917 무료 진단 결과 |

- 핵심 기능의 표시명은 사용자 요청에 따라 `자동정비` 대신 `구글·카카오의 메뉴·가격·영업시간 등을 대신 고쳐주기`로 바꿨다.
- 기존의 큰 승인·반영 목록 두 개는 현재 4장에서 숨기고, 작은 두 행으로 요약했다.
- 5장 원본 `매장 정보 자동정비` 제목도 `구글·카카오 정보 수정`으로 통일했다. 아래 기능 항목은 원문을 유지했다.
- 원본과 와이어프레임의 메뉴 가격이나 성과 수치를 새롭게 만들어 넣지 않았다.
- 5·7장은 요약 발표용이다. 전체 제품 화면을 축소 이미지로 넣은 구성이 아니라 원본의 정보 단위·연결을 편집 가능한 텍스트·도형으로 다시 배치했다.
