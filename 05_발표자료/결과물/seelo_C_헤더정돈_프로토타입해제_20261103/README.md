# 시안 C 헤더 정돈 · 프로토타입 해제

[Figma 2장](https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC?node-id=620-67)

- 범위: 발표자료 시안 C 9장. 방금 추가한 C 내부 메뉴·로고 등의 프로토타입 연결 152개 모두 제거. 남은 연결 0개.
- 상단 바 높이 112 → 96px, 메뉴 영역 높이 100 → 44px, 메뉴 글자 26 → 22px로 정돈.
- 흰색 평면 헤더, 왼쪽 로고와 오른쪽 메뉴. 그림자·돌출 강조선 없음.
- 현재 장은 진한 글씨와 옅은 회색 선택 배경, 나머지는 #8B95A1.
- 기존 강조 밑줄 레이어는 비표시로 보존. 바 안쪽으로 위치를 맞추고 클리핑 적용.
- 헤더 및 표시 요소 프레임 밖 넘침 0, 자동 레이아웃 0, 글꼴 누락 0.
- 9장 본문 서명 동일. 다른 파란색·A·B 시안 변경 없음.
- 별도 서비스 프로토타입 페이지와 디자인 원본은 이 C 내비게이션 수정 범위에 포함하지 않음.
