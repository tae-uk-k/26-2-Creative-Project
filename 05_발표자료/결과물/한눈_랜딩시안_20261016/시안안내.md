# 한눈 랜딩 페이지 시안 3종

`index.html`을 열면 시안을 전환하며 PC·모바일 폭으로 비교할 수 있습니다.

- 01 차분한 서비스형: 흰 배경·남색·결과 미리보기. 기본 방향으로 추천.
- 02 편집물형: 아이보리·짙은 녹색·명조 제목. 사장님에게 차분히 말을 건네는 구성.
- 03 리포트 중심형: 짙은 상단·실제 도구처럼 보이는 넓은 결과 예시.

각 HTML은 CSS·JS를 내장하여 개별 파일만으로 열 수 있습니다. 외부 이미지·글꼴·라이브러리 로딩이 필요하지 않습니다. `index.html`에서는 같은 폴더의 시안 세 파일을 불러옵니다.

무료 진단 버튼은 시안용 입력 창을 엽니다. 지도 주소 형식 확인과 결과 예시 이동만 동작하며 입력 정보는 저장·전송하지 않습니다. 실제 가입·AI 측정·결제는 연결하지 않았습니다. 리포트의 가게와 수치는 모두 가상 예시입니다.

기준: 2026-10-16 한눈 기획서. 총 60회 측정 / 계정당 무료 1회 / 무료에는 개선점 개수, 유료 보고서에는 원인·문안·채널 수정안. 자동 정비·재측정은 포함하지 않았습니다.
