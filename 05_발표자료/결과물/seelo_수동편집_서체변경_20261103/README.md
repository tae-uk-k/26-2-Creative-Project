## 현재 편집 방식

사용자 요청에 따라 본문 6장과 표지 비교 2안의 오토레이아웃·허그·채우기·컴포넌트 인스턴스 연결을 모두 해제했다. 각 프레임과 요소의 위치·크기를 직접 수정할 수 있다. 텍스트도 고정 크기 박스로 전환했다.

- 오토레이아웃 77개 → 0개.
- 연결 인스턴스 29개 → 0개.
- 허그·채우기 0개, 자동 크기 텍스트 0개.
- 해제 전후 요소 배치·크기 이탈 0개. 문구 변경 0개.
- 사용자가 추가한 선과 최신 텍스트를 작업 시작 시점 그대로 보존했다.
- 백지 원본·Apple 시안·공통 컴포넌트 원본은 전환 대상에서 제외했다.

## 서체

- 기존 한글: Noto Sans KR. 토스 전용 서체를 쓰고 있던 상태는 아니었다.
- 변경 한글: IBM Plex Sans KR. 큰 제목 Bold, 카드 제목과 강조 문장은 SemiBold, 본문 Regular, 보조 라벨 Medium을 사용했다.
- 변경 숫자: Plus Jakarta Sans. 큰 퍼센트·페이지 번호·단계 숫자에 적용했다.
- seelo 로고: Pacifico를 유지했다.
- 현재 Figma 가용 폰트 목록에 Toss Product Sans와 Pretendard가 없어, 가용 폰트 중 실제 렌더링이 가능한 서체로 교체했다.
- 토스 공식 서체 설명: https://toss.im/tossfeed/article/beginning-of-tps

## 검수 및 파일

- 실제 Figma 렌더링 후 누락 글꼴 0, 글자 겹침 0, 프레임 밖 텍스트 0을 확인했다.
- 원본 백지 발표자료는 루트 포함 269개 노드를 유지했다.
- `변경전_본문.json`, `변경전_표지비교.json`: 작업 시작 시점의 좌표·문구·서체 백업.
- `변경결과.json`: 인스턴스 분리로 바뀐 노드 ID 대응과 검수.
- `최종검수.json`: 렌더링 후 오토레이아웃·허그·인스턴스·서체 재확인.
- `수동편집_서체.png`, `표지_서체.png`: 검수 이미지.

이제 발표자료는 수동 배치 상태가 기준이다. 이전 생성 스크립트를 그대로 다시 실행하면 자동 배치가 복원되거나 기존 컴포넌트 ID를 찾지 못할 수 있으므로, 이후 수정은 현재 노드를 조회해서 진행한다.
