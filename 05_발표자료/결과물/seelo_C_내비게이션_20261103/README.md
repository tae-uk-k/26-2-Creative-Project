# 시안 C 내비게이션

[Figma 2장](https://www.figma.com/design/M5WCPZN32W6PEeIaEvcRkC?node-id=620-67)

- 9장 공통: 흰색 1920×112 전체 폭 상단 바, 가는 하단 구분선, 왼쪽 로고와 오른쪽 메뉴 정렬.
- 현재 장: #191F28 SemiBold + #FFC54F 4px 밑줄. 기존 노란 선택 상자 대신 밑줄로 표시.
- 나머지 메뉴: #8B95A1 Medium. 글자는 26px 유지, 실제 블러는 적용하지 않음.
- 메뉴 클릭은 같은 C 시안의 해당 장으로 이동. 다른 장 메뉴 연결 72개 검증.
- 본문·카드·표지·다른 시안 변경 없음. 9장 본문 서명 동일.
- 수동 편집 구조 유지. 내비게이션 자동 레이아웃 0개, 글꼴 누락·넘침 0개.

수정 전 스크린샷, 변경 기준, 실행 스크립트, 최종 렌더 3개와 검증 결과를 함께 보관했다.
