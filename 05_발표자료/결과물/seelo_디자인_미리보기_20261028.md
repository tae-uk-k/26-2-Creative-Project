## 검증

- 스크롤 방향에 반대로 되끌리지 않는 스냅, 관성·터치·카드 내부 스크롤 테스트 통과
- 스크롤 중 과도한 레이아웃 읽기와 불필요한 렌더링 정지 테스트 통과
- 3D 모델·챕터 전환·막대 채움·움직임 줄이기 테스트 통과
- HTML 로컬 참조 경로와 브라우저 실행 JavaScript 구문 검사 통과
- Figma 실제 렌더링·연결 그래프 확인. 플레이어의 실제 클릭 재생 검수는 로컬 브라우저 설정으로 수행하지 못함
