# 시간 단위 실재생 검수

- 공식 Trigger 문서는 timeout을 밀리초로 기술한다: https://developers.figma.com/docs/plugins/api/Trigger/
- 이 세션 MCP로 timeout=700을 설정한 진단 시작은 실제 플레이어에서 대기 후에도 12%에 머물렀다.
- 같은 노드에 timeout=0.7을 설정하고 다시 불러오자 실제 플레이어가 다음 60% 화면(713:1397)으로 자동 이동했다.
- 따라서 이 파일의 이 MCP 작성 경로에서는 자동 전환 값을 실제 재생 기준 초 값으로 보정했다. 투명 라우터는 0.001, 상태 시연은 0.7~1.4를 쓴다.
- 문서 단위와 실제 저장 경로 동작의 차이를 기록한다. 향후 다른 플러그인/API로 다시 작성할 때 동일한 변환을 기계적으로 적용하지 않는다.
