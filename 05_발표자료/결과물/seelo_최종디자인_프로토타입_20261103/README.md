원본 디자인 99개 화면은 그대로 보존했다. 같은 페이지 오른쪽의 `최종 디자인 · 클릭 프로토타입 · 20261103` 구역(713:635)에 재생용 67개 화면을 만들었다. 내부 조건 분기 49개는 별도 구역 `프로토타입 · 상태 분기 로직`(733:627)에 모았다.

- 일반 회원가입: 713:920

- 내 가게: 713:1585

- 정상 0% 결과: 713:1521

R로 처음부터 다시 시작한다. 입력칸은 클릭하면 준비된 입력 완료 상태로 바뀐다. 인증·신청 승인 대기·지도 초대·정비안 확인 화면은 빈 곳을 클릭해도 다음 단계로 진행한다. 승인 팝업은 배경 클릭도 정비 시작으로 연결했고, ×와 다시 확인은 취소·복귀로 연결했다.

## 연결

일반 가입은 가게 등록 전 홈, 무료 진단 CTA에서 시작한 가입은 가게 입력으로 이어진다. 로그인은 기존 내 가게로 이어진다.

가게 후보는 선택 표시와 우측 선택 정보를 바꾼다. 진단은 진행률 12 → 60 → 100% 후 정상 결과로 이어진다. 실패 시 재시도, 정상 0%는 오류와 분리했다.

지도 연결은 미연결 / Google만 / 카카오만 / 모두 연결의 네 상태를 구분한다. 한쪽 지도만 연결해도 해당 지도의 정비안으로 이어진다. 정비안의 영업시간 입력·제외·다시 포함, 근거 보기, 확인 완료, 승인 팝업, 취소 복귀를 연결했다.

정비는 0 → 71 → 100%로 진행하고 완료 후 전후 비교 보고서를 연다. 계정 설정은 입력 완료, 비밀번호 변경 확인, 로그아웃, 탈퇴 취소·확인 입력 상태로 연결했다.

랜딩은 기존 섹션을 긴 스크롤로 구성했다. 히어로 하단 안내 클릭과 아래 방향키는 지도 장면으로 전환한다. 주요 CTA, 이용 방법, 무료·유료 안내, FAQ 6개, 메뉴·영업시간·지도 안내 팝업을 연결했다.

## 범위

디자인 프로토타입으로 외부 서비스에 실제 가입·인증·정비를 실행하지 않는다. 입력은 준비된 상태를 클릭으로 보여준다. 근거 팝업은 기존 디자인에 있는 질문·횟수를 재사용했으며 AI 답변 원문 데이터는 원본에 없어 새로 만들지 않았다. 랜딩 사진 탭은 원본에 상세 내용이 없어 별도 사진 목록을 추가하지 않았다.
