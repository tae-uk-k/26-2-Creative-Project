## 반영 사항

1. 토스 시각 체계를 유지해 4장까지 구성했다. Apple 시안과 백지 원본은 수정하지 않았다.
2. 발표자 이름은 표지에만 표시한다. 표지의 사용자가 입력한 팀·이름·날짜를 유지했다.
3. 2장 주요 설명 5개의 글자 수를 공백 제외 121자에서 96자로 약 21% 줄였다. 원본의 53%는 원형 그래프로 표현하고, ___% 두 값은 유지했다.
4. 3장 원본 문장은 줄바꿈을 제외하고 그대로 유지했다. 일반 설명은 32px Regular와 회색, 핵심 구절은 40~50px Bold와 진한 글자색 또는 파란색으로 구분했다.
5. 표지에 편집 가능한 입체 가게를 만들었다. 기본안은 반투명 표면·하이라이트·그림자와 Figma GLASS 효과를 사용한다. 별도 비교 구역에 솔리드 블루 가게 안도 배치했다.
6. 사용자가 1장에서 지운 소개 라벨과 단계 요약은 되살리지 않았다. 남긴 제목·설명은 내용 변경 없이 재배치했다.
7. 4장은 백지 원본 468:42의 자동정비, 정비안 확인·승인, 정비 진행·반영 결과, 5단계 사용 흐름, 역할 분담을 반영했다. 승인·완료 항목은 기존 프로토타입 223:1934 / 223:2021의 항목을 가져와 발표용 크기로 구성했다. 메뉴 가격·매장 영업시간 등의 값을 새로 만들지 않았다.

## 검수

- 1~4장과 표지 비교안 2장 모두 1920 × 1080.
- 텍스트 겹침 0, 텍스트의 자동 레이아웃 부모 영역 이탈 0, 누락 글꼴 0.
- 발표자 이름은 1장과 표지 비교안에만 보인다. 2·3·4장은 0개.
- 표지의 사용자가 남긴 제목·설명, 3장 원본 문장, 백지 원본 4장 문장 대조 불일치 0.
- 백지 원본은 루트 포함 269개 노드로 유지됐다.
- 가게와 화면 도식은 텍스트·벡터·도형·효과·컴포넌트로 구성했다. 전체 화면이나 가게를 이미지 한 장으로 넣은 산출물이 아니다.
- 2장의 출처 글자는 사용자가 조정한 21px를 유지했다. 나머지 보이는 일반 텍스트는 28px 이상이다.
- 실제 Figma 렌더링을 `4pages-composition.png`, `covers-composition.png`로 확인했다.
