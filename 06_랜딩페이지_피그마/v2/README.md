# seelo 랜딩페이지 v2 (토스 스타일 · 지도 핀)

피그마 `seelo 디자인1` 페이지의 `Home / 메인 B - TO1 (디자인 시스템)` 복제본(토스 스타일로 고친 안)을 HTML 한 파일로 옮긴 것입니다.
빌드 도구 없이 `index.html`을 브라우저로 열면 바로 보입니다. 글꼴(Noto Sans KR, Pacifico)은 Google Fonts에서 불러옵니다.

## 구성
- 헤더: 로고 · 서비스 소개 · FAQ · 로그인 · 회원가입 · 무료 진단 시작(강조)
- 첫 화면: 반투명 타일 9칸 위 지도 핀과 가게 이름 라벨, 가운데 제목과 버튼
- 이용 방법 · 사장님이 하지 않아도 되는 일 · 진단 리포트 · 무료 안내 · FAQ · 마무리 · 푸터

## 움직임
- 첫 화면: 제목 → 설명·버튼 → 가게 핀과 라벨이 빠르게 하나씩 → 잠깐 쉬었다가 우리 가게가 천천히 등장
- 이름 라벨은 각자 다른 속도로 위아래로 떠다님
- 스크롤: 요소가 화면에 들어오면 아래에서 올라오며 나타나고, 화면 밖으로 나가면 다시 숨었다가 위로 올릴 때도 같은 효과
- 첫 화면을 완전히 지나갔다가 돌아오면 처음부터 다시 재생
- 기기의 '동작 줄이기' 설정이 켜져 있으면 움직임 없이 모두 바로 보임

## 알아둘 점
- 가게 이름(소담한상 등)과 수치는 이해를 돕는 예시입니다.
- FAQ "진단은 얼마나 걸리나요?" 답변은 문구가 정해지지 않아 `[진단 소요 시간 안내 문구 확정 필요]`로 비워 두었습니다.
- 로그인·회원가입은 연결할 페이지가 없어 지금은 맨 위로 이동합니다.
- 이전 버전(`../index.html`)과 기존 Flask 앱은 건드리지 않았습니다.
